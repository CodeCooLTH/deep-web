- A-2 สิทธิ์ปุ่มใหม่ = S1 · สิทธิ์ตั้งจังหวะ = สิทธิ์เดียวกับหน้าส่งอัตโนมัติเดิม
- A-3 "ส่งเอง" = ไม่มีพัสดุ iShip active · มีทั้งสองอย่าง → iShip ชนะ
- A-4 "ส่งสำเร็จ" ใช้ผลข้างเคียงชุดเดียวกับลูกค้ายืนยัน — SDS ยืนยัน SSOT ในโค้ดก่อนเขียน
- A-5 `OrderEvent` ชนิดใหม่มีผู้กด + เวลา · ชื่อ/CHECK ให้ DATABASE ตัดสิน (additive)
- A-6 ค่าตั้งต้น `ON_SAVE` ผ่าน default ไม่ backfill รายร้าน
- A-7 ถ้อยคำ Swal ให้ `safepay-ux` เสนอ
- A-8 user ตรวจภาพเอง · Playwright E2E บังคับ ที่ `*.deepth.local:4000`
