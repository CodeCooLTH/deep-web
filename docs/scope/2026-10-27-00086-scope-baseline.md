## Goal
ร้านบริการ (`SERVICE_QUEUE`) รู้ว่าลูกค้า "จองล่วงหน้า" หรือ "หน้าร้าน" · รู้ว่าใครรับผิดชอบ เริ่ม และทำเสร็จงานไหน เมื่อไร พร้อมรูปและบันทึก · เจ้าของเลือกรายคนได้ว่าใคร "ปิดงานได้" (บังคับที่ server ทุกทาง) และใคร "บันทึกค่าใช้จ่ายได้" (กรองระดับแถว) · ร้านประเภทอื่นไม่เปลี่ยนเลย

## Guardrails / Non-goals
- **ร้านประเภทอื่นไม่เปลี่ยนแม้แต่จุดเดียว**: ทุก UI/API/migration backfill กั้นด้วย vertical `SERVICE_QUEUE` และมีเทสฝั่งร้านอื่นยืนยัน (บทเรียน #97, #103)
- **00082 ไม่กระทบ**: เทส buyer-confirm-closes-job เดิมต้องเขียวโดยไม่ต้องแก้
- **พนักงานเดิมยังปิดงานได้**: migration ติ๊ก "ปิดงานได้" ให้ตอบแชท/ฝ่ายช่างทุกคนในร้านบริการ
- **ค่าเริ่มของรูป = ไม่บังคับ + ลูกค้าไม่เห็น** ทั้งร้านเดิมและร้านใหม่
- **สิทธิ์บังคับที่ server**: การซ่อนปุ่มอย่างเดียวไม่นับว่ากั้นแล้ว · ชื่อคนกดและเวลามาจาก session/server เสมอ
- **ช่างไม่เห็นเงิน**: allow-list ของ 00071 ขยายได้เฉพาะรูป/บันทึก/ผู้รับผิดชอบ
- **ไฟล์ของหัวหน้า** (00071, `(paces)/seller/**`): แก้เฉพาะจุดเชื่อมที่ S-id ระบุ · rebase ตาม HR17 · PR เดียว ไม่ commit จนกว่า user รีวิว
- **คำตรง vertical**: ใช้ "หน้าร้าน"/"จองล่วงหน้า"/"งาน"/"ช่าง" · ห้ามใช้คำของร้านขายของปน
