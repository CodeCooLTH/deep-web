# Scope Baseline — 00083 ติด tag อัตโนมัติจากคำที่ร้านพิมพ์ + เมนูจัดการ tag

สถานะ: ACTIVE (user อนุมัติ PRD+BRD v0.1 2026-10-21)
อ้างอิง PRD: `docs/20 - Features/00083 - Auto Tag By Keyword/PRD.md` §3.1-3.5 · BRD FR-001..FR-009, BR-AT-01..30 · spec: SRS/SDS (เขียนหลัง PRD+BRD ผ่าน user — baseline นี้ ACTIVE เมื่อ user อนุมัติ PRD+BRD v0.1 หรือเวอร์ชันที่แก้)

## Goal
ร้านจัดการรายการ tag ที่หน้า "จัดการ tag" ตั้งคำให้ระบบติด tag เมื่อคนฝั่งร้านพิมพ์ข้อความที่มีคำ และตั้งให้ถอด tag เมื่อสร้างคำสั่งซื้อที่ผูกห้องนั้น

## Assumptions
- PRD/BRD ข้อเสนอ P-1..P-8 เป็นค่าตั้งต้นของ baseline จนกว่า user ตอบคำถามเปิด Q-1..Q-7; ข้อใดเปลี่ยน → Controller จด Change Log และปรับ S-id ที่เกี่ยว
- tag ยังเก็บเป็นชื่อบน `ExternalContact.tags` (ไม่ย้ายโมเดล); เพิ่มเฉพาะตารางรายการ tag/กติกา/ประวัติ
- ผู้ติดต่อหนึ่งรายมีห้องเดียวต่อเพจ (unique ในสคีมาปัจจุบัน) จึงถือติด tag ที่ห้อง = ติดที่ผู้ติดต่อของห้อง
- ตัวเทียบคำใช้ตัวเดียวกับวลีจุดชนวนของ 00061 (NFC · lowercase · ยุบช่องว่าง · มีคำนี้อยู่ในข้อความ) ไม่ใช้ตัวเทียบของตอบอัตโนมัติ (ตัดวรรคตอน/แทน `/` ด้วยช่องว่าง ออกแบบสำหรับข้อความลูกค้า)
- ชื่อ tag ใช้เพดาน 30 ตัวอักษรตามกติกา CRM เดิม (ตัวกรอง 40 / schema สินค้า 50 เป็นคนละเรื่อง)
- เมนูอยู่กลุ่ม CHAT ของ `seller-menu.ts` ต่อจาก "ส่งอัตโนมัติถึงลูกค้า"; ชื่อ icon ตรวจกับ tabler ก่อนใช้ (HR12)
