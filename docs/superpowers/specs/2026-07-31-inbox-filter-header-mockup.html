สรุปเปรียบเทียบ

A — ลดแถวได้เฉพาะร้านที่ไม่ได้ใช้ครบทุกช่องทาง/เพจ แต่ไม่มีใครเสียคลิกเลยสักคน และเสี่ยงต่ำสุด
B — 2 แถวเสมอ แลกด้วยการเลือกเพจเป็น 3 คลิก (กระทบเฉพาะร้านหลายเพจ)
C — 2 แถวเสมอ ไม่เสียคลิกเลย แต่ย้ายตำแหน่งของที่ผู้ใช้คุ้นมือแล้ว (ปุ่มตัวกรองย้ายลงแถวล่าง)

รวม A เข้ากับ B หรือ C ได้ — A เป็นกฎการซ่อน ไม่ใช่การจัดวาง จึงไม่ขัดกัน
