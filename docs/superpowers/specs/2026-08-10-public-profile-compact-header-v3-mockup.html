6 · สรุปที่เปลี่ยนจาก v2

1. แถบตัวเลขจาก 44px (บรรทัดเดียวสีเทา) → 72px มีเส้นคั่นตั้ง เลข 22px = เน้นขึ้นชัดแต่ยังเล็กกว่าเดิม 126px
2. ไอคอนเหรียญ 56 → 44px · ชื่อเหรียญย้ายไปชั้นสีรอง (`text.secondary`) = ลดน้ำหนักเหรียญตามที่สั่ง
3. ปุ่ม + ออกจากแถว → ลิงก์ "ดูทั้งหมด N →" มุมขวาแถวเดียวกับหัวข้อ (แบบ GitHub) คืนช่องให้เหรียญ และบอกจำนวนจริงตั้งแต่ยังไม่กด
4. ปุ่มแชทออกจากหน้าตาม phase นี้
5. อัตราตอบกลับรวมเป็นประโยคเดียว "ตอบกลับ 100% ใน 1 นาที" แล้วต่อท้ายบรรทัดหมวดหมู่ — −26px
6. เช็คยืนยันตัวตนย้ายไปต่อท้ายชื่อร้าน (verified badge)
