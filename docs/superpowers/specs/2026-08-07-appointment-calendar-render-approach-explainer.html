อาจอพพฤศส

สิ่งที่ตัวสาธิตข้างบนกำลังบอก

  • ฝั่งซ้ายไม่มีขั้นตอนให้ลืม — จุดเหลือง/กากบาทเป็น “ผลลัพธ์ของข้อมูล” ข้อมูลเปลี่ยนเมื่อไหร่ภาพเปลี่ยนตาม ไม่ต้องมีใครสั่ง
  • ฝั่งขวาต้องจำสั่ง redraw() ทุกจุดที่ข้อมูลเปลี่ยน ในหน้าจริงมี 3 จุด (fetch เสร็จ · เปลี่ยนคิวงาน · เปลี่ยนเดือนแล้ว fetch ชุดใหม่) ลืมจุดใดจุดหนึ่ง = ปฏิทินโชว์ความว่างของคิวงานอันเก่า โดยไม่มีอะไรฟ้อง — เป็นคลาสบั๊กที่โปรเจกต์นี้เจอมาแล้วหลายรอบ (บั๊กที่แก้ล่าสุดในคอมมิต 9003ce12 ก็คือเรื่องนี้เป๊ะ: ปฏิทินโหลดความว่างของคิวงานผิดตัวตอนกดการ์ดครั้งแรก)
  • สิ่งที่ Flatpickr ให้ฟรีจริง ก็มี: ช่องวันเป็นปุ่มกลม ๆ ไม่มีเส้นตาราง + ชื่อวันย่อไทย (“อา จ อ พ พฤ ศ ส”) มากับตัว lib — แต่ทั้งสองอย่างนี้ในฝั่งซ้าย จบไปแล้วด้วย CSS 8 บรรทัดกับอาเรย์ 7 ช่อง ซึ่งเขียนครั้งเดียวไม่มีทางลืมทีหลัง
  • สิ่งที่เสียถ้าย้าย: ต้องคำนวณช่วง 42 วันที่มองเห็นเอง (FullCalendar ส่ง datesSet ให้อยู่แล้ว), ต้องปิดหัวเรื่องของ Flatpickr เพราะเราวาด พ.ศ. เอง, และหน้า /queues ยังใช้ FullCalendar อยู่ดี → มีปฏิทิน 2 กลไกให้ดูแลแทนที่จะเป็นชุดเดียว
