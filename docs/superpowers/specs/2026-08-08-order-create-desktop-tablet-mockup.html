(ของเดิม 5)		แก้ปัญหาข้อไหนความเสี่ยงเหมาะกับใคร
A. เปิดครบ ปิดเฉพาะของแถม4F2 ฟิลด์บังคับถูกซ่อน · F3 คลิกเยอะ · F4 ทางลัดฝังลึกต่ำ — ลบโค้ดมากกว่าเพิ่มทุกร้าน (เป็นฐานของ B/C/D)
B. วางจากแชทมาก่อน3 ← น้อยสุดF3 · F4 (ยกทางลัดขึ้นบนสุด)ต่ำ — ระวังการ์ดเกะกะคนพิมพ์เองร้านที่ปิดการขายในแชทเป็นหลัก
C. เปลี่ยนตามประเภทร้าน4 ขายของ / 3 ร้านบริการF2 · ตอบโจทย์ "ร้านคนละแบบต้องการข้อมูลคนละชุด" ตรงที่สุดกลาง — ต้องดูแลลำดับ 3 ชุดร้านบริการ / บ้านพัก
D. แท็บเล็ตเป็นพลเมืองชั้นหนึ่ง4 (แต่ scroll สั้นลงมาก)F1 — ต้นเหตุจริงของคำว่า "ใช้ยาก" บนแท็บเล็ตกลาง-สูง — เพิ่ม breakpoint ที่ 768pxร้านที่ยืนขายด้วย iPad
E. ตะกร้าลอยข้าง + แท็บ5 ← ไม่ดีขึ้นเลยเห็นยอดรวมตลอด แต่เอา friction แบบ accordion กลับมาในรูปแท็บสูงสุด — กระทบ viewport-lock + deep-linkออเดอร์หลายรายการมาก ๆ
