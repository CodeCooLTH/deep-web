## 0. สรุปการตัดสินใจ (อ่านส่วนนี้ก่อน)

1. **ขอบรูป + ไอคอนมุม** ทำเป็นคอมโพเนนต์เดียวใช้ 3 จุด ขอบเป็น `outline-2 outline-offset-2 outline-purple` ติดที่ตัวรูปเอง ไม่ติดที่ wrapper
   - ไอคอนมุมอยู่ **มุมบนขวา** (มุมล่างขวาเป็นของ `ChannelBadgeOverlay`)
   - เสนอไอคอน `shopping-cart` เป็นตัวเลือกหลัก (U1)
2. **ชิป "Meta AI คุมอยู่"** ใช้โทน **กลาง (เทาเข้ม)** ไม่ใช้ info (ฟ้า) หรือ warning (เหลือง)
   - ฟ้าชนกับป้ายลูกค้า ซึ่งเป็น info ในแถวเดียวกัน
   - เหลืองจะอ่านเป็นข้อผิดพลาด
   - ไอคอน `sparkles` ตรงกับ legend ของโต๊ะแชท 00077 ที่ใช้ `sparkles` กับ Meta AI อยู่แล้ว
3. **ไอคอน `sparkles` ถูก "ลูกค้าใหม่" ใช้อยู่** (`customer-behavior.ts:235`) จึงต้องย้ายป้ายลูกค้า ไม่งั้นสองชิปในแถวเดียวกันจะมีไอคอนเดียวกัน
   - เสนอ "ลูกค้าใหม่" เป็น `user-plus` ซึ่งฟอร์มสร้างออเดอร์ใช้อยู่แล้วที่ `CustomerQuickBlock.tsx:277`
   - เสนอ "ลูกค้าซื้อซ้ำ" เป็น `repeat` ซึ่งตัวกรองใน `/customers` ใช้อยู่แล้ว
4. **แถวแคบ:** ชิปบรรทัดป้ายแสดงสูงสุด 4 ใบ ที่เหลือยุบเป็น `+N` ด้วย Tailwind container query (CSS ล้วน ไม่วัด DOM)
   - เหตุผล: ความกว้างข้อความจริงเหลือแค่ 112-246px ทั้งในมือถือและ rail เดสก์ท็อป 384px (คำนวณใน §2.4)
5. **หน้าตั้งค่า:** สร้างหน้าใหม่ `/settings/auto-notify` ชื่อ "ส่งอัตโนมัติถึงลูกค้า" วางในกลุ่มเมนู CHAT
   - ไม่ยัดลง `/settings` เพราะหน้านั้นคือ "การจัดส่ง" (iShip) และ OWNER/MANAGER เท่านั้น
   - บทบาท CHAT ต้องเห็นสถานะได้ตาม BRD ซึ่งขัดกับกติกาของหน้า `/settings` เดิม
   - ไม่ยัดลง `/settings/auto-reply` เพราะนั่นคือบอท และฟีเจอร์นี้ต้องแยก "ระบบ" ออกจาก DeepBot
6. **ข้อความระบบ:** ป้ายเกยขอบบนบับเบิล "ส่งโดยระบบ" ไอคอน `send` สีกลาง ไม่กดได้
   - ต่างจาก DeepBot ที่ขอบ/ตัวอักษรสี primary และกดได้
   - ต่างจากป้าย AI ของ Meta ที่เป็นเทาเหมือนกันแต่ใช้ `brand-meta`
7. **ช่องติ๊ก "แจ้งลูกค้า"** ใน `ShipmentDraftPanel` ถูกแทนด้วยข้อความ **เฉพาะเมื่อระบบจะส่งจริง** (สวิตช์เปิด + ออเดอร์ผูกห้อง + ไม่ใช่ dry-run) ไม่ใช่แค่สวิตช์เปิด ไม่งั้นร้านเสียทางแจ้งเลขโดยไม่รู้ตัว
8. **คอนทราสต์ขอบ `#7b70ef` ผ่าน ≥3:1 ทุกพื้นทั้ง light/dark** ต่ำสุด 3.39:1 (แถวเลือก, light) คำนวณมือ ต้องให้ QA วัดจอจริงซ้ำ (§1.3)

- ขอ Controller เคาะว่ารับความเสี่ยงนี้หรือไม่ ก่อนลงมือเขียน

### 2.3 Section breakdown

- **A. รูป (`BuyerAvatar`):**
  - เพิ่ม prop `customerRing?: boolean` (ใช้คอมโพเนนต์เดียวกับหัวห้อง/แผงขวา)
  - ใส่ `outline-*` ที่ `<img>` **และ** ที่ `<span>` fallback ตัวอักษรย่อ (ทั้งสองมี `rounded-full`) ถ้ารูปโหลดพลาด ขอบต้องไม่หาย
  - จานมุมอยู่ใน wrapper `span.relative.shrink-0` เดิมที่ `InboxRow.tsx:222`
- **B. บรรทัดป้าย (`InboxRow.tsx:339-418`):** เรียงลำดับใหม่ตามตาราง §2.4
- **C. ป้ายพฤติกรรม:** `customerBadges()` คืนเป็น counted 1 = "ลูกค้าใหม่", ≥2 = "ลูกค้าซื้อซ้ำ" (tone `info`), ป้ายตีกลับ/ยกเลิกคงเดิม (tone `warning`)
- **D. ไม่เปลี่ยน:** คำนำ `คุณ: ` คงตามมติ 2026-08-01 แม้ข้อความล่าสุดมาจากระบบ (user ให้เป็น "คุณ" ทั้งคนและบอท)
- **E. ป้าย DeepBot (`:383`):** ต้องไม่ขึ้นกับข้อความระบบ (ค่า `autoReplyKind` ใหม่) ดู FR-CS-16

- ชิป `+N` ใช้ `role="img"` + `aria-label="ป้ายอื่นอีก N รายการ: …ชื่อ…"` + `title` (ท่าเดียวกับป้ายพฤติกรรม `InboxRow.tsx:366`)
- ที่ข้อความกว้าง ≥448px (`@md` = 28rem, เช่นแท็บเล็ต 834) แสดงครบทุกใบ ไม่มี `+N`
- **ผลที่คาด:** กรณีทั้ง 4 ใบอยู่พร้อมกันที่ข้อความกว้าง 176px ชิปเรียง 3 บรรทัด (98+73 พอดี 1 บรรทัด, 80 บรรทัดสอง, 102 บรรทัดสาม) ต่างจากเดิมที่ไม่มีเพดานและเคยพุ่งถึง 153px สูง ตามที่ critique 2026-08-09 บันทึกไว้
- Tailwind `@container` / `@md:` เป็นของ core v4 ไม่ใช่ arbitrary value แต่ยังไม่มีใครใช้ใน repo dev ต้องตรวจว่า build ออกคลาสได้ (U3)

**ไม่ใช้ JS วัดความกว้าง** ตรงนี้ใช้ container query ล้วน เพราะ `docs/conventions/measurement-must-not-decide-what-it-measures.md` ห้ามวัด DOM แล้วเปลี่ยนสิ่งที่วัด

### 2.5 ชิป Meta AI: ดีไซน์

- คลาส: `badge text-2xs inline-flex shrink-0 items-center gap-1 bg-default-200 text-default-800`
- ไอคอน `sparkles` ขนาด 12 `aria-hidden="true"` ข้อความ "Meta AI คุมอยู่"
- `title="Meta AI กำลังตอบลูกค้าห้องนี้แทนร้าน"`
- **ไม่ใส่ `role="img"` + `aria-label`** (ชิปนี้มีข้อความที่มองเห็นอยู่แล้ว ใส่ label จะไปทับข้อความ ตรงข้ามกับป้ายพฤติกรรมที่ไม่มีข้อความ) ดู `docs/conventions/aria-name-requires-supporting-role.md`
- สี: light `#eef2f7`/`#343a40` (10.2:1), dark `#27272a`/`#e4e4e7` (≈11.8:1)
- แสดงเฉพาะ MESSENGER/INSTAGRAM และเฉพาะเมื่อ `isMetaAiHolding(...)` เป็นจริง (ฟังก์ชันตัวเดียวตาม FR-CS-02) LINE/DEEP ไม่เคยขึ้น

**เหตุผลที่ไม่ใช้ info/warning:**
- ฟ้า (info) คือโทนของ "ลูกค้าใหม่/ซื้อซ้ำ" ในแถวเดียวกัน

- **ลำดับชนะของช่องป้าย:** DeepBot/AUTO_TEST → ระบบ (ค่าใหม่) → AI ของ Meta (เปลี่ยนเงื่อนไขที่ `:677-688`)

### 6.2 บับเบิลล้มเหลว (ใช้กลไกเดิม ไม่สร้างใหม่)

## 7. User flow

1. ผู้ขายเปิด `/inbox` → เห็นวงม่วงที่รูป + ป้ายตัวอักษรของลูกค้าที่เคยซื้อ และชิป "Meta AI คุมอยู่" ในห้องที่ AI ตอบ
2. แตะแถว → หัวห้องมีวงม่วง และชิป "Meta AI คุมอยู่" ในแถบชิปใต้หัว → แตะชิปเพื่อกางคำอธิบาย (ไม่มี action)
3. ผู้ขายยังพิมพ์ได้ตามปกติ ถ้า Meta ปฏิเสธ → บับเบิลล้มเหลวตามกลไกเดิม พร้อมถ้อยคำ `#10` เดิม
4. เปิดแผงลูกค้า → รูปมีวงม่วง (ไม่มีป้ายข้อความ)
5. ไปเมนู CHAT → "ส่งอัตโนมัติถึงลูกค้า" → อ่านข้อควรรู้ → เปิดสวิตช์ → toast "เปิดแล้ว ใช้กับคำสั่งซื้อที่สร้างหลังจากนี้"
6. สร้างออเดอร์ในห้อง → ห้องมีบับเบิลสรุปพร้อมป้าย "ส่งโดยระบบ" (หรือบับเบิลล้มเหลวถ้าส่งไม่ได้)
7. เปิดพัสดุจากแผงพัสดุ → เห็นข้อความ "ระบบจะแจ้งเลขติดตามให้ลูกค้าในแชทนี้เอง" แทนช่องติ๊ก

## 11. Impeccable compliance

- **Mode: Operate** (คอนโซลผู้ขาย รายการหนาแน่น แถวกวาดตา ฟอร์มสวิตช์) · scanability + consistency ชนะการแสดงออก (`operate.md`) แบรนด์อยู่ในรายละเอียด: ชิปตระกูลเดียวกัน ภาษาไอคอนเดียวกัน ถ้อยคำเดียวกับระบบเดิม
- **The Trusted Counter:** ชิป/ป้ายแต่ละอันแปลงสถานะจริงที่ตรวจสอบได้ (นับจากแถว `Order` ตรง ๆ) ไม่ประกาศลอย ๆ ไม่มีข้อความไฮป์ ("เยี่ยมมาก" ฯลฯ)
- **One Voice:** accent ของหน้าตั้งค่า = สวิตช์ ON (primary น้ำเงิน) เท่านั้น ในรายการห้อง ม่วงเป็นเส้น 2px + จาน 16px ต่อรูป ไม่ถึง 1% ของพื้นที่จอ ชื่อลูกค้า (`text-default-900` ตัวหนา) ยังเป็นพระเอกของแถว
- **Verified-Means-Green:** ชิปใหม่ทั้งหมดไม่ใช้เขียว (Meta AI = เทา, ลูกค้า = info ฟ้า, ระบบ = เทา, สวิตช์ ON = primary น้ำเงิน) ข้อสังเกตที่มีอยู่เดิมและไม่ได้แตะ: ชิป "ติดตาม" ค้างอยู่ใช้เขียว (user สั่ง 2026-10-05) และ "สนใจ" ใช้ `text-success` (ไม่ใช่ `-ink`) เป็นหนี้เดิม ไม่ใช่ของรอบนี้
- **Sentence-case / ภาษาไทย:** ไม่มี ALL CAPS ศัพท์: ใช้ "Meta AI", "ลูกค้าซื้อซ้ำ" ตามที่ user ระบุ
- **เงาผสมหมึก:** ป้ายบนบับเบิลใช้ `shadow` ของธีม (ไม่ดำสนิท)
- **น้ำเสียง:** ข้อความทุกชิ้นบอกทางออกหรือบอกเหตุ ("ตอบเองให้ไปรับดูแลแชทที่ Business Suite", "ถ้าส่งไม่ได้ จะมีข้อความ ‘ส่งไม่สำเร็จ’ ในห้องนี้") ไม่ใช้ "ไม่สามารถ" / "คุณไม่มีสิทธิ์" เป็นกลางกับ Meta AI (ไม่โทษ)

**จุดที่ theme ขัดกับ Impeccable / HR และการตัดสิน:**

1. **ม่วง `#7b70ef` ใน `(paces)`** ขัดกับ HR7 และ DESIGN.md ที่สงวนม่วงไว้ฝั่ง buyer · **ตัดสิน:** ใช้ตาม Q-8 ที่ user ล็อกไว้ ผ่านโทเคน `--color-purple` (ไม่ใช่ hex ดิบ) hue ใกล้ม่วง buyer (`#7367F0`) มาก เสี่ยงโดน critique ตีกลับ Controller ควรเพ่งตรงนี้
2. **ขอบหนา 2px** ขัดกับ One-Pixel Border Rule · **ตัดสิน:** กฎนี้ห้ามขอบข้างหนาบนการ์ด/รายการ (`border-s-3`) ส่วนนี้เป็น `outline` รอบรูปวงกลมตามที่ user สั่ง (outline 2px offset 2px) ท่าเดียวกับวงแหวน `ring-2` ของกองรูปแอดมินในแถวเดียวกัน (`InboxRow.tsx:602`) ไม่ใช่แถบสีตกแต่ง
3. **ชิป 11px** (`text-2xs`) เป็นขนาดเดิมของระบบ · **ตัดสิน:** คงตามเดิม เป็น precedent ในไฟล์
4. **เป้าแตะของชิปใน `ThreadChipStrip`** สูง ≈28px (`py-1 text-xs`) ต่ำกว่า 44px บนมือถือ · **ตัดสิน:** เป็นหนี้ของคอมโพเนนต์เดิม ชิปใหม่ยึดตามเพื่อนบ้าน ถ้า Controller อยากแก้ ให้แก้ที่ระดับ strip (`min-h-11 lg:min-h-0`) ไม่แก้เฉพาะชิปนี้ (U11)

## 12. Design decisions + rationale

- **ชิปเป็นเทา ไม่ใช่ฟ้า/เหลือง:** อธิบายแล้วที่ §2.5
- **เพดานชิป 4 ใบ:** ต่อยอดมติเดิมของ critique 2026-08-09 ที่ตัดแท็กเหลือ 1 ใบเพราะความสูงแถวต่างกัน 2.4 เท่า การเพิ่มชิป 2 ใบโดยไม่มีเพดานคือการย้อนบทเรียนเดิม
- **ย้าย `sparkles` ออกจาก "ลูกค้าใหม่":** HR16 ไอคอนเดียวไม่ควรหมายถึงสองอย่างในแถวเดียวกัน ราคา: แก้ `customer-behavior.ts` 1 บรรทัด + `customerBadges` ที่เทสมีอยู่
- **หน้าใหม่ ไม่ใช่ยัดหน้าเดิม:** §5.1
- **ข้อความแทนช่องติ๊กเป็นเงื่อนไขหลายตัว ไม่ใช่แค่สวิตช์:** ป้องกันการเสียทางแจ้งเลขแบบเงียบ ๆ
- **ไม่เพิ่ม Swal ยืนยันตอนเปิดสวิตช์:** operate.md · ผลข้างเคียงทุกอย่างเปิดเผยบนหน้า และไม่ย้อนหลัง
- **ไม่แตะคำนำ "คุณ: " ในพรีวิวแถว:** ตามมติ 2026-08-01
- **ตัวเลือกไอคอนทั้งหมดเป็นข้อเสนอ รอ user เลือก (HR12)** ดู U1

## 13. Anti-slop self-check

1. **เฉพาะกับ Deep หรือไม่:** ใช่ ทุกชิ้นผูกกับของจริงของโปรเจกต์: ศัพท์ `resolveOrderVocab` ที่ผันตามประเภทกิจการ, หน้าต่าง 24 ชม. ของ Meta, โควตา LINE, `trackingMessage()` และลิงก์ iShip, ตัวแบ่ง "ระบบ" ออกจาก DeepBot · เอาไปใช้กับสินค้าอื่นไม่ได้
2. **พระเอกต่อหน้าจอ:** แถวรายการ = ชื่อลูกค้า (เข้มสุด) · หัวห้อง = ชื่อ · หน้าตั้งค่า = สองสวิตช์ (ข้อความเข้มสุด ที่เหลือถอยเป็น default-600/700)
3. **ตัด/ไม่ซ้ำ:** ไม่เพิ่มการ์ดสถิติ ไม่เพิ่มป้ายที่ซ้ำกับขอบ (ในแถวมีป้ายข้อความ จานมุมเป็น `aria-hidden`) ตัดการ์ด "ข้อควรรู้" ที่เป็นข้อความคงที่ทิ้งส่วนช่องทางที่ร้านไม่ได้เชื่อม · ชิป `+N` ผสานกับ `+N` ของแท็กเดิมเพื่อไม่ให้มีสองความหมาย
4. **ครบทุกสถานะ:** ตาราง §10 + §2.7 (empty, loading, error, ไม่มีสิทธิ์, ข้อความยาว, รูปพลาด, ตัวเลข 0, หมดอายุ 24 ชม. ระหว่างเปิดค้าง)
5. **ข้อความตรงกับสิ่งที่ระบบทำได้จริง:** ข้อความแทนช่องติ๊กปรากฏเฉพาะเมื่อระบบจะส่งจริง · ไม่แนะนำ "ส่งเองได้" ในสถานะที่ Meta ปฏิเสธมือเช่นกัน (§6.2) · toast ไม่อ้างว่าส่งสำเร็จ · ปุ่มชื่อด้วยผลลัพธ์ ("ลองใหม่", "ยกเลิก")
6. **คำเดียวกัน = ของเดียวกัน:** "ส่งอัตโนมัติถึงลูกค้า" เป็นชื่อเดียวทั้งเมนู/หัวหน้า · "ส่งโดยระบบ" ≠ "DeepBot" ≠ "AI ของ Meta" · "ลูกค้าใหม่" = ใบที่นับ 1 (ไม่ใช่ "ยังไม่เคยซื้อ" ซึ่งฟอร์มสร้างออเดอร์ต้องแก้ตาม Q-4) · ข้อควรรู้ยังไม่ชน "ซื้อซ้ำ" ของสถิติสาธารณะ (คนละผู้ชม, glossary ตาม PRD §3.2.1)

มติ user: **ย้ายสัญญาณไปที่รูป + เวลา** (ทับ §2.4/§2.5 ในส่วนที่ขัด)

1. **ลูกค้าใหม่/ซื้อซ้ำในแถวรายการห้อง ไม่มีชิปข้อความแล้ว** — บอกด้วยขอบรูปม่วง + จานมุมบนขวา:
   - ลูกค้าใหม่ (นับได้ 1): จานม่วงไอคอนรถเข็น
   - ลูกค้าซื้อซ้ำ (≥2): จานม่วงแสดง **ตัวเลขจำนวนใบ** (2, 3 … เกิน 9 = "9+") แทนไอคอน
   - จานมุมในแถวเปลี่ยนเป็น `role="img"` + `aria-label` ("ลูกค้าใหม่ ซื้อแล้ว 1 คำสั่งซื้อ" / "ลูกค้าซื้อซ้ำ ซื้อแล้ว 3 คำสั่งซื้อ") + `title` — เพราะไม่มีชิปข้อความข้างล่างแล้ว
   - ชิปข้อความ "ลูกค้าใหม่/ลูกค้าซื้อซ้ำ" ยังใช้ในหน้าอื่น (`/orders`, `/customers`, ฟอร์มสร้างออเดอร์) ตามเดิม
2. **Meta AI ในแถว = ไอคอนเล็ก `sparkles` หน้าเวลา** (คอลัมน์ขวา บรรทัดเวลา) ไม่ใช่ชิป · `role="img"` + `aria-label="Meta AI กำลังควบคุมห้องนี้"` + `title` · หัวห้องยังเป็นชิปเต็มตาม §3
3. **บรรทัดชิปในแถว: สูงสุด 2 ใบ + "+N"** ทุกขนาดจอ (เลิก container query 4 ใบ) ลำดับ: ติดตาม → ตีกลับ/ยกเลิก → DeepBot → สถานะขาย → ad_id → แท็ก · `+N` อ่านชื่อที่ซ่อนได้ (aria/title)
