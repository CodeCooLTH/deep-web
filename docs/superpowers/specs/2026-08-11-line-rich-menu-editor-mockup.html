!

เปิดใช้เมนูของ Deep บนเพจ “BT สาขา สุขสวัสดิ์”?

ถ้าเพจนี้เคยตั้งเมนูไว้เองใน LINE Official Account Manager เมนูของ Deep จะแสดงแทนทันที

  • ระบบตรวจไม่ได้ว่าเพจนี้มีเมนูเดิมอยู่หรือเปล่า — LINE ไม่เปิดให้เครื่องมือภายนอกตรวจสอบส่วนนี้
  • ฝั่ง LINE Official Account Manager จะยังแสดงเมนูเดิมของคุณว่า “ใช้งานอยู่” ทั้งที่ลูกค้าเห็นเมนูของ Deep แล้ว — เป็นเรื่องปกติ ไม่ใช่ความผิดพลาด
  • กด “คืนเมนูเดิม” ได้ทุกเมื่อในหน้านี้ เมนูที่ตั้งไว้เดิมจะกลับมาทันที

⑥ ทางเข้า — แถวใหม่ในการ์ด LINE OA ที่ /settings/channels (5 สถานะ)

เขียวมีจุดเดียว — “ลูกค้าเห็นเมนูนี้อยู่” เท่านั้น (Verified-Means-Green: เขียว = ยืนยันแล้วว่าทำงานจริง) “สร้างไว้แล้ว” ใช้ฟ้าเพราะยังไม่ live · “ไม่ได้ใช้เมนูของ Deep” ห้ามเขียนว่า “ร้านนี้ไม่มีเมนู” เพราะเรามองไม่เห็นเมนูฝั่ง OA Manager — การเขียนว่าไม่มีคือการโกหกที่ทำให้ร้านตัดสินใจผิด

สิ่งที่ mockup นี้ยึดจากของจริง ไม่ได้วาดตามใจ
• สัดส่วนพรีวิว 2500×1686 = กรอบที่ระบบเรนเดอร์จริง (RICH_MENU_CANVAS_*) ผ่านเกณฑ์ ≥1.45 ของ LINE
• เพดาน 14 ตัวอักษร ของแถบเปิดเมนู = เพดานจริงของ LINE นับเป็น code point (ไม่ใช่ String.length)
• เลย์เอาต์ 2×2 (4 ปุ่ม) และ T-split (3 ปุ่ม) = ค่าจาก layoutFor() ตัวเดียวกับที่ประกอบพิกัดส่ง LINE
• ปุ่ม “ดูสินค้า/ดูบริการ” จะหายไปทั้งปุ่มถ้าร้านยังไม่มีหน้าร้านสาธารณะ — เมนูจะเหลือน้อยลงหนึ่งช่อง (ไม่ใช่ลิงก์เสีย)
• ป้าย “ตอบสถานะพัสดุอัตโนมัติ” ใต้ช่องกรอก = คำอธิบายพฤติกรรมปุ่ม ซึ่งตอนนี้ยังไม่ทำงาน (ยังไม่ต่อ webhook)
