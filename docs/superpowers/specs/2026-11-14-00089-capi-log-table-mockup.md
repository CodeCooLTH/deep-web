## จอไหนเป็นอะไร

`DataTable` สลับที่ `lg` (1024px): **≥ lg = ตาราง · < lg = การ์ดรายการ** ⇒ Desktop 1280 เป็นตาราง · Tablet 768 และ Mobile 390 เป็นการ์ดทั้งคู่ (Tablet ต่างแค่ padding `sm:px-5` และเวลา · ชุดข้อมูล · มูลค่า อยู่บรรทัดเดียว)

## คอลัมน์ตาราง (Desktop)

| คอลัมน์ | แสดง | ข้อมูลมาจาก |
|---|---|---|
| เวลา | `14-11-2569 13:31:02` | `formatDateTime(createdAt)` |
| ลูกค้า | รูป 32px + ชื่อ · ไม่มีลูกค้า = "–" · มีลูกค้าแต่ไม่มีชื่อ = "ลูกค้าไม่ระบุชื่อ" | `customer.avatarUrl` · `customer.name` · `t.logNoName` |
| เหตุการณ์ | "ซื้อ (Purchase)" + ใต้ชื่อ ลิงก์เล็กสีน้ำเงิน "ออเดอร์ #DP-000123" เมื่อมีออเดอร์ | `t.events[eventKey].label` + `metaName` · `order.orderNo ?? publicToken.slice(0,8)` |
| โฆษณา | รูป 32px (ไม่มีรูป = ช่องไอคอน speakerphone) + ชื่อแอดตัด … พร้อม `title` + "คลิกเมื่อ 14-11-2569 13:20" · ไม่มี = "–" | `ad.photoFileId?variant=thumb` · `ad.adTitle` (ว่าง = "รหัสโฆษณา {adId}") · `ad.clickedAt` → `t.logAdClicked` |
| ชุดข้อมูล | ชื่อชุดข้อมูล | `datasetName` |
| มูลค่า | ชิดขวา `฿590.00` · null = "–" | `value` |
| สถานะ | ป้าย soft: รอ เหลือง · สำเร็จ เขียว · ล้มเหลว แดง · ข้าม เทา | `status` → `t.logStatus` |
| เหตุผล | ข้อความเหตุผล · แดงเมื่อ FAILED · ไม่มี = "–" | `capiReasonKey` + `attempts` → `t.logReason` |

## การ์ด (Tablet/Mobile)

1. รูป 36px + ชื่อลูกค้า · ใต้ชื่อ = ชื่อเหตุการณ์ · ป้ายสถานะชิดขวา (ไม่มีลูกค้า = ไม่มีรูป ชื่อเหตุการณ์เป็นบรรทัดหลัก)
2. เวลา · ชุดข้อมูล · มูลค่า (Mobile เวลาบรรทัดแรก ที่เหลือบรรทัดถัดไป)
3. ลิงก์ "ออเดอร์ #…" พื้นที่แตะสูง 44px (`min-h-11`)
4. บรรทัดแอด: รูป 32px + "จากโฆษณา {ชื่อ} · คลิกเมื่อ {วันเวลา}" ตัด … ทั้งบรรทัด + `title`
5. เหตุผล (แดงเมื่อ FAILED)

หัวการ์ด: "บันทึกการส่ง" + "เก็บไว้ทั้งหมด ไม่มีหมดอายุ" + ตัวกรองสถานะ/เหตุการณ์ · ท้ายการ์ด: "แสดง 20 รายการ" + "โหลดเพิ่ม"

## สิ่งที่ม็อกอัพเติมจากโค้ด (ต้องยกไปแก้โค้ดถ้าเห็นด้วย)

- `whitespace-nowrap` ที่ชื่อชุดข้อมูล ชื่อเหตุการณ์ และลิงก์ออเดอร์ + คอลัมน์เหตุผลกว้างขั้นต่ำ 13rem — ไม่ใส่แล้ว "ชุดข้อมูลของเพจ" แตกทีละคำ 4 บรรทัด และเหตุผลแคบเหลือ 1–2 คำต่อบรรทัด

## คำถามที่ยังเปิด

1. **ตารางล้นแนวนอนที่ Desktop 1280** — มี sidebar แล้วพื้นที่เหลือ ~995px แต่ 8 คอลัมน์ต้องการ ~1,290px ⇒ มูลค่า/สถานะ/เหตุผลต้องเลื่อนขวาถึงเห็น · ทางเลือก: (ก) รวมสถานะ + เหตุผลเป็นคอลัมน์เดียว (ป้ายบน เหตุผลล่าง) (ข) ย้ายชุดข้อมูลไปใต้เวลา (ค) ยอมเลื่อนแนวนอน
2. **บรรทัดแอดบนมือถือตัดวันคลิกหาย** — "คลิกเมื่อ 14-11…" ถูกตัด ถ้าวันคลิกสำคัญควรแยกเป็นบรรทัดของตัวเอง (แบบ timeline เดิม)
3. **Tablet ได้การ์ด ไม่ได้ตาราง** — ตามเกณฑ์ `lg` ของ DataTable ถ้าอยากให้ Tablet เป็นตารางต้องแก้ DataTable (กระทบทุกหน้า) — แนะนำคงไว้
4. ข้อเดิมจากแบบ timeline ยังเปิดอยู่: "token หมดอายุ" ในโค้ดเป็น PENDING ไม่ใช่ FAILED · SKIPPED ที่ไม่ใช่ TOO_OLD ไม่มีเหตุผล · "แสดง 20 รายการ" อาจอ่านว่ามีแค่ 20
