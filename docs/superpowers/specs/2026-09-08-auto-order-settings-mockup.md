## 3 จอ

### 375px — ประตูมือถือ (ตั้งค่าไม่ได้ **โดยตั้งใจ**)

มติ user 2026-08-29: หน้านี้ต้องดู **แม่แบบ + รายชื่อเพจ + ผลทดสอบ** พร้อมกันถึงจะตั้งค่าได้
อย่างมั่นใจ · แบบอย่างในระบบ = ตัวจัดหน้าร้าน 00035 ที่ gate ไว้ที่ `xl` (อันนี้ gate ที่ `md`
เพราะแท็บเล็ตพอ)

🛑 **จอนี้บอก 3 อย่าง ไม่ใช่แค่ไล่ผู้ใช้ไปที่อื่น:**
1. ตั้งค่าที่ไหนได้ **และทำไม**
2. **"ระบบยังทำงานบนมือถือตามปกติ"** — ไม่บอก = ผู้ขายเข้าใจว่าฟีเจอร์ทั้งอันใช้บนมือถือไม่ได้
   ทั้งที่ความจริงคือ *ตั้งค่าไม่ได้เท่านั้น* การดักจับ/ผลลัพธ์ทำงานเต็มที่
3. ทางไปต่อที่ทำได้จริงบนมือถือ (ห้องแชท · ชิปร่างใน `/orders` พร้อมตัวเลข)

### 768px — 1 คอลัมน์

จุดแตก 2 คอลัมน์คือ `xl` (1280) **ไม่ใช่ `md`** — ที่ 768 การ์ดทั้งหมดเรียงลงมาตามลำดับ
ตรวจสุขภาพเพจ → สถานะ → วลี → แม่แบบ → ลองพิมพ์ → แชททดสอบ → เพจ → LINE → ร่างค้าง

### 1440px — 2 คอลัมน์ `xl:col-span-7` / `xl:col-span-3`

ซ้าย = ของที่ต้องอ่าน/พิมพ์ (วลี · แม่แบบ · ลองพิมพ์ · แชททดสอบ)
ขวา = ของที่ติ๊ก/อ้างอิง (เพจ · ข้อจำกัด LINE · ทางลัดไปดูร่าง · เวลาตรวจสิทธิ์ล่าสุด)

## คำที่ตัดสินแล้ว (ห้ามลอกของ Auto-Reply)

| สถานะ | คำ | คำอธิบายใต้แถบ |
|---|---|---|
| `OFFLINE` | ไม่ใช้งาน | ระบบจะไม่อ่านข้อความที่คุณพิมพ์เลย |
| `TEST` | ทดสอบ | อ่านเฉพาะห้องแชทที่เลือกไว้ และไม่สร้างออเดอร์จริง — ผลจะขึ้นเป็นร่างให้ดูเท่านั้น |
| `LIVE` | **สร้างออเดอร์จริง** | ทุกข้อความที่ตรงวลีจุดชนวนจะถูกอ่านเพื่อสร้างคำสั่งซื้อทันที (ตัดสต๊อกจริง) |

🛑 `LIVE` **ไม่ใช้คำว่า "ตอบลูกค้าจริง"** ของ Auto-Reply — สองฟีเจอร์ทำคนละอย่างสิ้นเชิง
(อันนั้นส่งข้อความหาลูกค้า อันนี้สร้างออเดอร์+ตัดสต๊อก) ลอกคำมาจะทำให้ผู้ขายคิดว่าเปิดสวิตช์นี้
แล้วลูกค้าจะได้รับข้อความ ซึ่งไม่จริงเลย

**Swal ก่อนเปิด LIVE:** หัวข้อ `ให้ระบบสร้างคำสั่งซื้ออัตโนมัติทุกครั้งที่คุณพิมพ์ตามรูปแบบ?`
· ปุ่มยืนยัน `สร้างออเดอร์จริง`

## สภาพที่ "เปิดอยู่แต่ไม่ทำงาน" — ต้องมีคนบอก

ระบบ **ไม่ auto-flip กลับเป็น OFFLINE โดยตั้งใจ** (ร้านถอดเพจ 5 นาทีเพื่อ re-auth แล้วต้องจำ
มาเปิดคืนเอง = magic write ที่ผู้ใช้ไม่ได้สั่ง) ⇒ หน้าจอต้องบอกแทน:

| สภาพ | ข้อความบนจอ |
|---|---|
| LIVE/TEST แต่ไม่ได้เลือกเพจเลย | `ยังไม่ได้เลือกเพจเลย — ตอนนี้ระบบจึงไม่อ่านข้อความจากที่ไหนเลยแม้สถานะจะเปิดอยู่` (danger-ink) |
| TEST แต่ไม่มีห้องทดสอบ | `อยู่ในโหมดทดสอบแต่ยังไม่ได้เลือกห้องแชทเลย — ตอนนี้จึงไม่อ่านข้อความจากที่ไหนเลย` |

## แม่แบบ — พิสูจน์แล้วว่าตัวแกะอ่านผ่าน

เนื้อในกล่องเทาคือ `AUTO_ORDER_TEMPLATE` ตัวจริง และมีเทส `[blocker]` 4 เคสยิงสตริงนี้เข้า

ไม่ตกร่างสักข้อ

🛑 **เทมเพลตที่ตัวเองอ่านไม่ผ่าน = happy path ของทั้งฟีเจอร์ไม่มีวันสำเร็จ** และผู้ขายจะโทษ
ตัวเองว่าพิมพ์ผิดทั้งที่พิมพ์ตามทุกตัวอักษร (เกิดจริงตอน A3 — สูตรเทียบยอดลืมหักส่วนลด)
