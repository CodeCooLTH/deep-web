### Section breakdown (prose)
**พระเอกของหน้า:** การ์ด ① (ส่วนต่างแชทรวม) กับกล่องเส้นประ "แอดที่ส่วนต่างสูงที่สุด" ในการ์ดนั้น เป็นคำตอบของคำถามที่ร้านถามบ่อยที่สุด (US-1). ② และ ③ คือชุดตัวเลขรองในรูปทรงเดียวกัน แต่เนื้อต่างชนิด (แถบเทียบ / แถบอัตรา / ตาราง) ไม่ใช่ตัวเลขใหญ่ซ้ำ 3 ใบ
**หัวหน้า (ไม่ห่อ `.card` ตามท่า `AdReportFilters`):**
- `DateRangeControl` เดิม ค่าใน URL `?from&to`
- `FilterDropdown` เลือกเพจ (ซ่อนเมื่อร้านมี ≤1 เพจ)
- ปุ่ม "ดูยอดขายตามโฆษณา" ไป `/reports/ads?from&to&shopChannelId` (พกช่วงและเพจ)
- บรรทัดช่วงวันที่ `text-xs text-default-700`
- บรรทัด "ข้อมูลจาก Meta อัปเดตเมื่อ HH:mm" ใช้ `formatDateTime` และแสดงเวลา `fetchedAt` ที่เก่าที่สุดของคำขอที่สำเร็จ ระหว่างดึงแสดง "กำลังดึงข้อมูลจาก Meta…"
- บรรทัดหมายเหตุเมื่อเข้าเงื่อนไข: ช่วงรวมวันนี้ / เลือกเพจ / ชื่อบัญชีโฆษณา
**① แชท (Meta) เทียบ แชท (Deep)** (FR-003 ช่องแชท, FR-004 ยอดรวม, F-02)
- วงกลมไอคอน `message-circle` พื้น `bg-primary`
- เลขหลัก = แชท (Deep) Σ ของแอดที่พบใน Insights
- ป้ายส่วนต่างรวมข้างเลข
- แถบเทียบ 2 แถว (`h-3 rounded`): Meta สี `bg-default-400`, Deep สี `bg-primary`, ความกว้างเทียบสัดส่วนกับค่าที่มากกว่า (ค่ากว้างไดนามิกเป็น `style={{width}}` แบบธีมเอง ไม่ใช่ arbitrary class)
- ข้อความ `text-2xs` บอกขอบเขต: "นับเฉพาะ {n} แอดที่พบใน Insights" และถ้ามีแอดตกหล่น "ไม่รวมแชท (Deep) {m} ห้องจากแอดที่ไม่พบใน Insights" (ตัวลบนับจากชุดเดียวกับตัวตั้ง)
- กล่องเส้นประ (กล่อง `border border-dashed border-default-300 rounded p-2.5` ของ `TotalSubscriber`) = แอดที่ส่วนต่างสูงที่สุดที่เข้าเกณฑ์ (≥20% และ Meta ≥20): `AdThumb size-12`, ชื่อ, "แชท (Meta) 88 · แชท (Deep) 51" และลิงก์ "ดูรายแอด" ไป `#ad-gap-table`
- ไม่มีแอดเข้าเกณฑ์: กล่องบอก "ไม่มีแอดที่ส่วนต่างถึง 20% (นับเฉพาะแอดที่แชท (Meta) ตั้งแต่ 20)" ใช้โทนกลาง
**② ปิดการขายจากแชทของแอด (Deep)** (F-05–F-09 ที่ระดับยอดรวม)
- วงกลมไอคอน `messages` พื้น `bg-info`
- เลขหลัก = ปิดการขาย (Deep) % พร้อมบรรทัด "{n} {noun} จาก แชท (Deep) {m}" (`{noun}` ผันตาม `resolveOrderVocab`)
- 4 แถวแถบอัตราแบบ `TotalSubscriber` สีต่างกัน: คุยต่อ ≥2 / คุยต่อ ≥3 / ตอบกลับ / บล็อกเพจ
- แต่ละแถวมีบรรทัดรอง "{k} จาก แชท (Meta) {N}"
- ค่า >100% แสดงตามจริงและบอกเหตุ แถบถูก clamp ที่ 100% (ภาพเท่านั้น)
**③ ค่าโฆษณา** (FR-003 ค่าโฆษณา, การแสดงผล, เข้าถึง, ความถี่, CTR, CPC, F-04/F-11)
- วงกลม `cash` พื้น `bg-dark`
- เลข ฿ + ป้ายโทนข้อมูล "฿32 ต่อแชท (Meta)"
- ใต้เลขเป็นตาราง `table-sm table-borderless` 3 คอลัมน์ (ตัวชี้วัด · ค่า · ที่มา) ที่มา = `Meta` / `Meta · ประมาณการ` / `Deep`
**④ ตำแหน่งแสดงแอดและกลุ่มผู้ชม** (FR-006 + FR-007 รวมเป็นการ์ดแท็บ)
- `card-header`: ชื่อ + ป้าย "ประมาณการ" + ตัวเลือกแอด (`input-icon-group` ไอคอน `speakerphone` + native `form-select form-select-sm`) แทนตำแหน่งปุ่ม Export/Import ของธีม
- แถบแท็บ 2 ช่อง (ท่า `SessionOverview`: วงกลมไอคอน `bg-info/15 text-info` + หัวข้อ + ค่า + ป้ายเล็ก, ขีดเส้นใต้ `border-primary` ที่ช่อง active)
  - แท็บ 1 "ต้นทุนต่อแชท (Meta) ต่ำสุด" ค่า `฿27` ป้าย "Facebook ฟีด" (นับเฉพาะแถวที่แชท (Meta) ≥20; ไม่มีแถวเข้าเกณฑ์ = "—")

  - ค่าในช่องแท็บเป็น insight ของแท็บนั้น ไม่ซ้ำตัวเลขรวมใน ①–③ (ผู้ใช้เห็นคำตอบทั้งสองก่อนกดสลับ)

  - คอลัมน์: ตำแหน่ง (ไอคอนแพลตฟอร์ม + ชื่อไทยตาม BR-AIQ-09) · ค่าโฆษณา · การแสดงผล · คลิก · แชท (Meta) · ต้นทุนต่อแชท (Meta) · สัดส่วนแชท (Meta) (แถบ + %)

### User flow
1. เปิด `/reports/ad-quality` (เจ้าของร้านเท่านั้น `F1`) → หัวและการ์ดฝั่ง Deep ขึ้นทันที การ์ดฝั่ง Meta เป็น skeleton แล้วทยอยขึ้นตามคำขอ Q1–Q4 ที่ขนานกัน
2. เปลี่ยนช่วงวันที่/เพจ → URL เปลี่ยน กริด `aria-busy` + `opacity-60` + `role=status` "กำลังคำนวณใหม่…" (ท่า sibling)
3. เลือกแอดที่ ④ → ?ad=… เฉพาะ ④ คำนวณใหม่ (Q3/Q4 ใหม่) การ์ดอื่นไม่เปลี่ยน
4. เห็นแอดติดป้ายใน ① → กด "ดูรายแอด" เลื่อนไป ⑤ → กด "ทำไมตัวเลขไม่เท่ากัน" เห็น 4 สาเหตุ
5. กด "ดูยอดขายตามโฆษณา" → `/reports/ads` พกช่วง/เพจ (ต้องเพิ่มลิงก์ตอบกลับใน `AdReportFilters` ของ `/reports/ads` ด้วย ไม่เพิ่มการเรียก Meta)
6. การ์ดล้ม → กด "ลองใหม่" ในการ์ดนั้น = ดึงใหม่ไม่ใช้แคช การ์ดที่ใช้คำขอเดียวกัน (Q1: ①②③⑤⑥) อัปเดตพร้อมกัน

### Impeccable compliance
- **Mode: Operate** ผู้ขายตรวจตัวเลขเพื่อตัดสินใจเพิ่ม/ลดงบทุกวัน สแกนง่ายและเหมือนหน้าพี่น้อง (`/reports/ads`) ชนะการแสดงออก; ความเป็น Deep อยู่ในรายละเอียด (ศัพท์ "แชท (Meta)/(Deep)", การไม่แสดง 0, ป้ายประมาณการ) ไม่ใช่การตกแต่ง
- **The One Voice Rule:** accent สีหลัก (`bg-primary`) ใช้ 4 จุด คือวงกลมไอคอน ①, แถบ Deep (①), แถบ "คุยต่อ ≥3" (②), เส้นใต้แท็บ active (④) กับปุ่มหลักในแบนเนอร์ ส่วนที่เหลือเป็นเทาและหมวดอื่น ภาพรวมจอไม่เกิน ~10%
- **Verified-Means-Green:** ไม่มีเขียวทั้งหน้า (ไม่ใช้ `bg-success`/`text-success`/`chart-alpha`) ส่วนต่างต่ำ, ต้นทุนต่อแชทต่ำสุด, อัตราตอบกลับ ไม่ใช่ "ยืนยันแล้ว"; แดงไม่ใช้เลยเพราะไม่มีความล้มเหลวของข้อมูล (การโหลดไม่สำเร็จเป็น warning ตามหน้าพี่น้อง)
- **Sentence-Case:** ไม่มี `uppercase` (ธีมใส่ที่ kicker และ `thead`; ตัดออกเพราะ "Meta" จะกลายเป็น "META" และขัดกฎ) ปุ่มเป็นกริยา+กรรม
- **Ink-tinted shadow:** ใช้ `.card` ของ Paces ตามธีม ไม่เพิ่มเงา
- **น้ำเสียง:** ทุกสถานะบอกทางออก ไม่ใช้ "ไม่สามารถ… ได้" อธิบายเหตุเป็นกลาง ไม่กล่าวหา ไม่ไฮป์
- **จุดที่ theme/user ขัดกับ Impeccable และการตัดสิน**
  1. *Kicker เล็กสีเทา + เลขใหญ่ + วงกลมไอคอนทึบ ≈ hero-metric template* (ใน `donts` และ craft-floor "Refuse"): **user สั่งโทนนี้ชัดเจนสำหรับหน้านี้** จึงทำตาม แต่ลดความเสี่ยงโดย (ก) kicker คือหัวข้อการ์ดจริง ไม่ใช่ eyebrow เหนือหัวข้ออื่น, ตัวเล็กพิมพ์ปกติ ไม่ uppercase, สีเข้มพอผ่าน contrast (`text-default-700` ไม่ใช่ `text-default-400` ของธีมที่ตก AA), (ข) แต่ละใบเนื้อต่างชนิด ไม่ใช่ตัวเลขซ้ำสามใบ, (ค) `text-[13px]` ของธีมเปลี่ยนเป็น `text-sm` ไม่ใช่ arbitrary. **ให้ Controller เพ่งข้อนี้ตอนรัน `/impeccable critique`**
  2. *ป้าย ▲ เขียว / ▼ แดง:* user อยากได้ แต่หน้านี้ไม่มีช่วงก่อนหน้า (BRD ไม่มีการเทียบ) และเขียว/แดงผิดความหมาย จึงคงรูปทรงป้าย (`badge text-sm py-0` + พื้นอ่อน) แต่เปลี่ยนสีตามความหมายจริง (ตารางด้านบน)
  3. *`CountUp` ของธีม* = choreography ตอนโหลด ผิด `donts` ตัดทิ้ง (เหมือนที่ sibling ตัด)
  4. *สีฟ้า/ชมพูตามเพศ* ห้ามตาม BRD FR-007
  5. *BRD FR-001 บรรทัดสถานะการเชื่อม* ให้การ์ด Meta เป็นสถานะว่าง แต่ 4 การ์ดว่างเหมือนกัน = slop และซ้ำแบนเนอร์ → spec นี้ซ่อนแทน (ดู O1)
- **จุดเสี่ยงให้ critique:** (ก) kicker/hero-metric ข้างต้น (ข) `chart-zeta` ส้ม (#db9052) คอนทราสต์เส้น/แท่ง ~2.6:1 กับพื้นขาว — แก้ด้วยค่าตัวเลขในตาราง/tooltip ทุกครั้งไม่พึ่งสีอย่างเดียว (ค) แถบแท็บ 2 ช่องกว้างเต็มการ์ดที่ 1440 อาจดูโล่ (ง) ตาราง ⑥ 9 คอลัมน์ที่ 768
- **ไม่มีค่าดิบ:** ทั้งสเปกใช้ primitive ของ Paces (`text-xs/sm/lg/xl`, `bg-{semantic}/15`, `size-9`, `size-12`, `h-1.25`, `gap-base`) ความกว้างแถบเป็น `style={{width}}` แบบธีมเอง
### Design decisions + rationale
- **D1 หน้าแยกตาม §11** ไม่มีแท็บบน `/reports/ads` และ `/reports/ads` ไม่เรียก Meta เพิ่ม
- **D2 โครงตามภาพที่ user ส่ง:** แถวบน 3 ใบ → ใบกว้างที่มีแท็บ → ตาราง (ธีม `analytics/page.tsx`) แต่ย้ายตารางรายแอดไว้ล่างเต็มแถว เพราะข้อมูล 9–11 คอลัมน์ไม่พอใน 3/4 คอลัมน์
- **D3 ใช้แท็บ 2 ช่องให้เป็นแท็บจริง:** ธีมมีแถบแท็บที่สลับกราฟรายวัน แต่หน้านี้ไม่มีข้อมูลรายวัน (นอก v1) จึงให้แท็บสลับ "ตำแหน่ง ↔ อายุ/เพศ" และให้ค่าในช่องเป็น insight ของแท็บนั้น (ไม่ซ้ำตัวเลขรวมใน ①–③) ผลคือตัวเลือกแอดอยู่ที่หัวการ์ดเดียว ครอบคลุมทั้งสองแผง
- **D4 ① เป็นพระเอก:** เป็นคำตอบของ US-1 และมีกล่องเส้นประของธีมช่วยเติมความสูงให้พอกับ ② ③ (ไม่มีพื้นที่ว่างที่ 1440)

### Anti-slop self-check
1. **เฉพาะ Deep หรือไม่:** ใช่ เพราะคู่ "แชท (Meta) / แชท (Deep)" ที่แยกแหล่งตลอดหน้า, ป้ายประมาณการ, หมายเหตุว่าทำไมไม่มียอดขายตามตำแหน่ง, 4 สาเหตุที่แชทไม่ตรงกัน (Meta AI รับเธรด / webhook หลุด) ใช้กับสินค้าอื่นไม่ได้ ส่วนความเป็น "template" ของโทนการ์ดเป็นคำสั่ง user ที่บันทึกไว้ใน compliance ข้อ 1
2. **สิ่งเด่นสุด:** การ์ด ① และกล่องเส้นประแอดที่ส่วนต่างสูงที่สุด (เลขหลัก + วงกลมสี + ป้าย) ส่วน ② ③ น้ำหนักรอง ④⑤⑥ เป็นตารางหนาแน่น
3. **ข้อมูลซ้ำ/คงที่ที่ตัดแล้ว:** ตัดกราฟรายวัน ตัดค่า "ค่าโฆษณา" ออกจากแถบแท็บ (อยู่ที่ ③) ไม่ทำตาราง "แอดส่วนต่างสูง" ซ้ำ ⑤ (เหลือกล่อง 1 แถวใน ①) ตัด `CountUp`/Export/Import/medal/"Congratulations" และไม่มี delta ▲▼ ที่ไม่มีช่วงก่อนหน้ารองรับ
4. **ครบ state:** loading / มีข้อมูล / ว่าง / Meta ไม่ส่ง / ล้ม+ลองใหม่ ต่อการ์ด; สถานะการเชื่อม 4 แบบ; แอดไม่พบ/ไม่มี action/ส่วนต่างติดลบ/Meta<20; "—" แยกจาก 0; ชื่อยาว; ตัวเลขหลักล้านและ >100%; ไม่ได้ครอบ "เลือกแอดเดียวไม่มีแถว" แยกเป็นภาพ แต่ใช้ข้อความ "ไม่มีข้อมูลจาก Meta ในช่วงนี้" + "หรือเลือกทุกแอด"
5. **Copy ตรงกับสิ่งที่ทำได้จริง:** ปุ่ม "ลองใหม่" มีเฉพาะสถานะที่ดึงใหม่ได้จริง; "เชื่อมบัญชีโฆษณา" ไปหน้าเชื่อมจริง; ไม่แนะนำให้กดสิ่งที่ไม่มีในสถานะนั้น (ในสถานะไม่เชื่อมมีแต่ปุ่มเชื่อม); ข้อความสาเหตุบอกว่า "อาจ" ไม่ชี้ตัวต่อแอด
6. **คำเดียว = ของเดียว:** "แชท (Meta)" = `…conversation_started_7d` ที่ Meta นับ, "แชท (Deep)" = `conversationId` ไม่ซ้ำจาก `ConversationAdReferral` (นิยาม FR-008 ของ 00091); "ประมาณการ" = ค่าที่ Meta ระบุว่าเป็นค่าประมาณเท่านั้น; "ปิดการขาย" ผูกกับ แชท (Deep) ส่วน "คุยต่อ/ตอบกลับ/บล็อก" ผูกกับ แชท (Meta) และเขียนตัวหารกำกับทุกที่
7. **สีสื่อความถูก:** ไม่มีเขียว ไม่มีแดง; ส่วนต่างสูง = warning; ส่วนต่างปกติ/ติดลบ = เทา; ประมาณการ = info; Meta = เทา, Deep = น้ำเงิน ทุกการ์ดที่เปรียบเทียบสองฝั่งใช้ชุดเดียว
