ChatNavRail — แถบเมนูหน้าแชท

เอาเมาส์ไปวางบนแถบซ้ายของกรอบด้านล่างเพื่อดูการกางออก — คอลัมน์แชทต้องไม่ขยับแม้แต่พิกเซลเดียว แถบจะลอยทับ · หัวแชท (โลโก้/ช่องค้นหา) อยู่บนสุดพาดเต็มความกว้าง แถบไม่ไปบัง

⚠ ม็อกอัพนี้ก็อปกฎ CSS จริงมาไว้ในไฟล์ (ไม่ได้ลิงก์ dev server) เพราะกฎ .chat-nav-rail เพิ่งเขียนใหม่ — ถ้าดึงสดจาก server ที่รันคนละ branch จะไม่มีกฎพวกนี้เลย ⇒ ต่างจากของจริงจุดเดียวคือ position:absolute แทน fixed เพื่อให้อยู่ในกรอบจำลองได้ 2 กรอบพร้อมกัน
