## 2. สิ่งที่ยึดจากของจริง (ไม่ได้วาดตามใจ)

## 3. กติกาด้านดีไซน์ที่จอนี้ต้องรักษา

- **เขียวมีจุดเดียว** — “ลูกค้าเห็นเมนูนี้อยู่” เท่านั้น (Verified-Means-Green: เขียว = ยืนยันแล้วว่า
  ทำงานจริง) “สร้างไว้แล้ว ยังไม่เปิดใช้” ใช้ฟ้าเพราะยังไม่ live
- 🛑 **“ไม่ได้ใช้เมนูของ Deep” ห้ามเขียนว่า “ร้านนี้ไม่มีเมนู”** — เรามองไม่เห็นเมนูที่ร้านตั้งเองใน
  LINE OA Manager (แพลตฟอร์มไม่เปิด API ให้ตรวจ) การเขียนว่าไม่มีคือการโกหกที่ทำให้ร้านตัดสินใจผิด
- 🛑 **จอยินยอมต้องมีครบ 3 ประโยค**: ระบุชื่อเพจจริง · บอกว่า **ระบบตรวจไม่ได้** ว่ามีเมนูเดิมอยู่ไหม ·
  บอกว่าฝั่ง OA Manager จะยังโชว์ของเดิมว่า “ใช้งานอยู่” ซึ่งเป็นเรื่องปกติ — ข้อสุดท้ายคือสิ่งที่กัน
  ไม่ให้ร้านคิดว่า Deep ทำ LINE ของเขาพัง
- **ไม่ล็อก desktop-only** ต่างจากตัวจัดหน้าร้าน 00035 — รอบนี้ไม่มี drag-drop และผู้ขายจำนวนมาก
  ทำงานบนมือถือ (BRD §6.5)
- **ปุ่ม “บันทึกร่าง” ไม่ยิงไป LINE** — เพดานสร้างเมนู 100 ครั้ง/ชม. การบันทึกทุกครั้งที่พิมพ์แก้จะ
  เผาเพดานหมดตั้งแต่ยังไม่เสร็จ

## 4. สิ่งที่จอนี้ยัง **ทำไม่ได้** (ตั้งใจ ไม่ใช่ตกหล่น)

- เพิ่ม/ลบ/สลับตำแหน่งปุ่ม และเปลี่ยนว่าปุ่มไหนทำอะไร — ล็อกไว้เพื่อกันปุ่มที่กดแล้วไม่มีอะไรเกิดขึ้น
  (BR-RM-03) ร้านแก้ได้แค่ **คำ**
- อัปโหลดภาพเมนูของร้านเอง — มติ D-RM-2 รอบแรกใช้เทมเพลตอย่างเดียว
- ไอคอนบนภาพเมนู — user เคาะให้เป็นข้อความล้วนใน v1 (โปรเจกต์ยังไม่เคยวาด SVG ลง canvas
  การดึง path ของ tabler มาวาดเพิ่มจุดล้มเหลวใหม่บนเส้นทางที่มี font timing เป็นความเสี่ยงอยู่แล้ว)
- ⚠️ ป้าย “ตอบสถานะพัสดุอัตโนมัติ” ใต้ช่องกรอกอธิบายพฤติกรรมที่ **ยังไม่ทำงาน** — ตัวส่งเขียนเสร็จแล้ว
  แต่ยังไม่ต่อ webhook (รอสาขา “DeepMenu” ในป้ายบับเบิลก่อน ไม่งั้นข้อความที่ระบบตอบจะขึ้นชิป
  “DeepBot” พร้อมแถวเงื่อนไข “ไม่เจาะจง” ซึ่งโกหกผู้ขายสองชั้น)

## 5. หมายเหตุเรื่อง impeccable hook

hook รายงาน 15 finding เรื่อง `design-system-font-size` / `design-system-radius` ในไฟล์ HTML —
**ยังไม่แก้และยังไม่ปิดเสียง** เพราะไฟล์นี้เป็น **mockup เดี่ยวที่ต้องเปิดได้โดยไม่มี CSS ของแอป**
จึงเขียนค่าเป็น literal เพื่อ *เลียนแบบ* ขนาดที่ Paces เรนเดอร์ออกมาจริง (14px = `text-sm`,
12px = `text-xs`) ไม่ใช่การเสนอค่าใหม่เข้า design system

ถ้าเห็นด้วยว่าเป็น false positive ให้สั่งปิดเฉพาะไฟล์นี้:

```
/impeccable hooks ignore-file "docs/superpowers/specs/2026-08-11-line-rich-menu-editor-mockup.html"
```
