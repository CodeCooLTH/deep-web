หัวห้องแชท — ออกแบบใหม่ให้ compact

user แจ้ง 2026-08-07: “ไม่ค่อยสวย ไม่ compact เปลืองพื้นที่มาก” · ทุกค่าในหน้านี้คัดจากคลาสจริงและ token ของ Paces (.card-header = py-3.75, .btn.btn-icon = size-9.25 37px, ChatAvatar = size-9 36px) ไม่ได้กะเอา

source: src/app/(paces)/seller/(chat)/inbox/[conversationId]/components/ChatThread.tsx (commit eba494ea) · Design Spec โดย safepay-ux

ตัวการที่ทำให้หัวสูงคืออะไร

  • ปุ่มในแถวสูง 37px · avatar 36px — ทั้งคู่ไม่ใช่ตัวปัญหา
  • กล่องชื่อถูกวางเป็น 2 บรรทัดซ้อนกัน: ชื่อ 24px + mb-1.25 5px + ชิปเพจ 20px = 49px ← ตัวนี้ดันความสูงทั้งแถว
  • บวก padding py-3.75 อีก 30px → 79px
  • แปลว่า ถ้าเอาชื่อกับชิปมาอยู่บรรทัดเดียวกัน ความสูงจะตกไปอยู่ที่ปุ่ม (37px) ทันที โดยไม่ต้องลดขนาดอะไรเลย

ตอนนี้ 79px

ชื่อกับชิปเพจซ้อนกัน 2 บรรทัด — ชิปกินความสูงเต็มบรรทัดของตัวเองทั้งที่มีข้อความสั้น ๆ

แบบ A — ชื่อกับชิปอยู่บรรทัดเดียว 67px · −12px

เปลี่ยนอย่างเดียว: เลิกซ้อน 2 บรรทัด · ไม่แตะ padding ของ .card-header จึงยังเท่าหัวการ์ดอื่นทั้งแอปเป๊ะ ๆ ปลอดภัยที่สุด

แบบ B — A + ลด padding เป็น py-3 61px · −18px (ux แนะนำ)

เหมือน A แต่บีบระยะบน-ล่างจาก 15px เหลือ 12px — มีที่ใช้จริงในโปรเจกต์แล้ว (LibraryPanel.tsx) แลกกับการที่หัวห้องแชทจะบางกว่าหัวการ์ดอื่นในแอปเล็กน้อย

แบบ C — ย้ายตราเพจไปติดมุมรูป ตัดชิปข้อความออก 61px · แถวโล่งสุด · ต้อง QA เพิ่ม

ความสูงเท่า B แต่ แถวสะอาดกว่ามาก — ชื่อลูกค้าเหลือเป็นของชิ้นเดียวบนหัวห้อง ตราเพจไปเกาะมุมรูปแบบเดียวกับในรายการแชท ชื่อเพจเต็มยังอ่านได้จากการชี้ที่รูปและในแผงข้อมูลลูกค้า

ข้อควรระวังที่บันทึกไว้ในโค้ด

  • 2026-08-02 เคยลองใส่ตราช่องทางซ้อนบน avatar ที่หัวเธรด แล้ว user รายงานว่า “ทำไม icon เพจมันซ้อนกัน” เพราะตอนนั้นมีทั้งตราบนรูปและชิปพร้อมกัน — แบบ C ตัดชิปออก จึงไม่ใช่เงื่อนไขเดิม แต่ยังต้องดูจริงก่อนตัดสิน
  • ร้านที่มีหลายเพจจะแยกเพจด้วย “รูปเล็ก 16px” แทนการอ่านชื่อ — ถ้าเพจใช้โลโก้คล้ายกันจะแยกยากขึ้น

เคสที่ต้องดูก่อนเคาะ — ตัวนับ 24 ชม. โผล่พร้อมชื่อยาว (390px)
