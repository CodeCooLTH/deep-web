Order Detail — สิ่งที่ปรับเพิ่มได้

ทุกอย่างในหน้านี้ใช้ ข้อมูลที่ระบบมีอยู่จริงแล้ว ไม่มีของแต่ง — ตารางท้ายหน้าบอกว่าแต่ละชิ้นมาจากคอลัมน์ไหน สีจาก token จริงของ Paces ฟอนต์ Anuphan

ข้อ 1 ไม่ใช่ของใหม่ — เป็นของที่ผมทำหายตอนรื้อหน้าเป็นโครงธีมเมื่อกี้
การ์ด "การจัดส่ง" เดิมอยู่ใน OrderFactsCard ที่ผมลบทิ้ง ตอนนี้ เลขพัสดุกับชื่อขนส่งไม่ปรากฏบนหน้าจอเลย (ยืนยันด้วย grep: ไม่มีการ์ดไหนใน 5 ใบ render trackingNo) — ออเดอร์ที่ส่งของแล้วจะดูเลขพัสดุไม่ได้ ผมไม่เห็นตอนเปิด production เพราะใบที่เปิดดูยังไม่มีเลขพัสดุ

7 ข้อมูลแต่ละชิ้นมาจากไหน

ไม่มีแถวไหนเป็นของแต่ง — ถ้าคอลัมน์ไหนไม่มีข้อมูลจริง ผมไม่ใส่ลงใน mockup ตั้งแต่แรก

สิ่งที่เพิ่มมีข้อมูลไหมมาจากไหน
โลโก้ขนส่งมีsrc/lib/iship/courier.ts — 9 แบรนด์ ไฟล์อยู่ใน public/images/logos/ แล้ว
เลขพัสดุ + ชื่อขนส่งมีOrderShipment (iShip) หรือ ShipmentTracking (ร้านแจ้งเอง) — หน้านี้คำนวณไว้แล้วในชื่อ shippingInfo แต่ไม่ได้ render
แถบ 4 ขั้นของขนส่งมีSHIPMENT_STAGES + describeProgress() ใน lib/iship/status.ts
ไทม์ไลน์การเดินทางมีตาราง ShipmentEvent — บน prod มีจริงแล้ว (พัสดุ Flash Thunder 12 เหตุการณ์)
ลิงก์หน้าติดตามของขนส่งยังไม่มีต้องทำ URL ต่อแบรนด์เอง — ถ้าไม่อยากทำ ตัดปุ่มนี้ออกได้
หมายเหตุภายในร้านมีOrder.internalNote — เขียนได้ตอนสร้างออเดอร์ แต่ไม่เคยแสดงที่ไหนเลย
QR ของลิงก์ผู้ซื้อมีOrder.shortCode + ปุ่ม QR ที่หน้ารายการออเดอร์ใช้อยู่แล้ว
ทักแชทมีOrder.customerId → Conversation ของลูกค้ารายนั้น
ยอดเก็บปลายทาง + ปุ่มได้รับเงินมีOrder.totalAmount + codReceivedAt + API ที่ทำไปเมื่อวาน
ลิงก์ไปหน้าลูกค้ามี/customers/[id] (feature 00014)
ช่องทางที่ลูกค้ามาจากมีOrder.salesChannel
