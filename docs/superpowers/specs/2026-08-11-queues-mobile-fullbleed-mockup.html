C · แท็บเล็ต 834px 🛑 หน้านี้ใช้จอเดียวกับมือถือจนถึง 1023px

ทำไมแท็บเล็ตไม่เต็มขอบ

  • คลาสที่ใช้คือ -mx-4 md:mx-auto md:max-w-2xl — เต็มขอบเฉพาะต่ำกว่า 768px ตั้งแต่ 768px ขึ้นไปการ์ดกลับมาอยู่กลางจอกว้าง 672px เหมือน /orders และ /products
  • ถ้าปล่อยเต็มขอบบนแท็บเล็ต ปฏิทินจะกว้าง 834px ช่องวันกลายเป็น ~115px ต่อช่องเพื่อใส่เลขตัวเดียว — กว้างจนสายตากวาดหาวันลำบาก
  • แถบล่างหายบนแท็บเล็ตด้วย (ซ่อนตาม path ไม่ได้ซ่อนตามความกว้าง) และปุ่มในแถบถูกจำกัดกว้าง 672px ให้ตรงแนวกับการ์ด ไม่ยืดเต็ม 834px
  • เดสก์ท็อป ตั้งแต่ 1024px ขึ้นไปเป็นคนละหน้าจอกันเลย (AppointmentCalendar ตารางเดือนเต็มที่มีชื่อผู้จองในช่องวัน) รอบนี้ไม่แตะ
