หัวโปรไฟล์ — 3 ทางเลือก

ทั้งสามเลิกใช้การวางชื่อซ้ายคู่รูปขวาแบบต้นแบบ และจัดการมุมใหม่หมด ไม่มีแผ่นขาวมุมโค้งเสียบทับแถบสีจนเกิดรอยบากอีกแล้ว เนื้อหาส่วนล่างเหมือนกันทั้งสามเพื่อให้เทียบเฉพาะหัว

ทาง A

ทาง C

กลางหน้า สมมาตร

โลโก้วงกลมอยู่กึ่งกลาง ชื่อและป้ายเรียงลงมาเป็นแกนกลาง ต่างจากต้นแบบชัดเจนที่สุดเพราะเปลี่ยนแกนการอ่านจากซ้าย-ขวาเป็นบน-ล่าง ให้ความรู้สึกเป็นหน้าแนะนำตัวมากกว่าหน้ารายการ

เรื่องมุมโค้งที่ไม่ชอบ แก้อย่างไรในแต่ละแบบ

  • ต้นเหตุเดิม — แผ่นขาวมุมโค้งด้านบนถูกดึงขึ้นไปทับแถบสี ทำให้เกิดรอยบากสองข้างที่อ่านเป็นความบังเอิญมากกว่าการออกแบบ
  • ทาง A ตัดปัญหาทิ้งทั้งหมด เพราะไม่มีแผ่นขาวมาคั่น เนื้อหาอยู่บนภาพตรง ๆ แล้วไล่ระดับความมืดรับกับพื้นขาวด้านล่าง
  • ทาง B เปลี่ยนแผ่นที่ถูกเฉือนให้กลายเป็นการ์ดลอยที่มีมุมครบสี่ด้านและมีเงา สายตาจึงอ่านว่าเป็นวัตถุที่ตั้งใจวาง
  • ทาง C ให้แถบสีจบด้วยขอบตรง แล้วใช้โลโก้วงกลมเป็นตัวคร่อมรอยต่อแทนมุมโค้ง
  • ผมแนะนำ B เพราะแก้ตรงสิ่งที่คุณไม่ชอบโดยตรง ไม่พึ่งรูปปกที่ร้านส่วนใหญ่ยังไม่มี และวางโปรไฟล์ต่างจากต้นแบบชัดเจน ส่วน A เก็บไว้ได้ถ้าอยากให้เข้าชุดกับหน้าลิงก์คำสั่งซื้อเป็นหลัก
