## กลไก 3 อย่างที่ต้องเข้าใจก่อนแก้ไฟล์นี้

**1. ทำไมคอลัมน์แชทไม่ขยับตอนกาง**
rail เป็น `fixed` โตได้ถึง 245px แต่โซนใต้หัวแชท (`.chat-body`) กันที่ไว้ **`--sidenav-width-sm` (75px) คงที่**
⇒ 170px ที่โผล่มาคือการลอยทับล้วน ๆ · 🛑 เปลี่ยนโทเคนนั้นเป็น `--sidenav-width` เมื่อไหร่ คอลัมน์แชท
จะกระโดด 170px ทุกครั้งที่เมาส์ผ่าน rail = พฤติกรรมที่ user ห้ามไว้ตรง ๆ (มีเทส `[blocker]` กันไว้)

**2. ทำไมต้องใช้คลาสของตัวเอง ห้ามใช้ `.app-menu`**
`(paces)/layout.tsx` ตั้ง `data-sidenav-size="on-hover-active"` ไว้เป็นค่า default ของทั้งแอป
⇒ กฎ global ของโหมดนั้นจะจับ `.app-menu` ทันทีแล้วบังคับกางค้าง 245px ตลอดเวลา
เหตุผลเดียวกันกับ `data-menu-color` — override โทเคนสีเฉพาะใต้ `.chat-nav-rail` ห้ามสลับที่ `<html>`
(sidenav ของหน้า seller อื่นทุกหน้าใช้ค่าเดียวกันนี้ร่วมกัน)

**3. ทำไมเมนูมาจาก `resolveSellerMenuItems` เท่านั้น**
ตอนนี้มี layout สองตัวที่ต้องมีเมนู (`(dashboard)` กับ `(chat)`) — ก็อปลำดับตัวกรองไปวางอีกที่
= permission drift ที่ `seller-menu.ts` เตือนไว้เองว่าเป็นความเสี่ยงอันดับ 1 และไม่มี gate ไหนจับได้
(ทั้งสองชุด "ถูก" ในตัวเอง) ⇒ SSOT อยู่ที่ `src/lib/seller-menu-server.ts` (มีเทส `[blocker]` กันไว้)

## 3 จุดที่ตั้งใจทำต่างจากธีมต้นแบบ

| จุด | ธีมทำ | เราทำ | เพราะ |
|---|---|---|---|
| `.menu-text` ตอนหุบ | `display:none` | คลิป (`clip-path`) | `display:none` ลบชื่อออกจาก accessibility tree ⇒ ได้ลิงก์ 22 ตัวที่ screen reader อ่านไม่ออกเลย (ไอคอนเป็น svg `aria-hidden`) |
| `.menu-title` ตอนหุบ | `display:none` | ยุบสูงเป็นเส้นคั่น | ซ่อนหัวข้อกลุ่มพาระยะห่างหายไปด้วย ⇒ ไอคอนกองเป็นพืดเดียว (อาการที่ user รายงาน) |
| `.badge` ตอนหุบ | `display:none` | จุดมุมไอคอน | ซ่อนทิ้ง = "มีข้อความใหม่" เงียบสนิทในสถานะที่ผู้ใช้เห็นบ่อยที่สุด |

เพิ่มจากธีม: แถบชี้ตำแหน่ง 3px ที่เมนู active (พื้นกล่องอย่างเดียวหาไม่เจอเมื่อไอคอนเรียงเป็นแถวเดียว) ·
`min-height: 44px` (ธีมให้ ~37–41px ต่ำกว่าเกณฑ์ที่ `PRODUCT.md` ประกาศไว้เอง) · เฟดขอบบน/ล่างบอกว่ายังมีเมนูต่อ

| 1280 | 75 | 384 | **437** | 384 |

**เมนูยาวเกินจอ** — 22 รายการ × 44px + เส้นคั่น 4 เส้น ≈ 1,050px ขณะที่ rail มี `ความสูงจอ − 65px`

## หนี้ที่ยังเปิด

- 🛑 **ถอด pin แล้ว ⇒ ทัชบนจอ ≥1024 กางค้างไม่ได้อีกเลย** (ไม่มี `:hover` ที่เสถียรบนทัช)
  คีย์บอร์ดยังกางได้ด้วย `:focus-within` — user รับทราบและสั่งถอดเอง
- **ยังไม่ผ่าน Impeccable CLI gate (HR8)** — เวิร์กทรีที่ทำงานไม่มี `.env` รันเซิร์ฟเวอร์ไม่ได้
- **แถบแท็บ ข้อความ|ความคิดเห็น ขยับไปเริ่มที่ x=75** — เป็นผลตามโครงสร้างของคำสั่งข้อ 4
  ต่างจากมติเดิมของ user เมื่อ 2026-08-04 (*"ชอบแบบพาดเต็มความกว้าง"* — ตอนนั้นยังไม่มี rail)
- ยังไม่ sync เอกสาร feature 00018/00037
