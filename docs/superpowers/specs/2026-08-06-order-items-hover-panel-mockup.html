Mockup — หน้า orders: toolbar ใหม่ + ตัวกรองพัสดุ + hover panel รายการสินค้า (Paces จริง)

ตาราง/ปุ่ม/dropdown = markup + CSS จริงของธีม (compile จาก custom/_table.css _buttons.css _forms.css _badge.css _card.css) · 3 เรื่องในชุดเดียว: ① redesign แถบค้นหา/กรอง ② ย้ายแถบ "พัสดุ: …" มาเป็นตัวกรองในแถวเดียวกัน ③ hover คอลัมน์สินค้า → panel รายการสินค้า

จุดที่ 1 — toolbar ใหม่ (รวมตัวกรองพัสดุเข้ามา)

ก่อน: แถบ "พัสดุ: รอเลขพัสดุ · รอรับเข้า 14 · …" ลอยอยู่ใต้การ์ดสถิติ + toolbar มีคำว่า "กรอง:" ลอย ๆ กับ dropdown "10" ที่เดาไม่ออกว่าคืออะไร
หลัง: ทุกตัวกรองรวมในแถวเดียว: ค้นหา (ซ้าย, กว้างขึ้น) · สถานะ · พัสดุ (ใหม่ — ตัวเลือกพร้อมจำนวน) · ช่วงเวลา · แถวละ N · ปุ่มสร้างขวาสุด — ตัดคำว่า "กรอง:" ทิ้ง (ปุ่มมี icon+ชื่อครบ ไม่ต้องมีป้ายบอกอีกชั้น)

DESKTOP toolbar ใหม่ — ตัวกรองพัสดุกำลังกางอยู่ (มุมมองปกติ)
( ตาราง — ดูจุดที่ 2 )

ตัวกรองที่ active = ปุ่มติดสี border-primary bg-primary/10 text-primary + โชว์ค่าที่เลือกบนปุ่ม ("พัสดุ: กำลังจัดส่ง") · จำนวนต่อตัวเลือกย้ายจากแถบเดิมมาอยู่ใน dropdown (สีตามความหมาย: รอเลข=warning, COD=info, มีปัญหา=danger) — แถบลอยใต้การ์ดสถิติถูกถอดทิ้ง · เส้นคั่นบาง ๆ ก่อนปุ่มสร้าง แยก "ตัวกรอง" ออกจาก "action" · "แถวละ 10" แทน "10" เปล่า ๆ

จุดที่ 2 — ตารางจริง + hover คอลัมน์สินค้า → panel รายการสินค้า

panel เปิดขึ้นบนจาก cell สินค้า (ตัวจริง absolute + group-hover กลไกเดียวกับ panel ของ mini timeline) — เฟรมนี้วาง panel ลอยเหนือตารางพร้อมลูกศรชี้จุดยึด · cell สินค้าเดิมไม่เปลี่ยน (ชื่อสินค้าแรก + "+N รายการ")
