สรุปตรง ๆ

ปัญหาหลักคือความยาวชื่อเพจ ไม่ใช่ตำแหน่ง — ชื่อเพจจริงของ BT ยาว 30-38 ตัวอักษร พอเอาไปวางฝั่งขวาซึ่งต้องแบ่งที่กับชื่อลูกค้าในบรรทัดเดียวกัน มันจะถูกตัดจนไม่รู้ว่าสาขาไหน ซึ่งคือข้อมูลที่เราอยากได้พอดี

ข้อดีจริงของแบบ E2 คือ ไม่เพิ่มความสูงแถว (เห็นเธรดต่อจอมากกว่าแบบ C หนึ่งแถว) และ บนเดสก์ท็อปมันทำงานได้ดีจริง เพราะ rail กว้างพอให้ชิปกางเต็ม

ทางที่ได้ทั้งสองอย่าง: ใช้ E2 บนจอ ≥768px (ชิปขวาบน ไม่เปลืองความสูง) และ ถอยเป็นแบบ C บนมือถือ (บรรทัดล่างเต็มความกว้าง อ่านชื่อเพจครบ) — เป็นข้อมูลชุดเดียวกัน แค่จัดวางต่างกันตามที่ว่างจริง ซึ่งเป็นสิ่งที่ responsive ควรทำอยู่แล้ว
