## 🛑 เปลี่ยนทิศทาง: เลิกใช้กราฟเส้น → แท่งซ้อน (user สั่ง 2026-08-29)

หลังดูม็อกอัพกราฟเส้นที่ปรับแล้ว user ตัดสินว่า **"ไม่เอากราฟเส้น เอา bar chart ดีกว่า stacked"**

### ทำไมมันแก้ปัญหาได้จริง ไม่ใช่แค่เปลี่ยนรูปทรง

กราฟเส้นให้เส้น 3–6 เส้นวิ่งทับกันในแถบค่า 0–6 ที่แคบมาก — **ไม่ว่าจะแต่งสี ลดจุด หรือลดจำนวนเส้น
อย่างไร เส้นก็ยังตัดกันอยู่ดี** เพราะปัญหาอยู่ที่รูปแบบกราฟเอง ไม่ใช่พารามิเตอร์ของมัน

แท่งซ้อนมี **1 แท่งต่อ 1 วัน** แต่ละแท่งแบ่งเป็นช่วงสีตามสินค้า ⇒
- ไม่มีอะไรตัดกันเลยโดยโครงสร้าง
- ได้ข้อมูลเพิ่มมาฟรี: **ความสูงรวมของแท่ง = ยอดขายรวมของวันนั้น** ซึ่งกราฟเส้นตอบไม่ได้
- คำถามหลักของหน้า ("ขายช่วงไหนของเดือน") อ่านจากรูปร่างของแถวแท่งได้ทันที

### มีแบบอย่างในระบบอยู่แล้ว — ไม่ต้องประดิษฐ์

หน้า "ภาพรวมกำไร/ขาดทุน" (`sales/components/SalesChart.tsx`) ใช้แท่งซ้อนรายวันแบบนี้อยู่แล้ว
และ cite Base ไปที่ `SalesChartSheet.tsx::buildSalesChartOptions` ⇒ ยกโครงมาได้ตรง ๆ ตาม HR10:

```
chart:       { type: 'bar', stacked: true, toolbar: { show: false } }
plotOptions: { bar: { columnWidth: '55%', borderRadius: 3 } }
xaxis:       { tickAmount: 10, labels: { hideOverlappingLabels: true } }
grid:        { strokeDashArray: 4 }
```

`hideOverlappingLabels` ยังแทนที่ตัวคัดป้ายแกน X ที่ผมเขียนเองด้วย — **และนั่นคือตัวที่ทำให้
annotation พังก่อนหน้านี้** (formatter คืนค่าว่างจน Apex หา category ไม่เจอ) ⇒ ตัดสาเหตุนั้นทิ้งไปเลย

### สิ่งที่ยังเก็บไว้จากรอบก่อน

| เก็บ | เหตุผล |
|---|---|
| ลำดับสีใหม่ (ฟ้าอ่อนเป็นสีสำรอง) | ช่วงสีในแท่งซ้อนอยู่ติดกันโดยตรง ยิ่งต้องแยกออกจากกันชัด |
| ตัด `chart-gamma` (เหลือง) | `--color-chart-gamma` = `--color-warning` = `#f9bf59` **เหมือนกันเป๊ะ** ⇒ ช่วงสีเหลืองในแท่งจะอ่านปนกับป้าย "เงียบมาแล้ว" |
| เส้นตั้งต้น 3 (เพดาน 6) | 3 ช่วงสีต่อแท่งอ่านง่าย · 6 ช่วงเริ่มเป็นสลิ่วบาง ๆ — แต่แท่งซ้อนทนได้ดีกว่าเส้นมาก ถ้าอยากกลับไป 5 บอกได้ |
| รูปใน tooltip + วงแหวนสีในตาราง | โยงตาราง↔กราฟโดยไม่ต้องจำสี · **ยิ่งเข้ากับแท่งซ้อน** เพราะช่วงสีเป็นบล็อกทึบ เทียบกับวงแหวนง่ายกว่าเส้นบาง ๆ |
| แกน Y จำนวนเต็ม | ยอดรวมของวันก็ยังเป็นจำนวนชิ้น ห้ามมี tick ครึ่งชิ้น |

### สิ่งที่ไม่ต้องใช้แล้ว

`markers.discrete` (จุดบนเส้น) · `dashArray` (เส้นประ) · `curve` · การส่ง `null` ให้วันอนาคต
(แท่งซ้อนไม่วาดแท่งของวันที่ไม่มีข้อมูลอยู่แล้ว)

### ข้อแลกที่ต้องยอมรับ

แท่งซ้อนอ่าน **"วันไหนขายดี"** และ **"สินค้าไหนมีส่วนแบ่งเท่าไร"** ได้ดีมาก แต่อ่าน
**"แนวโน้มของสินค้าตัวเดียวข้ามวัน"** ได้ยากกว่าเส้น เพราะตำแหน่งเริ่มต้นของช่วงสีขยับตามตัวที่อยู่ล่าง
— **แต่คำถามนั้นมีที่ตอบอยู่แล้ว** คือแถบ 31 ช่องในตาราง (หนึ่งแถวต่อสินค้า เส้นฐานคงที่)
จึงไม่ได้เสียความสามารถไป แค่ย้ายไปตอบในที่ที่เหมาะกว่า

## ที่ `safepay-ux` เสนอแล้วยังไม่ทำ

| หัวข้อ | เหตุผลที่ยังไม่ทำ |
|---|---|
| ใส่รูปใน legend ด้วย | ux แนะนำเองว่าพอแค่ tooltip ก่อน — legend ≤6 รายการต้องจัดความสูง/ตกบรรทัดเอง เพิ่มความเสี่ยงโดยที่ tooltip คือจุดที่ผู้ใช้กำลังพยายามถอดรหัสจริง ๆ |
| hover แถวตาราง → เน้นเส้นบนกราฟ | legend hover ทำอยู่แล้ว และวงแหวนแก้ปัญหาเดียวกันแบบไม่ต้อง hover เลย (ใช้ได้บนมือถือ) — ประเมินผลรอบนี้ก่อน |

## ที่ปฏิเสธ (พร้อมเหตุผล)

| ทางเลือก | ทำไมไม่เอา |
|---|---|
| กราฟแท่ง **เรียงข้างกัน** (grouped) | 31 วัน × 3–5 แท่งต่อวัน = 93–155 แท่ง บีบแคบกว่าเส้นอีก — 🛑 **นี่คือสิ่งที่ ux ปฏิเสธ ไม่ใช่แท่งซ้อน** สองอย่างนี้คนละเรื่อง: grouped วางแท่งข้างกัน · stacked มีแท่งเดียวต่อวันแล้วแบ่งเป็นช่วงสี |
| เปลี่ยนเป็น area chart | พื้นที่ทับกันของค่าน้อย ๆ จะกลืนกันแย่กว่าเส้น |
| แยกกราฟเล็กต่อสินค้า (small multiples) | **แถบ 31 ช่องในตารางทำหน้าที่นี้อยู่แล้ว** และเป้าหมายของกราฟรวมคือ "เทียบสินค้าหลายตัวพร้อมกัน" ถ้าแยกจะเสียจุดประสงค์หลัก |
| จับคู่สีในกราฟกับคำว่า "สี" ในชื่อสินค้า | ต้อง parse ภาษาไทยอิสระ ซึ่งสินค้าส่วนใหญ่ไม่มีคำสีในชื่อ · ชนกันเองทันทีเมื่อมีสินค้าสีเดียวกันสองตัว · ธีมไม่มีโทเคนสีดำให้ "สีดำ" อยู่แล้ว ⇒ แก้ด้วยวงแหวนโยงตาราง↔กราฟแทน (ไม่ต้องจำสีเลย) |

## สถานะ

- **กราฟเส้น** ที่ปรับแล้ว (สี/จุด/แกน Y/tooltip มีรูป/วงแหวน) **ขึ้น prod ไปแล้ว** (`9372ab8f`)
  ⇒ ของจริงตอนนี้ยังเป็นเส้นอยู่
- **แท่งซ้อนยังไม่ได้เขียนโค้ด** — ม็อกอัพนี้คือสิ่งที่รอ user เคาะก่อนลงมือ
- ค้างไว้ยังไม่ push: แก้ `border-radius` ของรูปใน tooltip จาก `5px` (ไม่มีในบันไดของระบบ) → `4px`
- 🛑 **ยังไม่เคยเปิดหน้าจริงด้วยตาเอง** — ตัวเลขและรูปในม็อกอัพนี้วาดจากภาพหน้าจอที่ user ส่งมา
