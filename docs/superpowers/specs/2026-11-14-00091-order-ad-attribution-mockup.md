## หน้าจอ

1. **รายการคำสั่งซื้อ `/orders`** — Desktop: ชิปโทนกลาง "โฆษณา: {ชื่อ}" + speakerphone ต่อจากป้ายประมูล ก่อน "เปิดข้อความสนทนา + วันที่" · ตัดที่ max-w-xs + title ชื่อเต็ม · Tablet/Mobile ใช้การ์ด (breakpoint lg) แถวเต็มกว้างระหว่างบล็อกหัวกับเส้นประ line-clamp-2 · 3 ใบ: ชื่อยาว / ชื่อสั้น (ใส่ป้ายประมูลเพื่อโชว์ลำดับ) / ไม่มีแอด (ไม่มี node)
2. **การ์ดในแชท** — บรรทัด "จากโฆษณา: {ชื่อ}" text-2xs เป็นลูกตัวแรกของ body ใต้หัวน้ำเงิน · Desktop วางทั้งฟอง w-64 และแผงขวา w-full · ใบไม่มีแอดวางเทียบ · แบนเนอร์โฆษณาบนหัวเธรดเป็นของเดิม (แอดล่าสุดของห้อง ≠ แอด ณ วันสร้างใบ)
3. **หน้ารายละเอียด** — แถว "มาจากโฆษณา: {ชื่อเต็ม} · ลูกค้ากดโฆษณาเมื่อ {formatDateTimeTH}" ต่อจากบรรทัดวันที่ ก่อนป้ายสถานะ · ไม่ truncate · 3b: ไม่มีชื่อ → รหัสโฆษณา / ไม่มีแอด → ไม่มีแถว margin เดิม
4. **รายงาน `/reports/ads`** — แถบกรอง (ช่วงวันที่ · เพจ · ส่งออก) · การ์ดสรุปใบเดียวพร้อมแถบสัดส่วน 2 ส่วน · ตาราง 7 คอลัมน์ (Desktop) / 5 คอลัมน์ + บรรทัดรอง (Tablet) / การ์ด + ปุ่มเรียง (Mobile) · 4b ชีต AdOrdersSheet (แผงขวา max-w-xl บน Desktop, เต็มจอบน Tablet/Mobile) · 4c ว่าง 2 แบบ

## มติจาก spec ที่สะท้อนในม็อกอัพ

- ไอคอน `speakerphone` ทุกจุด (คำตัดสิน Q1)
- อัตราปิดการขายแสดงค่าจริง + tooltip ที่หัวคอลัมน์ (Q3) · แชท = 0 → "—"
- ส่งออกเป็นปุ่มลิงก์ ไม่มีโมดัล (Q5 xlsx อย่างเดียว)
- รูปแอดไม่มี → tile ไอคอน (Q7)
- แอดที่ 0 คำสั่งซื้อ ใช้ข้อความธรรมดา ไม่แดง · ไม่มีสีเขียวในฟีเจอร์ (ยกเว้นป้ายสถานะเดิม)
- น้ำเงิน primary ใช้แค่ส่วน "จากโฆษณา" ของแถบ · ลิงก์เลข DP · ลิงก์/ปุ่มเดิม
- ใบยกเลิกในชีตแสดงจาง + ป้าย "ยกเลิก"

## จุดที่ตัดสินเองในม็อกอัพ (ให้ Controller ยืนยัน)

- **ว่างทั้งร้าน** ไม่แสดงแถบกรองและการ์ดสรุป (ไม่มีอะไรให้กรอง) · ปุ่ม "ไปที่กล่องข้อความ" เป็นปุ่มขอบ ไม่ใช่ primary ทึบ (คุม One Voice)
- **ว่างในช่วง** ยังโชว์การ์ดสรุป 0% เพราะยอดที่ไม่ได้มาจากโฆษณายังมี
- ใบยกเลิกในชีต ขีดฆ่ายอดเงินเพิ่มจาก "จาง" ตาม spec
- ตาราง Tablet ใส่บรรทัดรอง "เฉลี่ย ฿x/ใบ" และ "ยกเลิก/คืน n" ทุกแถว (รวมค่า 0) — spec ไม่ระบุว่าซ่อนเมื่อ 0

## ส่วนที่ต่างจากโทเคน DESIGN.md / ของจริง

- ม็อกอัพใช้ Tailwind CDN + ชื่อสี `d100…d900` แทน `default-*` (map ค่าเดียวกับ Paces) — ตอน build ใช้คลาส Paces จริง
- ขนาดตัวเลขพระเอกในการ์ดสรุปตั้ง 22px inline แทน `text-xl` ของ Paces (ม็อกอัพไม่มีสเกลเดียวกัน)
- สเต็ปเปอร์พัสดุ 4 ขั้น ป้ายขนส่ง และเลขพัสดุเป็นภาพประกอบ ของจริงคือ `ShipmentStepper` เดิม
- ม็อกอัพใช้ค่า arbitrary บางจุด (`grid-cols-[…]`, `w-[340px]`, `max-w-[340px]`) เพื่อจัดกรอบ — ห้ามลอกเข้า `(paces)/**` (HR7)
- โลโก้ LINE ใช้ `simple-icons:line` สีเขียว ของจริงใช้ `OrderSourceLogo`/`ChannelBadge`
- ไม่ได้วาด loading skeleton / error ของชีตและหน้า / ไม่มีสิทธิ์ / ไม่มีร้าน (ใช้ component เดิมตาม spec)
