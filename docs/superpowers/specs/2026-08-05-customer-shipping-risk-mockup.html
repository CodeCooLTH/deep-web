เรื่องกติกา
Base (theme-copy)กล่องเตือน = BookingForm ประวัติจอง · แถวค้นหา = ShipmentLinkPanel · การ์ด = ShippingActivity · แถวสรุปในแชท = notice box ของ ShipmentStatusView — ไม่มีชิ้นไหนประกอบจากศูนย์
สีwarning ทุกจุด — เฉพาะ badge "ปฏิเสธ COD" ใช้ bg-danger/15 text-danger-ink เพราะเป็นเรื่องเงิน แต่พื้น/กรอบกล่องยังเป็น warning (เตือน ไม่ใช่ตัดสิน)
ไม่มีประวัติไม่ render อะไรเลยทุกจุด — ห้ามมีการ์ด "ความเสี่ยง 0"
ที่มาตัวเลขจุดที่แสดงแบบเต็มต้องมีบรรทัด "จากคำสั่งซื้อ N ครั้งใน M ร้านบน Deep"
icontabler alert-triangle ผ่าน @iconify/react ตอน implement — mockup ใช้ SVG path เดียวกัน inline · ห้าม emoji
