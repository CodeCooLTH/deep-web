  • 2. เข้าหน้านี้แล้วแถบล่างหายทั้งแถบ ปุ่ม "งานใหม่" มาเป็นแถบติดล่างจอแทน

  • 4. แท็บเล็ตแยกเป็นซ้ายขวา ปฏิทินซ้าย รายการนัดขวา
A · โทรศัพท์ 393px ทรงที่คุณอนุมัติแล้ว + ตัวเลขจำนวนนัด

ลดเสียงของช่องว่าง แทนที่จะเพิ่มเสียงให้ตัวเลข

  • ต้นเหตุที่กวาดตาแล้วไม่เจอ ไม่ใช่ "จุดเล็กไป" แต่คือ 28 ช่องที่ไม่มีงานดังเท่ากับ 3 ช่องที่มีงาน
  • พอวันว่างจางลง วันที่มีงานก็เด่นขึ้นเองโดยไม่ต้องขยาย/เติมอะไรลงไปในช่องเลย
  • ความเข้ม 3 ระดับ ไม่ใช่ 2 — มีงาน / ว่างในเดือนนี้ / เดือนอื่น ถ้าเหลือ 2 ระดับ ขอบเขตของเดือนจะหายไปเพราะวันว่างกับวันเดือนอื่นจะดูเหมือนกัน

ครึ่งซ้ายที่ 768px (จอแคบสุดของช่วงนี้) ให้ช่องวัน ~49px ต่างจากโทรศัพท์แค่ ~5px แปลว่าแบ่งครึ่งเท่ากันใช้ได้ทั้งช่วง 768–1023 ไม่ต้องขยับเส้นเริ่มไป 900 · เทียบกับถ้าแบ่ง 40/60 จะเหลือ ~39px ซึ่งแคบกว่าโทรศัพท์ชัดเจน = บีบที่ของตัวเลขจำนวนนัดที่เพิ่งทำ

ตัดสินใจไว้แบบนี้

  • ปุ่มงานใหม่ยังเป็นแถบล่างจอเหมือนโทรศัพท์ — ตอนแรกผมจะย้ายไปหัวคอลัมน์ขวา แต่ ux ค้านว่า คุณเพิ่งชมแถบนี้ไป การย้ายที่ตอนหมุนจอ/สลับเครื่องจะทำให้ต้องจำตำแหน่งใหม่โดยไม่ได้อะไรกลับมา ผมเห็นด้วยเลยคงไว้ · ขอบซ้ายขวาของปุ่มตรงแนวกับกริดด้านบนพอดี
  • ปฏิทินฝั่งซ้ายค้างอยู่กับที่ เวลารายการขวายาว (วันที่มี 20 นัด) — เลื่อนทั้งหน้าไม่ทำกล่องเลื่อนซ้อนกล่องเลื่อน (เคยมีบั๊กแผงดรอปดาวน์โดนกล่องเลื่อนตัด จึงเลี่ยงไม่สร้างกล่องใหม่)
  • ขอบซ้ายขวาเหลือ 16px เท่ากับโทรศัพท์ ไม่บีบการ์ดให้แคบลงมาอยู่กลางจออีก (เดิม 672px เหลือขอบข้างละ ~80px)
  • ตั้งแต่ 1024px ขึ้นไปเป็นคนละหน้าจอ (ตารางเดือนเต็มที่มีชื่อผู้จองในช่อง) รอบนี้ไม่แตะ
จุดที่อยากให้ดู: ระหว่างปฏิทินกับแผงเทาฝั่งขวามีช่องไฟ 16px คั่นตามสเปก ถ้าดูแล้วรู้สึกว่า แถบขาวตรงนั้นเกินมา บอกได้ — ตัดช่องไฟออกให้เหลือแค่เส้นแบ่งก็ได้

สิ่งที่แลกไปกับการเลือกจุดแทนตัวเลข

  • ยังไม่รู้ว่าวันนั้นมีกี่คิว ต้องจิ้มเข้าไปดู — จุดบอกได้แค่ "วันนี้มีงาน" เหมือนเดิม สิ่งที่ดีขึ้นคือ หาวันที่มีงานเจอเร็วขึ้น เพราะวันว่างถอยไปข้างหลังแล้ว (คุณเลือกทางนี้เองหลังเห็นทั้ง 8 แบบ — บันทึกไว้เฉย ๆ ไม่ได้ค้าน)
  • ถ้าวันไหนอยากได้ตัวเลขกลับมา ทำได้ทีหลังโดยไม่ต้องรื้ออะไร — สลับ span เดียวในไฟล์เดิม
  • ร้านที่ตั้งความจุต่อวัน ยังเห็นกากบาทในวันที่เต็มเหมือนเดิม ซึ่งเดิม legend เป็นคนอธิบาย พอตัด legend แล้วต้องอาศัยว่ากากบาทอ่านออกเอง — ร้านคุณไม่ได้ตั้งความจุจึงไม่เจอกรณีนี้
