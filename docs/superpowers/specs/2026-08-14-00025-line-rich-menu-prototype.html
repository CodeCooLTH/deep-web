ตั้งค่า Rich Menu ของ LINE OA — 3 ทางเลือกหน้าตา

คำถามที่ต้นแบบนี้ตอบ: “หน้าตั้งค่า rich menu ควรเป็นยังไง” — ไม่ใช่ “ระบบทำงานถูกไหม” ทั้ง 3 แบบครอบขอบเขตเดียวกัน (เทมเพลต + รูป + action · เมนูหลายชุด + สลับ default · ตั้งเวลา/กลุ่มผู้ใช้ · วาดช่องเอง) แต่ ต่างกันที่โครงสร้าง ไม่ใช่ต่างที่สี — เลือกได้ว่าจะเอาอันไหน หรือหยิบชิ้นจากหลายอันมาผสม

ของทิ้ง (throwaway) — ไฟล์นี้ไม่ใช่โค้ดจริง ไม่มีเทส ไม่ต่อ API เปิดด้วยการดับเบิลคลิกได้เลย ไม่ต้องรัน dev server
สลับแบบ: กดปุ่ม ‹ › ที่แถบล่างจอ หรือกดลูกศรซ้าย/ขวาบนคีย์บอร์ด · URL จำค่าไว้ (?v=A)
ข้อควรรู้ก่อนตัดสิน: วันนี้ rich menu อยู่ “นอกขอบเขต” ของฟีเจอร์ 00025 (PRD.md:278, SRS.md:37) และในรีโปยังไม่มีโค้ด rich menu สักบรรทัด — ถ้าจะทำจริงต้องขยาย scope + ผ่าน safepay-ux ก่อนลงมือ (Hard Rule 8)

A — แคนวาสเป็นพระเอก (แก้ตรงบนรูป)

โครง 2 คอลัมน์แบบเดียวกับ LINE Official Account Manager: ซ้ายคือรูปเมนูขนาดใหญ่ที่มีกรอบช่องวางทับ คลิกช่องไหนก็แก้ช่องนั้นในแผงขวา จุดแข็ง — “ช่องนี้คือช่องไหนบนรูป” ชัดที่สุด, วาดช่องเองได้ตรง ๆ ด้วยการลากบนแคนวาส จุดอ่อน — ต้องใช้จอกว้าง (แนวเดียวกับ /seller/public-profile/builder ที่เป็น desktop-only อยู่แล้ว), แก้ action หลาย ๆ ช่องรัว ๆ ต้องคลิกไป-มา

B — รายการช่องเป็นพระเอก (รูปเป็นแค่ตัวอ้างอิง)

ทิ้งแคนวาสใหญ่ทิ้งไป เหลือพรีวิวเล็ก ๆ ปักไว้ข้างบน แล้วให้เนื้อหาหลักเป็น รายการช่องเรียงเป็นแถว — แต่ละแถวคือช่องหนึ่งช่อง แก้ action ได้ในแถวเลย จุดแข็ง — ทำงานได้เต็มที่บนมือถือ, กวาดตาดู “ช่องไหนยังไม่ผูก action” ได้ในวินาทีเดียว, เข้ากับภาษาหน้าอื่นของ seller (การ์ดแยกใบแบบ /orders, /products) จุดอ่อน — ความสัมพันธ์ “แถวนี้ = ตรงไหนบนรูป” อ่อนกว่า ต้องพึ่งตัวอักษร A–F บนพรีวิว, วาดช่องเองต้องเปิดชีตแยก

C — ตัวช่วยเป็นขั้น (ถามทีละเรื่อง)

ไม่มีหน้าแก้รวมเลย — แยกเป็น “คลังเมนู” (รายการชุดทั้งหมด + สลับ default) กับ “ตัวช่วยสร้าง” 5 ขั้น: เทมเพลต → รูป → action → เวลา/กลุ่ม → ตรวจแล้วเผยแพร่ จุดแข็ง — ร้านที่ไม่เคยตั้ง rich menu มาก่อนทำจบได้โดยไม่ต้องเดา, กันเผยแพร่ทั้งที่ช่องยังว่างได้ตั้งแต่ต้นทาง, ใช้ได้ทุกจอเท่ากัน จุดอ่อน — ร้านที่แค่อยากแก้ลิงก์เดียวต้องเดินผ่านหลายขั้น (ต้องมีทางลัด “แก้เฉพาะขั้น 3”), ไม่เห็นภาพรวมพร้อมกันทั้งหมด
