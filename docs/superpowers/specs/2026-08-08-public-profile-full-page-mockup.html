ยกเลิกคำสั่งซื้อนี้?

สต็อกที่ตัดไปแล้วจะถูกคืนกลับ และลิงก์ที่ส่งให้ลูกค้าจะใช้ไม่ได้อีก

2 ตัวเลือกแรก = ไม่นับเข้าตัวหาร · 2 ตัวหลัง = นับ. ชุดคำต้องแยกตาม Shop.vertical (ร้านคิวงานใช้ "ลูกค้าไม่มาตามนัด" ไม่ใช่ "ไม่โอนเงิน") และ ห้ามยืมชื่อ flag countsAgainstGuest จาก lodging.ts:149 มาใช้ตรง ๆ เพราะความหมายกลับด้านกัน (อันนั้น = นับเข้าประวัติผู้จอง)

ทำไมเป็น hybrid ไม่ใช่ A/B/C/D ตรง ๆ

  • A — โครงถูก แต่ทำ "17" กับ "94%" ใหญ่ 32px เท่ากันทั้งคู่ = hero-metric ซ้ำสองก้อน ไม่มีจุดโฟกัสเดียว
  • B — ยุบช่องทางเป็นชิป ซึ่งเป็น markup ใหม่ที่ไม่มีใน OfficialChannels.tsx ขัดคำสั่ง "ใช้ซ้ำ ไม่ต้องออกแบบใหม่"
  • C — ลำดับชั้นตัวเลขดีสุด แต่ไม่มีช่องทางในหัวโปรไฟล์เลย ขัดคำสั่งข้อที่สั่งมาตรง ๆ
  • D — ลำดับชั้นถูก caption กางตัวหารดีสุด แต่ ทำชิปคะแนน/tier หายไปทั้งก้อน โดยไม่มีเหตุผล
  • ที่ใช้จริง — identity + ช่องทางแบบ A · ตัวเลขใหญ่ก้อนเดียว + caption แบบ D · "17" ลดเป็น 22px (metric scale ของ DESIGN.md คือ 32/22/20 อยู่แล้ว) ให้ยังเป็นตัวเลขที่กวาดตาเห็น แต่ไม่แย่งโฟกัสกับ %

แก้อะไรอีกในรอบนี้

  • คอนทราสต์ — text.disabled (ink .4 ≈ 2.7:1 ตก AA) ถูกใช้กับข้อมูลจริงที่ไม่ใช่สถานะปิดใช้งาน ที่ ProfileHero.tsx:158,204 และ OfficialChannels.tsx:89 → เปลี่ยนเป็น text.secondary (อาการเดียวกันมีที่ OrderLinkShell.tsx:228,235 ด้วย — คนละหน้า ยังไม่แก้รอบนี้)
  • คะแนนมีสเกล — "13" → "13 / 100" + ปุ่ม ⓘ อธิบายที่มา (hit-area ต้อง 44px จริง — IconButton size="small" ของ MUI ให้แค่ 34px ไม่ผ่าน)
  • ป้ายเลิกโกหก — "จากออเดอร์ทั้งหมดบน Deep" → "จาก N ใบที่ปิดจบ · ไม่นับ M ใบที่ผู้ซื้อไม่รับของ" (ถ้า M = 0 ให้ตัดประโยคหลังทิ้ง ไม่เขียน "ไม่นับ 0 ใบ")
  • ช่องทางขึ้นหัวโปรไฟล์ + ถอดออกจากแท็บ — ใช้ OfficialChannels.tsx ทั้งก้อนไม่แก้ คงเป็นรายการแนวตั้งเดียวทุกจอ (2 คอลัมน์ต้องไปแก้ตรรกะเส้นคั่นภายใน = ผิดเงื่อนไข "ใช้ซ้ำ")

  • เดสก์ท็อปไม่แยก 2 คอลัมน์ — DESIGN.md ประกาศ "การ์ดคอลัมน์เดียวสไตล์ Instagram" เป็น signature ที่ sign-off แล้ว และ sidebar-stats คือหน้าตา dashboard ซึ่งอยู่ใน anti-reference ของ PRODUCT.md
