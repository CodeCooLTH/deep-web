D · หลังเปิดใบคืนแล้ว (เปิดชีตเดิมซ้ำ)

กด ⋮ → คืนของ อีกครั้ง จะเห็นใบที่เปิดไว้พร้อมปุ่มดำเนินการต่อ

สถานะปุ่มที่เห็นเกิดอะไรขึ้น
รอส่งคืน ออกเลขพัสดุขากลับ ได้รับของคืนแล้ว ยกเลิกเรื่องคืน ปุ่มแรกเปลี่ยนตามข้อที่เลือกไว้ — เลือก iShip = ออกเลขพัสดุขากลับ (ตัดเครดิตจริง) · เลือกแบบอื่น = บันทึกว่าส่งคืนแล้ว
กำลังส่งคืน การ์ด ใบปะหน้าพัสดุขากลับ + เปิด คัดลอกลิงก์ เฉพาะใบที่ระบบออกเลขให้ — คัดลอกลิงก์ส่งให้ลูกค้าทางแชทเพื่อพิมพ์ติดกล่อง (ลิงก์สาธารณะ ลูกค้าไม่ต้องมีบัญชี)
รับของคืนแล้ว— 🛑 จุดเดียวที่ตัวเลขเปลี่ยน — ยอดขายของรายการที่คืนถูกหักออก และค่าส่งขากลับเข้าเป็นค่าใช้จ่าย · มีหน้าต่างยืนยันก่อนเสมอ
