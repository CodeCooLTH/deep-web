Mockup v3 — รายละเอียดคำสั่งซื้อ (seller)

แก้จาก v2 ที่ไม่ผ่าน: ปุ่มกระจาย 4 จุด · การ์ด 7 ใบน้ำหนักเท่ากัน · เงินอยู่ 2 ที่ (ยอดรวมท้ายตารางซ้าย + สถานะชำระคอลัมน์ขวา)

3 อย่างที่เปลี่ยนใน v3:
1. ปุ่มทุกตัวอยู่แถบบนสุดที่เดียว (sticky) — เดิมกระจายที่ minibar / hero / การ์ดจัดส่ง / ⋮ · action รองยุบเข้า ⋮ ทั้งหมด (คัดลอกที่อยู่ / แก้ไขคำสั่งซื้อ / ยกเลิก) · ในเนื้อหาเหลือปุ่มเดียวคือ submit ของฟอร์มที่เปิดอยู่ (ปุ่ม submit ต้องติดฟอร์ม)
2. ยอดเงินขึ้นไปอยู่บนสุดคู่กับสถานะ — คำถาม "ได้เงินเท่าไหร่ / ได้หรือยัง" ตอบได้ในบรรทัดเดียวไม่ต้องมองสองที่
3. ยุบ 5 การ์ดเป็นการ์ดหลักใบเดียว แบ่ง section ด้วยเส้นประ (ผู้ซื้อ → จัดส่ง → รายการ → ยอดเงิน → การชำระเงิน) ตามลำดับงานจริงของผู้ขาย · คอลัมน์ขวาเหลือ "ความคืบหน้า" อย่างเดียว

Base: theme/paces/.../ecommerce/(orders)/order-details/ — การ์ดใบเดียวที่รวม hero+items+totals + เส้น dashed คือสิ่งที่ theme ทำจริงใน OrderSummary.tsx (v2 แยกเป็นการ์ดย่อยเองซึ่งหลุดจาก theme)
