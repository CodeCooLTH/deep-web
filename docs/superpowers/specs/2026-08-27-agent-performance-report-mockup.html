ตัวเลขทุกตัวในหน้านี้เป็นของจริง จาก production ร้าน BT Premium - คลอง 4 ธัญบุรี ช่วง 30 วันล่าสุด (ดึงแบบอ่านอย่างเดียว 2026-08-27) — ไม่มีตัวเลขแต่งขึ้นสักตัว ตามหลัก “ห้ามแต่งข้อมูล” ใน PRODUCT.md

ตัวอักษรในวงกลมไอคอน (฿ ⌁ ✓ ↗ ≡ ?) เป็นตัวแทนชั่วคราวของ mockup เท่านั้น — ของจริงใช้ไอคอน tabler ผ่าน @iconify/react (messages · clock-bolt · shield-check · target-arrow · receipt-2 · user-question) ห้ามหยิบตัวอักษรพวกนี้ไปใส่โค้ดจริง (Hard Rule 12: ห้าม emoji ใน UI ใช้ icon จริงเท่านั้น)

สิ่งที่เพิ่มจากที่ implement ไปแล้ว และอยากให้ช่วยตัดสิน: คอลัมน์กลุ่ม “ตอบแชท → เปิดบิล” (ตอบคำถามว่าแอดมินคนนั้นตอบแชทแล้วไปจนถึงเปิดบิลเองได้ไหม)
