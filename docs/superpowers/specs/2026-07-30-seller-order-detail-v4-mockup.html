Mockup v4 — รายละเอียดคำสั่งซื้อ (seller) · แบบ C "สถานะเป็นแกนหลัก"

หน้าคือไทม์ไลน์ของคำสั่งซื้อ แต่ละขั้นกาง/พับได้ — ขั้นที่กำลังเกิดกางอยู่ ขั้นที่จบแล้วพับ ลำดับความสำคัญมาจากวงจรของคำสั่งซื้อเอง ไม่ต้องจัดลำดับด้วยสายตา · คลิกหัวขั้นเพื่อกาง/พับได้จริงในเอกสารนี้

Base (theme file ที่โครงมาจากจริง): theme/paces/.../order-details/components/ShippingActivity.tsx — เส้นประแนวตั้ง (after:border-dashed) + วงไอคอน 33px + หัวข้อ + badge + เวลาขวา + คำอธิบาย. v4 เอาโครงนี้มาเป็น ตัวหน้า แล้วเติมกาง/พับด้วย card-toggle ของ Paces ([data-action="card-toggle"] i หมุน 180° ใน custom/_card.css) — ไม่ใช่ pattern ที่คิดขึ้นใหม่
ตารางสินค้า: OrderSummary.tsx · bubble: orders/components/BulkActionBar.tsx

กติกาการกาง: ขั้นที่ "กำลังเกิดหรือเพิ่งเกิด" กางอยู่ 1 ขั้น — PENDING/SHIPPED กาง จัดส่ง (ที่อยู่+เลขพัสดุคือสิ่งที่ผู้ขายต้องใช้), CONFIRMED กาง ผู้ซื้อรับของ (รีวิว = จุดจบ), CANCELLED กาง สั่งซื้อแล้ว (เหลือแค่อ้างอิงว่าสั่งอะไรไป)
