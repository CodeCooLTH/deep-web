8. สิ่งที่ mockup นี้ยืนยันไม่ได้

mockup เป็น HTML ล้วน ไม่ใช่ Paces จริง — สิ่งที่ต้องพิสูจน์ตอน implement เท่านั้น: (1) badge มุมบนซ้ายไม่ถูก overflow ของแถวตัดหัว (2) ที่ 320px จริง ชื่อลูกค้าในหัวเธรดยังไม่ตกบรรทัด (.card-header เป็น flex-wrap โดยกำเนิด — ต้อง flex-nowrap) (3) shop picker popover ไม่ถูกกล่อง scroll ของ rail ตัด (scroll-container-clips-popovers.md) (4) โมดัลที่ประกอบเองต้องมี useLockBodyScroll + overscroll-contain
