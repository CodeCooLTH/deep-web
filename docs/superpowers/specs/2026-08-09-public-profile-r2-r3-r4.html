สิ่งที่ mockup นี้จงใจแสดง (เคสจริงที่ต้องรอดทั้งหมด)

  • R3 · เพจที่ไม่มียอด — ใบที่ 3 ("ธนภัทร์ ช้อป 2") ไม่มีบรรทัดยอดเลย เพราะเพจที่เชื่อมไว้ก่อนหน้านี้อาจอ่าน fan_count ไม่ได้จนกว่าจะเชื่อมใหม่ (scope ผูกกับ token ตอน grant) — ห้ามแสดง 0 เพราะ 0 แปลว่า "ไม่มีคนถูกใจ" ซึ่งไม่จริง
  • R3 · Instagram ใช้คำคนละคำ — IG ไม่มี "ไลก์" ของบัญชี จึงเป็น "ผู้ติดตาม"
  • R4 · เหรียญที่ยังไม่มี artwork — "เปิดหน้าร้าน" ใช้ไอคอนเส้นแต่ยังอยู่ในกรอบวงกลมขาวขนาดเดียวกัน กับเหรียญที่มีรูป ทั้งแถวจึงอ่านเป็นตระกูลเดียวกัน ไม่ใช่ "บางใบโหลดไม่มา"
  • R2 · สินค้าที่ไม่มีรูป — "โช๊คหน้า เวฟ 110i" เป็นกล่องเทา+ไอคอน แต่มีขอบการ์ดล้อมรอบ จึงอ่านเป็น "ยังไม่ใส่รูป" ไม่ใช่ "หน้าโหลดไม่เสร็จ" แบบกริดชิดขอบเดิม
  • R2 · สินค้าที่ไม่มีคำอธิบายสั้น — "โช๊คหลัง สปริงแดง" ไม่ render บรรทัดคำอธิบายเลย (ไม่ใช่เว้นที่ว่างไว้)
  • R2 · ราคายังลอยบนรูป ตามที่เคาะ — ชื่อ+คำอธิบายอยู่ใต้รูปเพราะยาวไม่จำกัด รับประกันคอนทราสต์บนภาพไม่ได้

ยังไม่ได้ตัดสิน / ต้องยืนยัน

  • จำนวนคอลัมน์สินค้า mockup นี้ใช้ 2 / 3 / 4 (เดิม 3 / 4 / 5) — ลดลงเพื่อให้ชื่อไทยอ่านออกที่ 390px หลังมีข้อความเพิ่ม 2 บรรทัด
  • ย้ายช่องทางขึ้นหัวแล้ว แท็บ "เกี่ยวกับร้าน" จะเหลือแค่ bio + ที่อยู่ + วันเปิดร้าน — จะให้คงบล็อกช่องทางไว้ในแท็บด้วยไหม
  • ยอดผู้ติดตามต้องมีคอลัมน์ใหม่บน ShopChannel + จังหวะ refresh (งาน backend ยังไม่ได้ทำ)
