5. จุดที่ต้องตัดสินก่อนลงมือ

C-1 breakpoint: ux เสนอ mobile <900 แต่ BRD FR-018 ที่อนุมัติแล้วเขียน ≤767 และโค้ดจริงสลับ sidebar ที่ 768px — ม็อกอัพนี้ยึด 768 เพราะถ้าใช้ 900 จะเกิดช่วง 768–899 ที่ sidebar โผล่แล้วแต่เนื้อหายังเป็นโหมดมือถือ
C-2 FR-005 (PII): การโชว์เลขออเดอร์/ชื่อร้านบนหน้า OTP ต้อง query ออเดอร์ในจังหวะที่ ยังไม่ผ่าน resolveOrderAccess — เป็นคำถามความปลอดภัย ไม่ใช่แค่ scope
C-5 desktop 1200–1280: 3 แถบ (sidebar 240 + main + action panel) อาจแน่นที่ขอบล่างของช่วง — ต้อง QA จริง
