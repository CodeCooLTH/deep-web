เดิมใหม่
คอลัมน์ "ที่มา" 36pxย้ายขึ้นแถบหัว พร้อมชื่อเพจเต็ม ๆ + badge แพลตฟอร์ม — เห็นชัดกว่าเดิม ไม่ใช่แค่โลโก้จิ๋ว
คอลัมน์ "เลขออเดอร์" 159pxย้ายขึ้นแถบหัว (เป็นชื่อของทั้งบล็อก ไม่ใช่ค่าในช่อง)
คอลัมน์ "วันที่/เวลา" 80px (ตัด 3 บรรทัด)ย้ายไปมุมขวาแถบหัว บรรทัดเดียวเสมอ
"ขนส่ง" + "เลขพัสดุ" + "พัสดุ" = 427pxยุบเป็น "การจัดส่ง" ช่องเดียว 200px (โลโก้+ชื่อ / เลขพัสดุ / timeline เรียงลงมา)
"การชำระเงิน" 74px (ตัด 3 บรรทัด) + "ยอดรวม" 54pxรวมเป็นช่องเดียว — วิธีจ่าย / ยอด / สถานะเงิน COD อยู่ด้วยกันเพราะเป็นเรื่องเดียวกัน
"จัดการ" 209px (ปุ่มเรียงแถวเดียว)กริด 3×2 เหลือ ~106px — ปุ่มยังเห็นครบทุกตัว ไม่ต้องมีเมนู ⋮ (กฎ 2026-06-15 ยังอยู่)
"สินค้า" ถูกบีบเหลือ 107px200-250px + ชื่อได้ 2 บรรทัด + บอกจำนวน/ราคาต่อชิ้น
ที่อยู่ผู้รับ ไม่มีในตารางเลยเห็นได้เลย (ต้องเปิดเข้าไปดูทีละใบในของเดิม)

ข้อควรรู้ก่อนเคาะ

1. แถวสูงขึ้นต่อใบ — จาก 66px เป็นราว 130px (หัวกลุ่ม 34 + เนื้อหา 96) เห็นออเดอร์ต่อจอน้อยลงประมาณครึ่ง แลกกับการเห็นข้อมูลต่อใบมากขึ้นมาก (ที่อยู่ + สถานะย่อย + จำนวน/ราคาต่อชิ้น ที่เดิมไม่มีเลย) ถ้าอยากได้ทั้งสองอย่าง เพิ่มปุ่มสลับ "หนาแน่น / สบายตา" ได้ แต่เป็นงานเพิ่ม
2. การเรียงลำดับ (sort) — คอลัมน์ที่ย้ายขึ้นแถบหัว (วันที่/เลขออเดอร์) จะกดหัวตารางเรียงไม่ได้แล้ว ต้องย้ายไปเป็นตัวเลือกใน toolbar แทน
3. เลือกหลายรายการ — checkbox ย้ายไปอยู่แถบหัวกลุ่ม (ตามแบบที่คุณส่งมา) ยังใช้ได้เหมือนเดิม
4. มือถือ — ไม่แตะ ยังเป็นการ์ดเดิม
