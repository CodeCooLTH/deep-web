## 2. A — แผงข้อมูลลูกค้า (คอลัมน์ขวา `w-96` = 384px, `xl:block`)

**ถอดออก 3 บล็อก:** ป้ายพฤติกรรม (`CustomerBehaviorPills`) · แถบ "ทั้งระบบ" (`BuyerReputationRow`) · ลิงก์ "ดูโปรไฟล์เต็ม"

**หัวใหม่:** `p-4` → `px-4 pt-4 pb-3` และ **ตัดเส้นประใต้หัวทิ้ง**
> เส้นประเคยคั่นหัวออกจาก "แถวสัญญาณ" ที่ตามมา พอไม่มีแถวพวกนั้นแล้ว มันจะอยู่ห่างจากเส้นทึบ
> ของแถบแท็บแค่บรรทัดเดียว = เส้น 2 ชั้นติดกันที่ไม่ได้คั่นอะไรเลย

ระยะจากขอบบนถึงแถบแท็บ **232px → 108px** (คืนพื้นที่ให้เนื้อหาแท็บ ~124px)

🛑 ป้าย/สถิติเหล่านี้ **ไม่ได้ถูกลบจากระบบ** — ยังอยู่ครบที่ `/customers` และหน้าโปรไฟล์ลูกค้า
(`BuyerReputationRow.tsx` ยังถูก import โดย `CustomerProfileHeader.tsx`) ถอดเฉพาะแผงนี้

**ผลพลอยได้ฝั่ง server:** `customerBehavior` / `buyerReputation` กลายเป็น prop ที่ไม่มีใครอ่าน
จึงถอดคิวรีที่เลี้ยงมันทิ้งด้วย — `order.findMany` ทุกใบของลูกค้า + `getBuyerReputation()`
= **ประหยัด 2 คิวรีต่อการเปิดเธรด 1 ครั้ง**

## 3. B — หัวห้องแชท

### ตารางการมองเห็นตาม breakpoint (แก้รอบสอง — user สั่งให้มือถือเห็น bell + customer ตรง ๆ)

| ตัวควบคุม | คลาส | <768 | 768–1279 | ≥1280 |
|---|---|:--:|:--:|:--:|
ลำดับที่ user เคาะสำหรับจอแคบ: **`[ตอบอัตโนมัติ] [ข้อมูล] [⋯]`**

| ตัวควบคุม | คลาส | <768 | 768–1279 | ≥1280 |
|---|---|:--:|:--:|:--:|
| แถบ ปิด/อัตโนมัติ (segmented) | `ms-auto hidden md:flex` | — | ✓ | ✓ |
| ตอบอัตโนมัติ (ไอคอนกดสลับ) | `md:hidden` + เฉพาะร้านที่มีบอท | ✓ | — | — |
| ข้อมูลลูกค้า | `xl:hidden` | ✓ | ✓ | — |
| กระดิ่ง (เสียงแชทนี้) | `hidden md:inline-flex` | — | ✓ | ✓ |
| `⋯` (ถือสวิตช์เสียงอย่างเดียว) | `md:hidden` | ✓ | — | — |
| ~~คลังไฟล์~~ | **ถอดปุ่มออก** (user: "ปุ่มมันเยอะไปป่ะ") | — | — | — |
| **รวมจำนวนปุ่ม** | | **2–3** | **2 + แถบ** | **1 + แถบ** |

🛑 **กลุ่มปุ่มขวาถูกห่อด้วย `flex items-center gap-1`** ไม่ใช่ปล่อยให้ใช้ `gap-3` ของ `.card-header`
— นี่คือสิ่งที่ทำให้คำสั่งนี้เป็นไปได้จริง กางเลขที่ 320px
(`.card-header px-5`=40 · `gap-3`=12 · `.btn.btn-icon`=37 · avatar=36):

| แบบ | สูตร | ชื่อลูกค้าเหลือ @320 | @375 |
|---|---|--:|--:|
| เดิม `[back][avatar][ชื่อ][folder][⋯]` | 40+37+12+36+12+**ชื่อ**+12+37+12+37 | 85px | 140px |
| เติม bell+customer ด้วย `gap-3` เท่าเดิม | +12+37 ×2 | **−13px** ❌ | 42px |
| gap-1 + ถอดคลังไฟล์ — 2 ปุ่ม (ร้านไม่มีบอท: ข้อมูล + `⋯`) | 149 + **ชื่อ** + (37×2+4) = 227 | 93px | 148px |
| เดียวกัน + ไอคอนตอบอัตโนมัติ — 3 ปุ่ม | + 4+37 = 268 | 52px | 107px |

🛑 **ปุ่มคลังไฟล์ถูกถอด — ไม่ใช่การกลับมติ 2026-08-14 แต่เงื่อนไขที่ทำให้มันเกิดหมดไปแล้ว**
ตอนนั้นไฟล์อยู่ลึก 4 ชั้นเพราะปุ่ม "ข้อมูลลูกค้า" ไม่มีบนมือถือ (ต้องกด `⋯` ก่อน) ตอนนี้ปุ่มนั้น
อยู่บนแถบแล้ว ไฟล์เหลือ **2 แตะ** และปุ่มทั้งสองเปิด **ชีตใบเดียวกัน** ต่างแค่แท็บ = ทางเข้าซ้ำ

⚠️ **ของที่หายไปด้วยคือตัวนับ "มีไฟล์เก็บไว้ N ใบ"** ที่เคยเกาะมุมปุ่มนั้น — ยังไม่ได้ย้ายไปไหน
ทางที่สะอาดคือทำเป็น badge ของแท็บ "ไฟล์" เหมือนที่แท็บ "คำสั่งซื้อ" ทำอยู่ (`savedFileIds.length`
มีอยู่แล้วที่ `page.tsx` ⇒ ใส่ลง `CustomerPanelData` ได้ตรง ๆ ไม่ต้อง prop drill) — **ยังไม่ทำ**

### ตอบอัตโนมัติมี 2 รูปร่าง ตัวเดียวกัน

| จอ | รูปร่าง | เหตุผล |
|---|---|---|
| ≥768px | แถบ segmented `[ปิด][อัตโนมัติ]` | มีที่ว่าง ⇒ ให้คำแบกความหมาย อ่านสถานะได้โดยไม่ต้องเรียนไอคอน |
| <768px | ปุ่มไอคอนกดสลับ `robot` / `robot-off` | แถบกว้าง ~150px กินที่ชื่อทั้งแถว — ไอคอนคู่เดียวกับในแถบ ไม่ใช่คนละชุด |

`variant` prop ของ `ThreadAutoReplyToggle` ตัวเดียว — ไม่ใช่ 2 component (HR16)

### แถบ ปิด / อัตโนมัติ — ผูกกับอะไร

| ช่อง | เขียนลง DB | ผล |
|---|---|---|
| **ปิด** | `{ autoReplyEnabled: false }` | `auto-reply.service.ts` gate 1 ตัดจบ ⇒ เงียบทั้ง **DeepBot (กลุ่มคำ)** และ **DeepAI (ChatBot)** เพราะ `tryChatbotAnswer` อยู่หลัง gate นี้ในไปป์ไลน์เดียวกัน |
| **อัตโนมัติ** | `{ autoReplyEnabled: true, clearPause: true, clearHandoff: true }` | ชุดเดียวกับปุ่ม "ให้บอทตอบต่อ" ใน `BotPausedBanner` |

🛑 **ต้องส่ง `clearPause`+`clearHandoff` ไปด้วยเสมอ** — ไม่งั้นห้องที่ถูกพัก (พนักงานพิมพ์ตอบ)
หรือถูกส่งต่อคน จะยังเงียบต่อ แล้วแถบขึ้นว่า "อัตโนมัติ" ทั้งที่บอทไม่ตอบ = ปุ่มที่โกหก

🛑 **มี 2 ช่อง ไม่ใช่ 3** — คอลัมน์เก็บได้ `null | true | false` แต่ `null` กับ `true` ให้ผล
เหมือนกันเป๊ะตั้งแต่ถอดสวิตช์ระดับร้านออก 2026-07-30 ("ไม่มีแล้วสิ ปิดทั้งหมด ให้ user ปิดเอง
ในแต่ละ row") ⇒ ช่องที่สามจะไม่มีความหมายต่างจากช่องข้าง ๆ. ถ้าอยากได้ "ผู้ช่วย" จริงตามภาพ
ต้องเพิ่มคอลัมน์ + ด่านใหม่ในไปป์ไลน์ = ฟีเจอร์ที่ต้อง doc-first (HR11)

🛑 **ไม่ render เลยเมื่อ `botCouldReply=false`** — ร้านที่ยังไม่มีบอทตัวไหนตอบได้ การให้เลือก
"อัตโนมัติ" คือการเสนอสิ่งที่ไม่มีทางเกิดขึ้น (เกณฑ์เดียวกับที่ `BotPausedBanner` ใช้อยู่แล้ว)

### กระดิ่ง

- ไอคอนสะท้อน **ผลลัพธ์รวม** (`appMuted || threadMuted`) ไม่ใช่สถานะสวิตช์ใดสวิตช์หนึ่ง
- ปิดเสียงทั้งแอปอยู่ → ยังกดได้ (มันเปลี่ยนค่าของ *แชทนี้* จริง) แต่ `title` บอกตรง ๆ ว่ายังไม่มีผล
- ตรรกะอยู่ที่ `useThreadSound()` เจ้าของเดียวทั้งปุ่มและเมนู (HR16)

## 4. C — เมนู `⋯` เหลือสวิตช์เสียงอย่างเดียว (จอแคบเท่านั้น)

> user รอบสอง: "ใน mobile ผมอยากให้มี [bell] [customer info] หน่อย **ตอนนี้มันต้องกด dropdown ก่อน**"
> user รอบสาม: "ปุ่มมันเยอะไปป่ะ" → **"[ตอบอัตโนมัติ] [ข้อมูล] [dropdown] ← dropdown ให้แสดง เปิดปิดเสียง"**

| ของในเมนูเดิม | ย้ายไปไหน |
|---|---|
| ข้อมูลลูกค้า | ปุ่มไอคอน `user-circle` (ทุกจอ · `xl:hidden`) |
| เสียง — เฉพาะแชทนี้ | <768px **ยังอยู่ใน `⋯` ตามที่ user เคาะรอบสุดท้าย** · ≥768px เป็นปุ่มกระดิ่ง |
| เสียง — ทั้งแอป | ถอดตามคำสั่งรอบแรก (ยังอยู่ที่ไอคอนลำโพงบนแถบบนสุด) |
| ตอบอัตโนมัติ | แถบ segmented (≥768) / ไอคอนกดสลับ (<768) |
| คำสั่งซื้อ | 🛑 **ถอดทางลัด** — เปิดแผงข้อมูลลูกค้าแล้วแท็บอยู่ตรงนั้น (+1 แตะ) |
| คลังไฟล์ *(เคยเป็นปุ่มบนแถบ ไม่ได้อยู่ในเมนู)* | 🛑 **ถอดปุ่ม** — เหตุผลด้านบน |

`ThreadOverflowMenu.tsx` ถูกเขียนใหม่ให้เหลือสวิตช์เสียงตัวเดียว + `md:hidden`
(ไม่ต้องลบไฟล์แล้ว — คำถามนั้นตกไป)

🛑 **ห้ามระบุตำแหน่งของสวิตช์ระดับแอปในข้อความเตือน** — มันอยู่ใน `ChatHeader` ซึ่ง `hidden lg:flex`
ในหน้าเธรด ⇒ คนที่เห็นข้อความนี้บนมือถือจะถูกชี้ไปหาของที่ไม่อยู่บนจอ
(คีย์ `threadSoundAppMutedHint` ยังอยู่ในดิกชันนารี ใช้เป็น `title` ของกระดิ่ง)

## 5. สิ่งที่ยังต้องดูด้วยตา

1. **320px กับร้านที่มีบอท** — ชื่อลูกค้าเหลือ 12px = เกือบเป็นจุดไข่ปลาอย่างเดียว (ดูตารางงบ)
   ที่ 375px ขึ้นไปสบาย (67px / 108px)
2. **768–1024px** — หัวเธรดมีทั้งแถบ + คลังไฟล์ + กระดิ่ง + ข้อมูลลูกค้าพร้อมกัน ชื่อยาว ๆ
   อาจโดนบีบ (`flex-header-truncation.md`)
2. **โหมดมืด** — ยังไม่ตรวจเลย (`--color-primary-ink` ในโหมดมืดเป็น `#93c5fd` คนละค่า)
3. **แถบ segmented ในเมนู `⋯`** — เมนูกว้าง 240px ส่วนแถบ ~150px พอดี แต่ยังไม่ได้กดจริง
4. ยังไม่ผ่าน `safepay-ux` (HR8) และ `/impeccable critique` — session นี้เรียก subagent ไม่ได้
