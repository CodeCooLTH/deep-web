## จุดที่ mockup ต่างจากของจริง

- หน้าตั้งค่า (settings) เป็นโครงย่อ: แถวบล็อก ยอดขาย/จำนวน/ค่าใช้จ่าย เป็นแถวพับปลอม และพรีวิวการ์ด LINE วาดคร่าว ๆ ไม่ใช่ `PreviewPanel` จริง · หัวหน้าเป็นแถบธรรมดา ไม่ใช่ layout `(fullscreen)` จริง
- Swal วาดด้วย HTML เลียน `swal2-popup` (28em, p-2rem, ไอคอน warning) และวางแบบ `absolute` ให้ backdrop คลุมทั้งภาพ fullPage (ของจริงเป็น `fixed`) · กรอบโฟกัสบนปุ่ม "ยกเลิก" แทน `focusCancel`
- ข้อมูลร้านที่ 2 (ชื่อลูกค้า/สินค้า/เบอร์) และร้าน "BT สาขาบางนา (ถูกล็อก)" สมมติขึ้นเพื่อโชว์ชิปขายของ, "ลูกค้าไม่ระบุชื่อ" ไม่มีเบอร์ และแถว EXCLUDED — ยอดยังตรง §A1 (12,800 = 9,500 + 3,300; กลุ่ม 62,000)
- คำเรียกใบของร้านขายของใช้ "คำสั่งซื้อ" และหัวคอลัมน์ "สินค้า" (ของจริงมาจาก `reportOrderWord()` / `resolveProductVocab`)
- GROUP HERO ที่ md+ แบ่ง 2 คอลัมน์: ขวาใส่ "รายการ 8 · ยกเลิก 1 ใบ" + ข้อความกติกา (สเปกไม่ได้กำหนดว่าขวาใส่อะไร) · ShopSummary มีป้าย "ยอดขายร้านนี้" ซึ่งสเปกไม่ได้เขียนถ้อยคำไว้
- โลโก้ PNG ไม่มี alpha จึงเห็นกล่องขาวบนพื้น `#f6f7fb` — ของจริงใช้ไฟล์เดียวกันจะเห็นแบบนี้ด้วย
- ไม่ได้ทำ state 429 / error / loading / TEST / MISMATCH / ตัดแถว 150 / ไม่เปิดยอดขาย / ไม่เปิดค่าใช้จ่าย (ไม่อยู่ในรายการที่สั่ง)
- `.card-header` padding 15px และ `.badge` ใช้ค่า arbitrary ใน CSS จำลอง (ตรงกับค่าธีม) — โค้ดจริงใช้คลาส Paces ไม่ต้อง arbitrary
