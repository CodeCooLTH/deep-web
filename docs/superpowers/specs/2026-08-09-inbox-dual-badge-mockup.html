รู้บัญชี — โลโก้เพจเหมือนกัน (เคส BT)อ่านข้อความอ่านข้อความอยู่ดี
พื้นที่หน้าลูกค้าที่เหลือ~30px~22px
ความสูงแถวเท่ากันเท่ากัน
ยังต้องมีบรรทัดที่มาไหมต้องมีต้องมี (โลโก้ซ้ำกันได้)

ข้อสังเกตก่อนตัดสิน

1. ได้ประโยชน์เฉพาะร้านที่โลโก้เพจต่างกัน — การ์ดกลางคือร้าน BT ของจริง มุมขวาเป็นรูปเดียวกันทั้ง 3 แถว ส่วนการ์ดขวาคือร้านสมมติที่แต่ละสาขาใช้โลโก้ต่างกัน ซึ่งแยกได้ทันทีจริง
2. บรรทัดที่มายังต้องอยู่ — เพราะโลโก้เพจซ้ำกันได้เสมอ ตัดออกไม่ได้ ดังนั้นแบบ 2 มุมคือ "เพิ่มของ" ไม่ใช่ "แทนของเดิม"
3. avatar เหลือ ~22px — user เคยรายงานเรื่อง badge บังรูปโปรไฟล์มาแล้วเมื่อ 2026-07-23 จนต้องลด badge จาก 20px เหลือ 16px
4. ทางสายกลาง — แสดงมุมซ้ายเฉพาะเมื่อรูปเพจในร้านนั้น ต่างกันจริง (หลักการเดียวกับที่เราซ่อนบรรทัดที่มาเมื่อมีบัญชีเดียว คือไม่แสดงสิ่งที่ไม่ให้ข้อมูล) — ร้านอย่าง BT จะเห็นเหมือนแบบ C ทุกประการ ส่วนร้านที่โลโก้ต่างกันจะได้ badge คู่เต็ม ๆ
