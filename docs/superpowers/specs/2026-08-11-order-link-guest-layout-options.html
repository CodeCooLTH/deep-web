แบบ ค — เปลี่ยนน้อยที่สุด ยังได้ปกไล่สีและสถิติร้านในจอแรก ใช้ขอบสี+เงายกการ์ดสถานะแทนการย้ายตำแหน่ง แลกด้วย สถานะที่ยังไม่ได้อยู่บนสุด และ “ขอบสีบอกความสำคัญ” เป็นภาษาที่หน้าอื่นฝั่งผู้ซื้อยังไม่ได้ใช้ที่ไหนเลย
