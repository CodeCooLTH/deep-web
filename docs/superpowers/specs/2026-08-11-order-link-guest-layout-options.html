Impeccable audit — สิ่งที่ต้องแก้ไปพร้อมกับโครงใหม่

คอนทราสต์ตก AA 7 จุด — color='text.disabled' คือ ink ที่ opacity 0.4 = 2.30:1 บนพื้นขาว (เกณฑ์ 4.5:1) ใช้อยู่ที่ eyebrow 3 อัน · "แจ้งร้านค้าว่าคำสั่งซื้อนี้มีปัญหา" · "ปกป้องการซื้อขายโดย Deep" · คำอธิบายใต้ปุ่มหลัก · ทางแก้ไม่ใช่เปลี่ยนเฉด — text.secondary (0.7) ได้ 5.22:1 ผ่านสบาย เป็นเฉดเดียวกันแค่เข้มขึ้น ตาม Hue-Preserving Contrast Rule

ทั้งหน้าไม่มี heading สักตัว — ชื่อร้านเป็น Typography component={Link} variant='h6' ซึ่งเรนเดอร์เป็น <a> ไม่ใช่ <h1> ส่วนหัว section เป็น overline บน <span> ⇒ ผู้ใช้ screen reader กระโดดตามหัวข้อไม่ได้เลยทั้งหน้า

tap target ต่ำกว่า 44px — "ยังไม่ได้รับสินค้า?" เป็น variant='text' size='small' สูงราว 30px ขัดเกณฑ์ที่ PRODUCT.md ตั้งไว้เอง (≥44px สำหรับกลุ่มผู้สูงวัย/digital-literacy ต่ำ)

ชื่อร้าน noWrap + title — ชื่อยาวถูกตัดแล้วอ่านต่อไม่ได้เลยบนมือถือ เพราะ title ต้อง hover ซึ่งเป็นบทเรียนที่โปรเจกต์เขียนไว้แล้วใน aria-name-requires-supporting-role.md

สีนอก token 1 จุด — bgcolor:'rgba(40,199,111,0.15)' ที่ป้าย "ซื้อจริง" ทั้งที่ค่าเดียวกันมีอยู่แล้วใน VERIFY_BADGE_PALETTE.green.bg และไฟล์นั้นก็ import VERIFIED_INK จาก SSOT เดียวกันมาใช้อยู่แล้ว

ทั้ง view เป็น 'use client' ทั้งที่เนื้อหาเกือบทั้งหมดคงที่ — มีของที่ต้องเป็น client จริงแค่ ping auth-flow/start ตัวเดียว จอแรกที่ผู้ซื้อทุกคนเจอบนมือถือจึงแบก JS ทั้งต้นไม้ไปโดยไม่จำเป็น

ที่ทำไว้ดีแล้วและต้องรักษาไว้ — env(safe-area-inset-bottom) ที่แถบ CTA · คำอธิบายว่าทำไมที่อยู่ถึงถูกปิดบัง · ShopEvidence/TrustPill/ShopCover ถูกยกเป็นไฟล์ร่วมของสองจอแล้ว · detector deterministic ผ่าน 0 finding บนไฟล์กลุ่มนี้
