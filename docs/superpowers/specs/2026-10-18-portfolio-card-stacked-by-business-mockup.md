## คำขอ (user 2026-10-18)
- มุมมองเจ้าของธุรกิจ: ยอดขายของทุกธุรกิจที่เป็นเจ้าของ (เจ้าของหลัก/เจ้าของร่วม — `listOverviewShops`)
- ยอด = ทุกรายการที่ไม่ยกเลิก (ยืนยัน/ปิดงานแล้ว + รอ) — ห้ามคำแปลก ๆ ใช้ "ยืนยันแล้ว" / "รอยืนยัน" เดิม
- กราฟเป็นแท่งซ้อน แยกสีต่อธุรกิจ · legend มีโลโก้ธุรกิจ

## แบบในม็อกอัพ
- เลขใหญ่ = ยอดรวมทุกธุรกิจ · **ไม่มีบรรทัดยืนยันแล้ว/รอยืนยัน** (user สั่งตัด 2026-10-18 — การ์ดนี้แยกตามธุรกิจแทน)
- legend 1 แถวต่อธุรกิจ: แถบสี (= สีแท่ง) · โลโก้ 24px · ชื่อเต็ม (ตัด …) · ยอดของธุรกิจนั้น — เรียงยอดมากไปน้อย · tablet 2 คอลัมน์
- สีแท่งชุดเดียวกับ `PortfolioPanel` (`stackColorToken` · เกิน 5 ร้าน = "อื่น ๆ" สีเทา)
- **ไม่มีเส้น/ตัวเลขจำนวนคำสั่งซื้อ (บริการ)** — user สั่งตัด 2026-10-18 ทั้งบนการ์ดและ tooltip
- desktop ≥1024 ไม่มีการ์ดนี้ — ใช้ `PortfolioPanel` เดิม

## ประเด็นที่ต้องตัดสิน
1. โลโก้ 2 สาขาเกือบเหมือนกัน (ดำ-ทอง ต่างแค่ชื่อสาขาตัวเล็ก) ⇒ ต้องมีชื่อคู่โลโก้เสมอ
3. แผง desktop `PortfolioPanel` แท่งยังนับเฉพาะงานที่ปิดแล้ว (คู่กับกำไรในตาราง) — ให้รวมงานที่ยังไม่ปิดเหมือนการ์ดไหม
4. ค่าใน stack ต่อร้านตอนนี้ = `series.values` (ร้านบริการ = ปิดงานแล้วเท่านั้น) ⇒ build ต้องบวก `unclosedValues` ต่อร้านด้วย ไม่งั้นแท่งรวมไม่เท่าเลขใหญ่
