โจทย์ที่แก้: "รก ดูไม่ออกว่าอะไรสำคัญ" — ไม่ใช่เรื่องจำนวนแถว
หลักที่ยืมมาจากระบบอ้างอิง: มีของที่เด่นแค่ชิ้นเดียวในจอ ที่เหลือถอยเป็นพื้นหลัง
สี = Paces น้ำเงิน #236dc9 ไม่ใช่เขียวของ ref (Hard Rule 6: เอาโครงตาม ref แต่ skin ตามธีมปัจจุบัน)

สิ่งที่เปลี่ยนจากของเดิม

1. ช่องทาง → segmented control ก้อนเดียว — พื้นเทาชิ้นเดียว ตัวที่เลือกเป็นการ์ดขาวยกขึ้น (เดิมเป็น pill 4 ก้อนลอยแยก ดูเป็นของ 4 ชิ้นทั้งที่เป็นตัวเลือกชุดเดียวกัน)
2. ปุ่มตัวกรอง → เส้นขอบสี primary — เป็น "ของเด่นชิ้นเดียว" ที่ตาเกาะ พร้อมตัวเลขบอกจำนวนที่กรองอยู่
3. ในดรอป → ชิปพับได้ แทนรายการแนวตั้งยาว — เห็นทั้งหมดในจอเดียว ไม่ต้องเลื่อน (แก้บั๊กเลื่อนไม่ได้ไปในตัว)
4. มีปุ่ม "ใช้ตัวกรอง" / "ล้างตัวกรอง" — มีจุดจบชัดเจน (เดิมเปลี่ยนแล้วมีผลทันที ไม่รู้ว่าจบเมื่อไหร่)
5. เพจย้ายเข้าไปเป็นชิปในดรอป — ไม่ต้องมีดรอปดาวน์แยกอีกแถว

V1 — กลุ่มเป็นแท็บข้อความมีเส้นใต้ (กลุ่มยังคลิกเดียว)

แถวล่างมี "ปิดงาน" กับ "สแปม" เป็นมุมมองพื้นฐาน (ลบไม่ได้) ต่อด้วยเส้นคั่นแล้วจึงเป็นกลุ่มที่ร้านสร้างเอง
สแปมใช้สี danger ของ Paces (#f7577e) ตั้งแต่ยังไม่ถูกเลือก — เป็นถังที่ "ไม่ควรมีอะไรอยู่" ต่างจากมุมมองปกติ กวาดตาเจอโดยไม่ต้องอ่าน
เมื่อสถานะ/สแปมขึ้นมาเป็นแท็บแล้ว จึงถูกถอดออกจากดรอป — ไม่งั้นจะคุมเรื่องเดียวกันจาก 2 ที่แล้วขัดกันเอง
ได้: สลับกลุ่ม/ปิดงาน/สแปม ยังคลิกเดียว · แท็บข้อความมีน้ำหนักต่างจาก segmented ชัด ไม่กวนกัน · ดรอปสั้นลงจนไม่ต้องเลื่อน
กลุ่ม "พัสดุ (iShip)" (user สั่ง 2026-07-31) — ดูที่ ออเดอร์ล่าสุด ของลูกค้าคนนั้น เพื่อให้สอดคล้องกับชิปสถานะที่มีอยู่แล้วในแถว (ซึ่งก็อ้างออเดอร์ล่าสุดเหมือนกัน) จะได้ไม่ขัดกันเอง หัวข้อนี้โผล่เฉพาะร้านที่เชื่อม iShip แล้ว (มี ShopShippingAccount status=ACTIVE)
แท็กกรองได้แล้ว (user สั่ง 2026-07-31) — เลือกหลายอันได้ ติดอันใดก็ได้ (OR) โชว์ครบพับหลายบรรทัด ดึงรายการจาก GET /api/chat/tags ที่มีอยู่แล้ว
