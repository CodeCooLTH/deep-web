## 6. Trust Score v2 (00040) — เอกสารเสร็จ ตัวเลขเคาะครบ ยังไม่ implement

`docs/20 - Features/00040 - Trust Score v2/` มี **PRD.md + BRD.md** (ยังขาด SRS/SDS/API/DATABASE/TestCase ตาม template 7 ไฟล์)

มติ D-1..D-9 + ตัวเลข Q-1..Q-6 ล็อกครบใน **BRD §11** ที่สำคัญ:
- ช่องออเดอร์ = `max(rolling 90 วัน, ตลอดชีพ × 0.4)` · อายุร้าน = `min(10, round(sqrt(วัน/365) × 10))` · penalty = `min(10, round(max(0, 97 − rate) / 5))` (ยกเลิกฟรี 3%)
- ถอด `Math.max(เดิม, ใหม่)` ใน `trust-score.service.ts` ออก · cron รายวัน · **เขียน `TrustScoreHistory` เฉพาะตอนคะแนนเปลี่ยนจริง**
- 🛑 **Q-3 กับดักใหญ่:** หน้าต่าง 90 วันต้องนับ `OrderEvent` ของ **`SYSTEM_CONFIRMED` / `COD_SETTLED` / `BUYER_CONFIRMED` รวมกัน** — **ห้ามหยิบ `BUYER_CONFIRMED` ชนิดเดียวแม้ชื่อจะฟังดูตรงที่สุด เพราะบน prod = 0 ใบ** จะทำให้ทุกร้านได้ rolling = 0 โดยไม่มี error สักตัว · `Order.createdAt` ห้ามใช้ (00033 ผู้ขายพิมพ์เอง) · `Order.updatedAt` ห้ามใช้ (เพี้ยนเฉลี่ย 38.5 ชม. สูงสุด 119.7 ชม.)

**⚠️ ลำดับที่ตกลงกันไว้:** ทำให้คะแนน **ขึ้นได้ก่อน** (ปลดล็อกยืนยันตัวตน + รีวิว) แล้วค่อย implement v2 — ไม่งั้นได้ระบบที่ลงโทษเป็นแต่ให้รางวัลไม่เป็น

## 8. วิธี query prod แบบอ่านอย่างเดียว (ใช้ได้จริง ทำมาแล้วทั้ง session)

```bash
vercel env pull /tmp/p.env --environment=production --yes >/dev/null 2>&1
PGURL=$(grep -E '^DIRECT_URL=' /tmp/p.env | sed 's/^DIRECT_URL=//; s/^"//; s/"$//')
/opt/homebrew/opt/libpq/bin/psql "$PGURL" -X -q <<'SQL'
BEGIN READ ONLY;
-- SELECT เท่านั้น
COMMIT;
SQL
rm -f /tmp/p.env
```

- `.env.local` = **localhost:5434 (dev)** · `.env.vercel-prod` ในเครื่อง**ก็ชี้ localhost เป็นไฟล์เก่า อย่าเชื่อ** ต้อง `vercel env pull` สดทุกครั้ง
- `psql` อยู่ที่ `/opt/homebrew/opt/libpq/bin/psql` (ไม่อยู่ใน PATH)
- **ลบไฟล์ env ทิ้งทุกครั้งหลังใช้**
- `grep -E` ล้มกับข้อความไทยเพราะ locale → ใช้ `LC_ALL=C grep -a` และ**ตัดสินผลเทสด้วย exit code ไม่ใช่ grep**
- ห้ามรันอะไรที่ไม่ใช่ SELECT (Hard Rule 14)
