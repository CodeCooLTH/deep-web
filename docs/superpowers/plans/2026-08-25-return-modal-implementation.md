## 3. กับดักที่เสียเวลาไปแล้วในรอบก่อน — อย่าเหยียบซ้ำ

1. **`btn-primary` / `btn-light` ไม่มีอยู่ในธีม** — `.btn` ให้แค่ layout ไม่มี background ⇒ ปุ่มเป็นตัวหนังสือเทา หัวหน้ารายงานว่า "เลือกไม่ได้" (แก้แล้ว + มีด่าน)
2. **`git add -A` พาไฟล์ที่ไม่ตั้งใจขึ้น main** (CSS 1MB) — ตรวจ `git status` ก่อน commit เสมอ
3. **แถบเครื่องมือ/overlay ห้ามทับปุ่มที่กำลังประเมิน**
4. **`component` ที่ประกาศในตัว render** ⇒ input หลุดโฟกัสทุกตัวอักษร — eslint จับได้ อย่าปิด
5. **mutation เขียว ≠ ผ่าน** — แปลว่าชุด input อ่อน ต้องเติม input แล้วรัน mutation เดิมซ้ำจนแดง
6. **grep คลาส/คำต้องตัดคอมเมนต์ก่อน** — ไฟล์ที่ทำถูกคือไฟล์ที่เขียนคำเตือนของกฎนั้นไว้
7. **verify หลัง rebase เสมอ + เช็ค fast-forward แยกคำสั่งก่อน push** (HR17)
