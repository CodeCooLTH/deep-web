## ⚠️ เกือบรายงานผิดเป็นบั๊ก (บทเรียนซ้ำรอย P-5)

รอบแรกอ่านหน้าจอครั้งเดียวที่ **+5 วินาที** หลังกดบันทึก แล้วเห็นว่ายังเป็นเลขเดิม → เกือบสรุปว่า "S-12 acceptance (2) ค่าใหม่ไม่แสดงทันที = บั๊ก"

ตรวจซ้ำด้วยการ poll เป็นช่วง ๆ พบว่า `router.refresh()` **ทำงานถูกต้อง** แต่บน dev server ใช้เวลา ~4–6 วินาที (Turbopack ต้อง recompile RSC) — จังหวะที่อ่านครั้งเดียวไปตกก่อนที่ refresh จะลงพอดี บน prod ที่ build แล้วจะเร็วกว่านี้มาก

**บทเรียน:** การยืนยันเชิงเวลาต้อง **poll จนกว่าจะเข้าเงื่อนไขหรือหมดเวลา** ไม่ใช่ `sleep` ครั้งเดียวแล้วอ่าน — ไม่งั้นได้ false positive ที่ดูน่าเชื่อเพราะมีตัวเลขประกอบ
