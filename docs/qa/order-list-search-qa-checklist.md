## B. ค้นหา 5 ฟิลด์ — Happy path + parity มือถือ/เดสก์ท็อป (TC-001–013)
- [ ] เลขคำสั่งซื้อเต็ม → เจอ + ไฮไลต์ (มือถือ+เดสก์ท็อป ผลเท่ากัน)
- [ ] ชื่อผู้ซื้อ (บางส่วน) → เจอ + ไฮไลต์ ทั้ง 2 จอ
- [ ] เบอร์โทรตรงเป๊ะ → เจอ เบอร์ที่เห็นเต็มค่าไม่ปิดบัง ทั้ง 2 จอ
- [ ] เลขพัสดุเต็ม → เจอ + ไฮไลต์ ปุ่มคัดลอกยังกดได้
- [ ] ชื่อสินค้าที่แสดงอยู่แล้ว (ไม่ถูกยุบ) → เจอ + ไฮไลต์
- [ ] ชื่อสินค้าที่ถูกยุบซ่อน (item ≥3 เดสก์ท็อป / ≥2 มือถือ) → **กางอัตโนมัติ** + ไฮไลต์
- [ ] กางอัตโนมัติแล้วกดย่อเอง → ย่อได้จริง ไม่เด้งกางกลับ
- [ ] หลายคำ AND ข้ามคนละฟิลด์ (ชื่อ+สินค้า) → เจอเฉพาะใบที่ตรงทั้งคู่
- [ ] เบอร์เก็บไม่มีขีด พิมพ์มีขีด → เจอ + ไฮไลต์ทั้งก้อน
- [ ] เบอร์เก็บมีขีด พิมพ์ไม่มีขีด → เจอ + ไฮไลต์ทั้งก้อน
- [ ] เลขคำสั่งซื้อมีตัวอักษรปน พิมพ์ท่อนมีตัวอักษร → เจอแบบ substring (ไม่ตัดสัญลักษณ์)
- [ ] ไฮไลต์บนเลขคำสั่งซื้อ (ลิงก์น้ำเงิน) ไม่กลายเป็นสองเฉด (`inheritColor`)

## C. เกณฑ์ขั้นต่ำ + ล้างคำค้น (TC-014–017)
- [ ] พิมพ์ 1 ตัวอักษร มือถือ → ไม่กรอง + ข้อความ "พิมพ์อีก 1 ตัว" (เทาไม่ใช่แดง)
- [ ] พิมพ์ 1 ตัวอักษร เดสก์ท็อป → ไม่กรอง ไม่มีข้อความเตือน (ปกติ ไม่ใช่บั๊ก)
- [ ] ปุ่ม × ล้างคำค้น มือถือ — พื้นที่แตะ ≥44×44px (วัดจริงด้วย DevTools)
- [ ] ปุ่ม × ล้างคำค้น เดสก์ท็อป — table reset กลับหน้า 1

## D. ตรงเต็มค่าลอยบนสุด (TC-018–019)
- [ ] เบอร์ตรงเต็มค่า → ลอยบนสุด + ring (มือถือ) / พื้นจาง (เดสก์ท็อป)
- [ ] ชื่อผู้ซื้อตรงเป๊ะ (ซ้ำกัน) → **ไม่**ลอยขึ้น ไม่มีสัญญาณภาพ

## E. ผลว่างเพราะตัวกรอง — จุดเสี่ยงสูงสุด (TC-020–027)
- [ ] ตัวกรองสถานะ (แท็บ/ชิปมือถือ) บัง → "พบ N ในทั้งร้าน" + ปุ่มกดแล้ว **ชิปกลับเป็นทั้งหมดจริง** + เห็นผล
- [ ] ตัวกรองกองพัสดุ (stage chip มือถือ) บัง → ปุ่มล้าง stage จริง
- [ ] ตัวกรองประเภทออเดอร์ (โมดัลมือถือ) บัง → ปุ่มล้าง + เปิดโมดัลซ้ำเห็นค่ากลับเป็น "ทุกประเภท"
- [ ] ตัวกรองช่วงเวลา (โมดัลมือถือ) บัง → ปุ่มล้าง + เปิดโมดัลซ้ำเห็นค่ากลับเป็น "ทั้งหมด"
- [ ] ตัวกรองสถานะ (dropdown เดสก์ท็อป) บัง → ปุ่มล้าง columnFilters จริง
- [ ] ตัวกรองขนส่ง (dropdown เดสก์ท็อป) บัง → ปุ่มล้างจริง
- [ ] ตัวกรองช่วงเวลา (dropdown เดสก์ท็อป) บัง → ปุ่มล้างจริง
- [ ] ผลว่างจริง N=0 → **ไม่มี**ปุ่ม/ข้อความ "ในทั้งร้าน" โผล่มาหลอก
