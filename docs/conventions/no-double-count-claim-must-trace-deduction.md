# ข้ออ้าง "ไม่คิดซ้ำ" ต้องไล่เส้นทางหักจริง

## กฎ
เมื่อโค้ดตั้งค่าใช้จ่ายก้อนหนึ่งเป็น 0 ด้วยเหตุผล "ก้อนนี้ถูกหักที่อื่นแล้ว" (กันนับซ้ำ):
1. **ชี้ไฟล์:บรรทัด** ที่หักก้อนนั้นจริงในคอมเมนต์ ไม่ใช่แค่ "อยู่ในค่าส่งแล้ว"
2. **ไล่ทุกประเภทร้าน** — กติกาการเงินแยกตาม `usesServiceFinanceRules(vertical)` (ร้านบริการ vs ร้านอื่น) ถ้าที่อื่นหักเฉพาะบางประเภท เงื่อนไข "ไม่คิดซ้ำ" ต้องผูกกับเงื่อนไขเดียวกัน (ส่ง flag เข้าไป เช่น `codFeeInShipping`)
3. **เทสสองขา**: ประเภทที่หักที่อื่นแล้ว = 0 · ประเภทที่ไม่ได้หัก = ต้องมีค่า

## ทำไม
00096 P2 (2026-11-16): `orderVariableCost` ข้าม % COD เมื่อพัสดุ iShip มี `codFee` เพราะ "codFee อยู่ในค่าส่งขาไปแล้ว" — จริงเฉพาะร้านบริการ ร้านขายของไม่ถูกหักค่าส่งขาไป (มติ 2026-10-02) ⇒ codFee หายเงียบ กำไรสูงเกินจริงทุกใบ COD · เทสทั้งชุดเขียว เพราะเทสมีแต่ขาที่หักแล้ว · reviewer อิสระจับได้ก่อน merge

- grep คอมเมนต์ "ไม่คิดซ้ำ|รวมอยู่ใน|หักแล้ว" ในไฟล์ที่แตะ แล้วถามว่า "หักจริงที่ไหน กับร้านประเภทไหน"
