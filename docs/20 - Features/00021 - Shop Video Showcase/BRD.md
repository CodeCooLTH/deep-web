# BRD: Shop Video Showcase

## 1. เหตุผลทางธุรกิจ

Deep ขายเรื่องเดียวคือ "ร้านนี้เชื่อถือได้ไหม" ทุกอย่างบนหน้าร้านต้องตอบคำถามนี้ ตัวเลขสถิติตอบได้ว่าร้านเคยขายมาแล้วกี่ครั้ง แต่ไม่ได้ตอบว่าของหน้าตาเป็นยังไงและร้านมีของอยู่จริงไหม

คลิปที่ร้านถ่ายเองตอบได้ทั้งสองอย่างพร้อมกัน และตอบด้วยหลักฐานที่ปลอมยากกว่าข้อความ

## 2. กฎธุรกิจ

| รหัส | กฎ | เหตุผล |
|---|---|---|
| BR-V1 | คลิปที่ปักหมุดได้ต้องมาจากบัญชีที่ร้านเชื่อมและยืนยันความเป็นเจ้าของแล้วเท่านั้น | ถ้าเอาคลิปใครก็ได้มาอ้าง ตัวคลิปจะไม่มีน้ำหนักเป็นหลักฐานอีกต่อไป และแย่กว่านั้นคือกลายเป็นเครื่องมือให้ร้านหลอกลวงยืมความน่าเชื่อถือของคนอื่น |
| BR-V2 | ปักหมุดได้ไม่เกิน 6 คลิปต่อร้าน | หน้าร้านต้องพาไปสู่การตัดสินใจ ไม่ใช่กลายเป็นฟีดคลิป |
| BR-V3 | ตัวเลขยอดวิว/ไลก์ที่แสดง ต้องเป็นค่าที่ได้จากแพลตฟอร์มโดยตรงเท่านั้น | ตัวเลขที่ร้านกรอกเองได้เท่ากับไม่มีความหมาย และขัดกับหลักที่ใช้กับสถิติอื่นทั้งหน้า |
| BR-V4 | ไม่มีตัวเลข = ไม่แสดงช่องนั้น ไม่ใช่แสดง 0 | 0 สื่อว่า "มีคนดูศูนย์คน" ซึ่งเป็นคนละเรื่องกับ "เราไม่รู้" |
| BR-V5 | ร้านถอดคลิปออกได้ตลอดเวลา ไม่ต้องขออนุมัติ | เป็นพื้นที่ของร้านเอง |
| BR-V6 | ระบบไม่เก็บสำเนาคลิป อ้างอิงไปที่แพลตฟอร์มต้นทางเสมอ | ร้านลบคลิปที่ต้นทางแล้วต้องหายจากหน้าร้านด้วย ไม่ใช่ยังค้างอยู่ในระบบเรา |

## 3. ผู้เกี่ยวข้อง

| ฝ่าย | ได้อะไร | เสียอะไร |
|---|---|---|
| ผู้ซื้อ | เห็นของจริงก่อนโอนเงิน | หน้าร้านหนักขึ้นถ้าเปิดคลิป (บรรเทาด้วยการโหลดเมื่อกดเท่านั้น) |
| ร้าน | เอาคลิปที่ลงทุนถ่ายไว้แล้วมาใช้ซ้ำโดยไม่ต้องทำอะไรเพิ่ม | ต้องเชื่อมบัญชีก่อน |
| Deep | หน้าร้านมีน้ำหนักขึ้นโดยไม่ต้องเก็บไฟล์วิดีโอเอง | ผูกกับ API ของแพลตฟอร์มที่เราคุมไม่ได้ |

## 4. ตัวชี้วัด

- สัดส่วนร้านที่เชื่อมช่องทางแล้วปักหมุดคลิปอย่างน้อย 1 คลิป
- สัดส่วนผู้ชมหน้าร้านที่กดเล่นคลิปอย่างน้อย 1 อัน
- ยังไม่มีการวัดผลต่อยอดสั่งซื้อ — ต้องรอปริมาณข้อมูลมากพอก่อน

## 5. ต้นทุน

ไม่มีค่าใช้จ่ายเพิ่ม — ใช้ token เดิมจากการเชื่อมช่องทางแชท ไม่มีที่เก็บไฟล์เพิ่ม ไม่มีบริการภายนอกใหม่
