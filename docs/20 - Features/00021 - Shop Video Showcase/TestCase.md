# Test Cases: Shop Video Showcase

## 1. Unit — `src/lib/shop-video.test.ts` (16 เคส, ผ่านทั้งหมด)

ตัวนี้เป็นด่านกันลิงก์หลอกลวงบนหน้าที่ผู้ซื้อใช้ตัดสินใจโอนเงิน เทสจึงเน้นทางที่ **ควรถูกปฏิเสธ** มากกว่า happy path

| กลุ่ม | เคส | คาดหวัง |
|---|---|---|
| ผ่าน | TikTok/YouTube Shorts/watch/youtu.be/IG reel·reels·p, FB reel·videos·watch | ได้ `{provider, videoId}` ถูกต้อง |
| ผ่าน | มี query string ติดมา (ลิงก์แชร์จริงมักมี) | ยังแยกรหัสได้ |
| ปฏิเสธ | โดเมนอื่น รวม `tiktok.com.evil.com`, `notyoutube.com` | `null` |
| ปฏิเสธ | `http://` ธรรมดา | `null` — ถูกดักแก้ระหว่างทางได้ |
| ปฏิเสธ | ลิงก์ย่อ `vm.tiktok.com`, `vt.tiktok.com`, `facebook.com/share/r/…` | `null` — SSRF |
| ปฏิเสธ | รหัสมีอักขระที่หลุด path เช่น `..%2F..%2Fadmin`, มีช่องว่าง | `null` |
| ปฏิเสธ | `javascript:`, `data:`, สตริงว่าง, ข้อความไทย | `null` |
| ประกอบ URL | YouTube ใช้โดเมน `youtube-nocookie` | ไม่ตั้ง cookie ติดตามจนกว่าจะกดเล่น |
| ประกอบ URL | hostname ของ URL ที่ประกอบออกมา | อยู่ในโดเมนที่ตั้งใจเสมอทั้ง 3 แพลตฟอร์ม |
| ประกอบ URL | FB ต้องชี้ `/plugins/video.php` และ `href` ถูก encode | ผ่าน |

รัน: `npx vitest run src/lib/shop-video.test.ts`
