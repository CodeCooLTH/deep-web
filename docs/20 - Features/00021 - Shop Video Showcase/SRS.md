# SRS: Shop Video Showcase

## 1. Functional Requirements

### FR-V1 — รายการคลิปที่เลือกได้
ระบบต้องดึงคลิปจากทุกช่องทางที่ร้านเชื่อมไว้ (Facebook Page, Instagram Business) มาแสดงให้ร้านเลือก โดยจัดกลุ่มเป็นแท็บแยกราย**บัญชี** ไม่ใช่รายแพลตฟอร์ม เพราะร้านเดียวมีได้หลายเพจ

**Acceptance**
- ร้านที่เชื่อม 1 เพจ + 1 IG เห็น 2 แท็บ พร้อมจำนวนคลิปของแต่ละบัญชี
- ร้านที่ยังไม่เชื่อมช่องทางใดเลย เห็นสถานะว่าง พร้อมทางไปหน้าเชื่อมช่องทาง
- ดึงจากบางช่องทางไม่สำเร็จ ต้องยังแสดงช่องทางที่สำเร็จได้ ไม่ใช่ล้มทั้งหน้า

### FR-V2 — บันทึกคลิปที่ปักหมุด
ร้านเลือกได้สูงสุด 6 คลิป ลำดับการกดเลือกคือลำดับที่แสดงบนหน้าร้าน

**Acceptance**
- เลือกครบ 6 แล้ว ปุ่มเลือกเพิ่มต้องไม่ทำงาน
- กดซ้ำที่คลิปเดิม = ถอดออก และลำดับของคลิปที่เหลือต้องเรียงใหม่ให้ต่อเนื่อง
- บันทึกแล้วเปิดหน้าใหม่ ต้องเห็นสิ่งที่เลือกไว้เดิม

### FR-V3 — ตรวจความเป็นเจ้าของตอนบันทึก (สำคัญที่สุด)
ทุกคลิปใน payload ต้องถูกตรวจกับรายการสดจากแพลตฟอร์มอีกครั้งฝั่ง server ก่อนบันทึก

**Acceptance**
- คลิปที่ไม่อยู่ในรายการของบัญชีที่เชื่อมไว้ → ปฏิเสธด้วย 403 `NOT_OWNED`
- **ดึงรายการจากแพลตฟอร์มไม่สำเร็จ → ต้องตอบ 503 `VERIFY_UNAVAILABLE` ไม่ใช่ 403** — ตรวจไม่ได้ กับ ตรวจแล้วไม่ใช่ของคุณ เป็นคนละเรื่อง การเหมารวมทำให้ร้านที่สุจริตโดนกล่าวหา
- ต่อให้ payload ถูกแก้ระหว่างทาง ก็บันทึกคลิปที่ไม่ใช่ของร้านไม่ได้

### FR-V4 — แสดงบนหน้าร้านสาธารณะ
คลิปที่ปักหมุดแสดงเป็นแท็บแรกชื่อ "ปักหมุด" บน `/u/[username]` และ `/b/[slug]`

**Acceptance**
- ไม่มีคลิป = ไม่มีแท็บนี้ (ไม่ใช่แท็บว่าง)
- มือถือ 3 คลิปต่อแถว, เดสก์ท็อป 5 ต่อแถว, สัดส่วน 9:16
- แสดงรูปปกก่อน โหลด iframe เมื่อผู้ชมกดเท่านั้น
- แต่ละคลิปแสดงโลโก้แพลตฟอร์ม ชื่อบัญชี และยอดเท่าที่มี

### FR-V5 — ตัดข้อมูลที่แสดงไม่ได้ออก
แถวที่บันทึกด้วยโค้ดรุ่นก่อนแก้บั๊กเก็บ media id ของ Instagram แทน shortcode ซึ่งประกอบ URL ฝังแล้วเปิดไม่ขึ้น ต้องคัดออกจากการแสดงผล

**Acceptance:** แถว Instagram ที่ `videoId` เป็นตัวเลขล้วน ต้องไม่ถูก render

## 2. Non-Functional Requirements

| รหัส | ข้อกำหนด |
|---|---|
| NFR-V1 | หน้าร้านต้องไม่โหลดสคริปต์ของแพลตฟอร์มใด ๆ จนกว่าผู้ชมจะกดเล่น |
| NFR-V2 | iframe ต้องจำกัดสิทธิ์ด้วย `sandbox` แน่นที่สุดเท่าที่ยังเล่นได้ และ `referrerPolicy` ต้องไม่ส่ง path เต็มออกไป |
| NFR-V3 | URL ที่ใช้ฝังต้องประกอบขึ้นจากรหัสที่ผ่านการตรวจแล้วเท่านั้น ห้ามใช้ค่าที่ผู้ใช้กำหนดโดยตรง |
| NFR-V4 | ห้ามยิง request ตาม URL ที่ผู้ใช้กำหนดจากฝั่ง server (SSRF) — ลิงก์ย่อทุกชนิดต้องถูกปฏิเสธ |
| NFR-V5 | การดึงคลิปจากหลายช่องทางต้องทำขนานกัน และช่องทางหนึ่งล้มต้องไม่ทำให้ทั้งชุดล้ม |

## 3. Authorization

| การกระทำ | ใครทำได้ |
|---|---|
| ดูรายการคลิปที่เลือกได้ | เจ้าของ/พนักงานของร้านที่ active อยู่ |
| บันทึกคลิปที่ปักหมุด | เจ้าของ/พนักงานของร้านที่ active อยู่ **และ** คลิปต้องอยู่ในบัญชีที่ร้านนั้นเชื่อมไว้ |
| ดูคลิปบนหน้าร้าน | ทุกคน ไม่ต้องล็อกอิน |

ขอบเขตร้านมาจาก `requireActiveShop(session)` — ไม่รับ `shopId` จาก request

## 4. ข้อจำกัดที่รู้อยู่

- Instagram ยังไม่มียอดวิว จนกว่าร้านจะเชื่อมบัญชีใหม่เพื่อให้ token มี scope `instagram_manage_insights`
- TikTok / YouTube ยังเชื่อมบัญชีไม่ได้
- ยอดที่แสดงเป็นค่า ณ เวลาบันทึก
