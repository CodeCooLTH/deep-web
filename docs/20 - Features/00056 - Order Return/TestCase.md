# Test Case: ระบบคืนของ (Order Return)

---

## 1. Overview

ครอบ **ชีตคืนของ 3 ขั้น** (วิธีคืน+ขนส่ง → ของที่คืน → ตรวจก่อนยืนยัน) และเส้นทางหลังเปิดใบ
(ออกเลขพัสดุขากลับ / รับของคืน / ยกเลิก) · เอกสารต้นทาง = `BRD.md` §8 (BR-RT-15..46)

**สภาพแวดล้อมที่ใช้ทดสอบจริง:** `seller.deepth.local:4000` บนฐาน dev (แยกจาก prod ตั้งแต่
2026-08-01) ผ่าน `browser-harness` ที่ต่อ Chrome จริงด้วย CDP — **ไม่ใช่ jsdom** รีโปนี้ไม่มี

### 🛑 ส่วนที่อยู่นอกขอบเขตของการทดสอบบนเครื่อง — และทำไม

**ทุกเคสที่ต้อง "ยิง iShip จริง" (กลุ่ม TC-RT-3x) จะถูกทดสอบบน prod กับลูกค้าจริงเท่านั้น**
โดยหัวหน้าเป็นคนนัดหมายลูกค้าเอง (สั่งตรง 2026-08-26: *"ห้ามเทส ยิง API จริง · ต้องเขียนโค้ด
ไปแสดงบน prod แล้วผมติดต่อลูกค้าถึงจะยิงจริงเท่านั้น"*)

เหตุผลที่กติกานี้ถูกต้อง ไม่ใช่แค่ข้อจำกัด:
- การเปิดพัสดุขากลับ **ตัดเครดิต iShip ของร้านจริง** — ทุกครั้งที่ทดสอบคือเงินที่หายไปจริง
- ร้านบนฐาน dev ที่เชื่อม iShip เป็นของ user อื่น และ token เป็นของบัญชีจริง
- ⇒ เคสกลุ่มนี้ผ่านแค่ `tsc` + เทสหน่วย + การอ่านโค้ด **ต้องระบุตรง ๆ ว่ายังไม่มีใครเห็นมันทำงาน**
  (`known-limitation-vs-unfinished.md` — การรู้ตัวโดยไม่บอกมีค่าเท่ากับไม่รู้)
