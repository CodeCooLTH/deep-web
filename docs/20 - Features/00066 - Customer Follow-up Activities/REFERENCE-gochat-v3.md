> **นี่คือเอกสารของอีกระบบ** — ชื่อตาราง/คอลัมน์/สิทธิ์ต้องแปลงเป็นโมเดลของ Deep (Shop · Customer · Conversation · ShopMember) ก่อนใช้ และทุกข้อที่อ้างพฤติกรรมของ Deep ต้องยืนยันกับโค้ด Deep เอง (HR16)

## 1. Schema (`activities`)
- id uuid PK · tenant_id NOT NULL → tenants CASCADE
- contact_id NULL → contacts CASCADE (ผูกลูกค้าเป็นหลัก) · conversation_id NULL → conversations CASCADE (บริบทว่าจดจากห้องไหน)
- type text default 'follow_up' CHECK IN (follow_up=ตามเรื่อง, appointment=นัดหมาย, other=อื่นๆ)
- title text NOT NULL 1..200 · note text NULL (โค้ดจำกัด 1000)
- due_at timestamptz NOT NULL · all_day boolean default false (งานทั้งวัน due_at = ต้นวันเวลาไทย ห้ามโชว์เป็นเวลา)
- assignee_user_id NULL → users SET NULL (คนเดียว)
- status CHECK IN (open, done) · outcome NULL หรือ (status=done AND IN reached=ติดต่อได้·สนใจต่อ, no_answer=ไม่รับสาย, call_later=ขอให้ติดต่อใหม่, not_interested=ไม่สนใจแล้ว)
- done_at · done_by → users SET NULL · snooze_count int default 0 · created_by → users SET NULL · created_at/updated_at
- CHECK: contact_id IS NOT NULL OR conversation_id IS NOT NULL
- Index: (contact_id,status,due_at) partial · (conversation_id,status,due_at) partial · (tenant_id,due_at) WHERE open · (assignee,status,due_at) partial · (tenant_id,due_at) ไม่ partial สำหรับปฏิทิน (0107 — index partial เฉพาะ open ปฏิทินใช้ไม่ได้)
- audit: edit_events เพิ่ม entity 'activity'
- **ไม่มีแท็ก** (แท็กอยู่ที่ห้อง ตัวกรองแท็กตรงเมื่อห้องที่จด "หรือห้องไหนก็ได้ของลูกค้าคนนั้น" ติดแท็ก)
- **ไม่มีคอลัมน์เงิน** (ตั้งใจ — ยอดขายมีแหล่งเดียว)
- ไม่มีตารางประวัติการเลื่อน เก็บแค่ snooze_count (≥2 ขึ้นป้ายเตือน)

## 2. กติกาธุรกิจ
- สิทธิ์: ทุกคนในร้านสร้าง/แก้/ปิด/เปิดกลับ/เลื่อน/ลบได้ ไม่เทียบกับเจ้าของงาน (กะดึกปิดงานแทนกะบ่าย) · สร้าง/แก้หัวข้อ/ปิด/ลบ ลง audit · reopen/snooze ไม่ลง
- สถานะ open↔done · complete (outcome ไม่บังคับ กด "ข้าม" ได้) · reopen ล้าง outcome/done_at/done_by · snooze เฉพาะ open: เปลี่ยน due_at/all_day + snooze_count+1
- สร้าง: ไม่เลือกผู้รับผิดชอบ = คนสร้าง · type default follow_up · **สร้างได้จากห้องแชทเท่านั้น** · ห้อง 1:1 ที่รู้จักลูกค้าเก็บทั้ง contact+conversation · ห้องกลุ่มเก็บแค่ conversation
- "งานของห้องนี้": ห้อง 1:1 = งานทุกใบของลูกค้าคนนั้น **ทุกช่องทาง** · ห้องกลุ่ม/ยังไม่ผูกลูกค้า = เฉพาะห้องนั้น
- เกินกำหนด (กติกาที่เดียว `isOverdue`, SQL เขียนซ้ำให้ตรง): มีเวลา = due_at < now · ทั้งวัน = เลยเมื่อ **ขึ้นวันใหม่** · SQL `AT TIME ZONE 'Asia/Bangkok'` · ส่ง now จากข้างนอก
- bucketOf: late / today (ถึงสิ้นวันนี้) / week (ภายใน 7 วันหลังสิ้นวันนี้) / later — ⚠️ เคยโยนงานที่ปิดแล้วลง "วันนี้" (เช็ก status แค่ตอนตัดสินเลยกำหนด)
- ลบห้อง/ลูกค้า → งานลบตาม · ลบ user → assignee NULL ("ทีมงานที่ถูกถอดออกแล้ว") งานเป็นของร้าน
- ⚠️ ช่องโหว่ใน gochat: รวมลูกค้าแล้ว **ไม่ย้าย activities** → Deep ต้องรวมตั้งแต่ต้น
- ⚠️ ช่องโหว่ใน gochat: `quickWhen()` สร้าง "ต้นวัน" ตามนาฬิกาเครื่องผู้ใช้ ขณะ server ตัดวันตาม Bangkok → Deep คำนวณเวลาไทยตายตัว
- 🛑 ไม่ส่งอะไรหาลูกค้าเลย (นัดหมายก็ไม่ส่งข้อความ)

## 3. หน้าจอ
ฟิลด์บนการ์ด: ไอคอน+ป้ายชนิด · หัวข้อ · เวลากำหนด (ทั้งวันโชว์แค่วัน · "พรุ่งนี้ HH:mm") · ผู้รับผิดชอบ (รูป+ชื่อ แถวของตัวเอง) · โน้ต · ชิป "เลื่อนมา N ครั้ง" · ป้ายแดงเลยกำหนด · งานที่ปิดโชว์ผลลัพธ์ + ผู้ปิด/เวลา · หน้ารวม/bubble โชว์ชื่อ/รูปลูกค้า (ห้องกลุ่มถอยไปชื่อห้อง + ไอคอนกลุ่ม)
ปุ่มกลาง (ใช้ร่วมทุกหน้าจอ): ทำแล้ว → 4 ผล + ข้าม · เลื่อน → "พรุ่งนี้ 09:00" / "อีก 3 วัน" (ทั้งวัน) / "สัปดาห์หน้า" (ทั้งวัน) + เลือกเอง · แก้ · ลบ (ยืนยัน) · เปิดกลับ
- a) แผงขวาในห้องแชท: "กิจกรรม (n)" n = ที่ยังเปิด · **กางเองเมื่อมีงานเลยกำหนด** · open เรียงใกล้สุดก่อน · done 3 ใบล่าสุด · ฟอร์ม: หัวข้อ/ชนิด/วันเวลา/ทั้งวัน/ผู้รับผิดชอบ(สมาชิกร้าน)/โน้ต
- b) Bubble มุมขวาล่างหน้าแชท+ความคิดเห็น: งาน **ของฉัน** ที่เลยกำหนด+ครบวันนี้ · ไม่มีงาน=ไม่มีปุ่ม · แดงเมื่อมีเลยกำหนด · สูงสุด 8 แถว + ลิงก์หน้ารวม · "ทำแล้ว" ปิดทันทีไม่ถามผล · กดแถวเข้าห้อง · มือถือซ่อนตอนเปิดห้อง · ไม่มี realtime (โหลดตอนเปิดหน้า/เปิดกล่อง/หลัง action)
- c) หน้ารวม: กระดาน 5 คอลัมน์ (เลยกำหนด · วันนี้ · 7 วันข้างหน้า · ภายหลัง · ทำแล้วใน 7 วัน) · ไม่มีลากการ์ด · มือถือเป็นแท็บทีละคอลัมน์ · สลับปฏิทินเดือน (ทุกสถานะ งานปิดแล้วจาง · ช่องละ 3 ใบ + "+N" · popover ทำแล้ว/เลื่อน/เปิดแชท · ไม่สร้างงานจากปฏิทิน · เพดาน 1,000 ใบ/เดือน เกินขึ้นแถบเตือน · มือถือเป็นจุดสี) · ตัวกรอง: ของฉัน|ทั้งร้าน · คน (เลขค้างต่อคน + "ยังไม่มีคนรับ") · แท็ก (OR) · ค้นชื่อลูกค้า (หน่วง 350ms, escape `% _`) · เลขนับของทั้งร้านไม่ขึ้นกับตัวกรองอื่น · ทุกค่าอยู่ใน URL · **เมนูซ้ายไม่ใส่เลข** · ค่าแปลกใน URL (uuid ปลอม) = "ไม่กรอง" ห้าม 500
- d) แท็บกิจกรรมในโปรไฟล์ลูกค้า: ข้อมูล/ปุ่มชุดเดียวกับแผงขวา (ห้องล่าสุดของลูกค้า) · ลูกค้าไม่มีห้อง → "งานต้องผูกกับห้องแชท จึงยังเพิ่มงานจากที่นี่ไม่ได้"
- e) ตัวกรองในกล่องแชท หมวด "กิจกรรม": เกินกำหนด / กำลังจะมาถึง / เสร็จสิ้น (มีงานและทำครบ) · ในหมวด OR ต่างหมวด AND · มีตัวเลข · ขอบเขตเดียวกับแผงขวา · แถวห้องมีป้าย "งานค้าง n" เทา / "เลยกำหนด n" แดง (ดึงเป็นก้อน)
