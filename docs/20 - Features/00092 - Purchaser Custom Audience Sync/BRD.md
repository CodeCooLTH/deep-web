# BRD: ส่งรายชื่อลูกค้าที่ซื้อแล้วเข้า Custom Audience อัตโนมัติ

## 1. ขอบเขต
**Input:** คำสั่งซื้อที่ถึงจังหวะ Purchase / ถูกยกเลิก-คืน · การเชื่อมบัญชีโฆษณาของร้าน
**Output:** Custom Audience "ลูกค้าที่ซื้อแล้ว" ในบัญชีโฆษณาของร้านที่อัปเดตเอง
**ผู้ใช้:** เจ้าของร้าน (ตั้งค่า) · Developer (เปิดร้านทดลอง)

## 2. Functional Requirements

#### FR-001: สวิตช์ระบบ + ร้านทดลอง
- [ ] ไม่ตั้ง env เปิด = ปิดทุกร้าน · มีรายชื่อร้านทดลอง = เฉพาะร้านในรายชื่อ (แบบ 00089)

#### FR-002: เชื่อมบัญชีโฆษณา
- [ ] ทางหลัก: ปุ่ม "เชื่อมบัญชีโฆษณา" → Facebook ขอ `ads_management` (เฉพาะบัญชีที่มี role ช่วงทดลอง) → เลือกบัญชีโฆษณาจากรายการ
- [ ] ทางรอง: กรอก Ad Account ID (ตัวเลข) + System User token
- [ ] token เข้ารหัส ไม่แสดงกลับ ไม่ log
- [ ] ตรวจว่ายอมรับข้อตกลง Custom Audience แล้ว — ยังไม่ยอมรับ = บอกให้ไปยอมรับพร้อมลิงก์ ไม่สร้าง audience
- [ ] token แบบกดเชื่อมเหลือ < 7 วัน = แจ้งเจ้าของ 1 ครั้ง

#### FR-003: สร้าง audience
- [ ] เปิดใช้ครั้งแรก = สร้าง Custom Audience ชื่อ "Deep · ลูกค้าที่ซื้อแล้ว · {ชื่อร้าน}" (customer_file_source = USER_PROVIDED_ONLY) และจำรหัสไว้
- [ ] audience ถูกลบใน Ads Manager = สร้างใหม่ตอนส่งรอบถัดไป แล้วเติมย้อนหลังใหม่ทั้งหมด

#### FR-004: เพิ่มลูกค้า
- [ ] คำสั่งซื้อถึงจังหวะ Purchase (ตามที่ร้านตั้งใน 00089 · ไม่ตั้ง = ชำระครบ) → เข้าคิวเพิ่มลูกค้า
- [ ] มาจากแชท Messenger = ส่ง PSID พร้อมรหัสเพจ · มีเบอร์โทร = ส่งเบอร์แฮช SHA-256 (รูปแบบ 66xxxxxxxxx) · มีทั้งคู่ = ส่งทั้งคู่
- [ ] ลูกค้าคนเดิมซื้อซ้ำ = ไม่ส่งซ้ำ
- [ ] ไม่รวมออเดอร์ร่าง/ทดสอบ

#### FR-005: ถอนลูกค้า
- [ ] คำสั่งซื้อถูกยกเลิก หรือคืนครบ → ถ้าลูกค้า (PSID/เบอร์เดียวกันในร้านนี้) ไม่มีคำสั่งซื้ออื่นที่ยังนับ = เข้าคิวถอน
- [ ] ยังมีใบอื่นที่นับ = ไม่ถอน

#### FR-006: ส่งเป็นชุด + ความทนทาน
- [ ] cron รวมคิวส่งเป็นชุด (≤ 10,000 คน/ครั้ง ตามเพดาน Meta)
- [ ] ล้มชั่วคราว ลองใหม่ · token เสีย/ไม่มีสิทธิ์ = หยุดร้านนั้น + แจ้งเจ้าของ · เชื่อมใหม่แล้วส่งต่อ
- [ ] ไม่กระทบการสร้างคำสั่งซื้อ

#### FR-007: เติมย้อนหลัง
- [ ] เปิดใช้ครั้งแรก = เข้าคิวลูกค้าที่ซื้อแล้วทั้งหมดของร้านตามเกณฑ์ FR-004

#### FR-008: หน้าตั้งค่า
- [ ] อยู่ในหน้า Conversions API (00089) เป็นการ์ด "กลุ่มเป้าหมายลูกค้าที่ซื้อแล้ว": สวิตช์เปิด/ปิด · บัญชีโฆษณาที่เชื่อม · ชื่อ/รหัส audience + ลิงก์ Ads Manager · จำนวนลูกค้าที่ส่งแล้ว · ส่งล่าสุด · สถานะ (ปกติ/หยุดเพราะ token)
- [ ] ก่อนเปิดครั้งแรกมีข้อความแจ้งว่า "จะส่งรหัสลูกค้าในแชทและเบอร์โทรแบบเข้ารหัสไปให้ Meta"
- [ ] เจ้าของร้านเท่านั้น

## 3. กฎทางธุรกิจ
- **BR-CA-01** ส่งแค่ PSID+รหัสเพจ และ/หรือ เบอร์แฮช SHA-256 — ห้ามส่งข้อมูลอื่น
- **BR-CA-02** "ซื้อแล้ว" = จังหวะ Purchase เดียวกับ 00089 (HR16 ห้ามนิยามใหม่)
- **BR-CA-03** ถอนเฉพาะเมื่อไม่มีใบอื่นที่นับอยู่
- **BR-CA-04** ปิดใช้ = หยุดส่ง ไม่ลบ audience ใน Meta (ร้านลบเองได้)

## 4. Quality
- เทส: เพิ่มเมื่อถึงจังหวะ / ไม่เพิ่มร่าง-ทดสอบ / ไม่ส่งซ้ำ / ถอนเมื่อยกเลิกใบเดียว / ไม่ถอนเมื่อมีใบอื่น / แฮชเบอร์ไทยถูกรูปแบบ (ค่าอ้างอิงคำนวณมือ) / ไม่มี token หลุด
