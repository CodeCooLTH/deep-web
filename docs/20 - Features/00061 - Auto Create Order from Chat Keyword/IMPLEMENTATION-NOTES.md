## 4. หนี้ที่ยังเปิดอยู่ (พูดตรง ไม่กลบ)

### 4.1 🛑 ยังไม่เคยเปิดหน้าจริงสักหน้า
เวิร์กทรีนี้ไม่มี `.env.local` และ **ไม่เคยรัน browser QA เลยสักเคส** — ทุกอย่างพิสูจน์ด้วย
`tsc` + เทส + theme-guard + mutation เท่านั้น. จุดที่ static ตรวจไม่ได้และเสี่ยงที่สุด:
- การ์ดผลลัพธ์สูง ~304px จากพื้นที่เห็นจริง ~380px ที่ 320×568 (**ตัวเลขจากสเปก ยังไม่ได้วัดจริง**)
- ปุ่มบนการ์ดในเธรดกับ `stretched-link`/พื้นที่กดของบับเบิลข้างเคียง
- แถบสถานะ 3 ค่าบนหน้าตั้งค่าที่ 768px (จุดแตกของประตูมือถือ)
- badge ที่สองในแถว `InboxList` ที่ rail 320px (ดันแถวสูงขึ้นไหม)

### 4.2 ไม่ได้ผ่าน `/impeccable critique` และ `/impeccable clarify`
ทั้งสองคำสั่งต้องรันโดย Controller หลัง build UI เสร็จ (HR8) — **ยังไม่ได้รัน**

### 4.3 ส่วนที่สเปกมีแต่โค้ดยังไม่มี
- **สถานะที่ 4 ของการ์ด** (`CREATED` ที่มาแทนใบก่อนหน้า) — การ์ดขึ้นคำว่า "สร้างใบใหม่แทนใบก่อนหน้า"
  แล้ว แต่ **ยังไม่มีปุ่ม "ยกเลิกใบเก่า"** และยังไม่มีกล่องเตือน iShip (AC-ACO-52)
- **ป้าย "หมดอายุใน N" บนแถว/การ์ดใน `/orders`** — ฟังก์ชัน `describeDraftExpiry()` +
  `compareByDraftExpiry()` เขียนและเทสครบแล้ว **แต่ยังไม่มีจอไหนเรียก**
  🛑 นี่คือคลาสเดียวกับที่ retro 2026-08-25 บันทึกไว้ ("โค้ดที่ถูกทุกบรรทัดแต่ไม่มีใครเรียก")
  — บันทึกไว้ตรงนี้เพื่อไม่ให้มันเงียบ
- **เรียง `expiresAt ASC` เมื่อชิป "ร่าง" ถูกเลือก** — ยังไม่ได้ต่อสายใน `OrdersList`
- `writeAutoOrderResultMessage(kind:'SOURCE_EDITED'|'SOURCE_UNSENT')` ตอนข้อความต้นทางถูกแก้/ถอน
  (TFR-018) — คอลัมน์และชนิดรองรับแล้ว แต่ `ingestMessageEdit` ยังไม่เรียก

### 4.4 ข้อจำกัดที่รู้ตัวและยอมรับ
- **Instagram**: ไม่มี `subscribed_apps` ของตัวเอง และรีโปไม่มีคอลัมน์ผูก IG→Page ⇒ สะท้อน
  สถานะจากเพจ Messenger ของร้านเดียวกัน (MISSING ชนะ) · **ร้านที่มีแต่ IG ได้ `UNKNOWN`
  ซึ่งบล็อกการเปิดใช้งาน** — เลือกให้บล็อกพร้อมข้อความ ดีกว่าปล่อยผ่านแล้วเงียบ
- **`after()` ถูกฆ่าก่อนจบได้บน serverless** — watchdog เป็น safety net ที่จำเป็นจริง ไม่ใช่ของประดับ
- **แคตตาล็อกทั้งร้านถูกโหลดต่อ 1 ข้อความ** — ยังไม่มีตัวเลขจริงจาก prod ว่าร้านทั่วไปมีสินค้ากี่รายการ
  จงใจไม่ตั้ง threshold ลอย ๆ พบว่าเป็นปัญหาจริงหลัง deploy ค่อยเติม cache/limit
