# แผนทดสอบ UAT กับทีม Flash — 2026-10-27

> ระบบ: prod `seller.deepthailand.app` · `OPEN_FLASH_EXPRESS=uat` (คุย `open-api-tra.flashexpress.com`) · เปิดเฉพาะร้าน **ธนภัทร์ อะไหล่มอเตอร์ไซค์** (`FLASH_PILOT_SHOP_IDS`)
> สถานะก่อนเริ่ม: เชื่อม mchId UAT สำเร็จแล้ว (2026-10-24 → ลายเซ็นใช้ได้จริง) · webhook = `EXTERNAL` (ยังไม่ชี้มา Deep) · ยังไม่มีพัสดุ Flash · `createMode = OFF` (ห้ามเปลี่ยนระหว่างเทส)

## 0. กติกาความปลอดภัย (อ่านก่อนเริ่ม)

1. **ใช้ออเดอร์ทดสอบเท่านั้น** — สร้างจากหน้า `คำสั่งซื้อ → สร้างคำสั่งซื้อ` (ไม่ใช่จากแชท) ชื่อผู้รับขึ้นต้น `ทดสอบ Flash` เบอร์ของทีมเอง
   - ออเดอร์จากแชทจะส่งเลขพัสดุเข้าห้องแชทลูกค้าจริงอัตโนมัติ
   - ออเดอร์ 1 ใบมีพัสดุได้ใบเดียว — ถ้าใช้ออเดอร์ลูกค้าจริง ใบ Flash UAT จะขวางการเปิด iShip ของจริง
2. **ห้ามเปลี่ยนโหมดสร้างพัสดุ Flash เป็น "อัตโนมัติ"** — ร้านมีออเดอร์จริงเข้าทุกวัน
3. จบเทส: ยกเลิกพัสดุ UAT ทุกใบ + ยกเลิก/ปิดออเดอร์ทดสอบ
4. ห้ามส่ง Secret Key ในแชท/ภาพหน้าจอ

## 2. ขอจากทีม Flash ตอนเริ่ม

- [ ] URL webhook ที่ตั้งไว้กับ mchId UAT ตอนนี้ (ระบบเราอ่านแล้วได้ "ส่งไปที่อื่น") — ขอลบ หรือยืนยันว่าเราเขียนทับได้
- [ ] ช่องทางให้ทีม Flash **เลื่อนสถานะพัสดุใน UAT** ให้เรา: รับของ → ระหว่างขนส่ง → นำส่ง → ส่งถึง (มีลายเซ็น/รูป) · ติดปัญหา (markerCategory) · ตีกลับ (ได้เลขใหม่) · ชั่งน้ำหนักจริง + ราคาจริง
- [ ] ยืนยันว่า UAT ยิง webhook ออกมาที่ `https://deepthailand.app/...` ได้ (ไม่มี IP allowlist ฝั่งเรา)

## 4. คำถามให้ทีม Flash ตอบ (จดคำตอบ)

1. ส่ง `outTradeNo` เดิมซ้ำ → ได้ error 1003 อย่างเดียว หรือคืน `pno` เดิมด้วย? มีวิธีค้นพัสดุด้วย `outTradeNo` ไหม
2. Rate limit ต่อ mchId / IP allowlist มีไหม
3. webhook retry: ถี่แค่ไหน นานแค่ไหน · ช่อง `dataSign` / `dataJson` ใน webhook ราคาคืออะไร ใช้ตรวจเนื้อหาได้ไหม
4. ชื่อจังหวัดกรุงเทพต้องส่งเป็น "กรุงเทพ" หรือ "กรุงเทพมหานคร"
5. เวลาใน webhook (`stateDate`/`routedAt`) เป็นโซนไหน
6. ตีกลับถึงร้านแล้ว = เลข `returnedPno` ถึง state 5 ใช่ไหม
7. มี API/รายงานแจ้ง "โอนเงิน COD ให้ร้านแล้ว" ไหม (ตอนนี้ไม่มีในเอกสาร)
8. `codRefunded` / `codRefundedPno` หมายถึงอะไร
9. ใบปะหน้าที่เราพิมพ์จาก `/pre_print` ใช้งานจริงได้เลยไหม
10. ขั้นตอนขอ key production สำหรับร้าน + เปิด COD
