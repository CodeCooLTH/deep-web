# เสียงแจ้งเตือนแชทใหม่ในแอปผู้ขาย

## มติ user (2026-10-09)
- ใช้เสียงแชทเดียวกับที่ดังในเว็บ: `public/sounds/sound-new-chat-msg.m4a` (ยาว 1.2 วินาที)
- **แอปผู้ขายเท่านั้น** แอปผู้ซื้อใช้เสียงมาตรฐานเหมือนเดิม
- **เฉพาะแจ้งเตือนแชทใหม่** (`pushNewChatMessage`) แจ้งเตือนอื่นของผู้ขายใช้เสียงมาตรฐาน

## ทำงานยังไง
| | iOS | Android |
|---|---|---|
| ไฟล์ในแอป | `assets/sounds/new_chat_message.wav` ฝังผ่าน `expo-notifications` `sounds` | ไฟล์เดียวกัน (เป็น resource) |
| ตัวเลือกเสียง | payload `sound: "new_chat_message.wav"` | channel `chat` (แอปสร้างพร้อมเสียงนี้) · payload `channelId: "chat"` |

ฝั่งเว็บกำหนดเสียงที่ `PUSH_SOUNDS` ใน `src/lib/expo-push.ts` (`default` · `chat`) ผู้เรียกส่ง `{ sound: 'chat' }` ผ่าน `pushToUsers`

## ข้อควรรู้
- **ไฟล์เสียงฝังในตัวแอป ⇒ ต้อง build ใหม่และส่งรีวิว** อัปเดตแบบ OTA ไม่พอ
- **เครื่องที่ยังไม่อัปเดตแอป:**
  - iOS หาไฟล์ไม่เจอจึงเล่นเสียงมาตรฐาน ไม่พัง
  - Android ยังไม่เคยปล่อย จึงยังไม่มีเครื่องที่ใช้ channel แบบเก่า
- **Android แก้เสียงของ channel ที่สร้างไปแล้วไม่ได้:** วันที่อยากเปลี่ยนเสียง ต้องตั้ง channel ชื่อใหม่ทั้งในแอปและในเว็บ
- 🛑 **`PushToken` ไม่ได้เก็บว่าเป็นแอปผู้ขายหรือผู้ซื้อ:** ผู้ขายที่ล็อกอินแอปผู้ซื้อด้วย จะได้ payload เสียงแชทที่แอปผู้ซื้อด้วย
  - iOS: แอปผู้ซื้อไม่มีไฟล์ จึงเล่นเสียงมาตรฐาน
  - Android: **ก่อนปล่อยแอปผู้ซื้อบน Android ต้องสร้าง channel `chat` ในแอปผู้ซื้อด้วย** หรือเพิ่มคอลัมน์บอกว่าเป็นแอปไหน
