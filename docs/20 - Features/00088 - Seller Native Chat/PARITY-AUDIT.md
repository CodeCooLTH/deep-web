2. **บ้านพักในแชทเว็บไม่ได้สร้าง Booking** — ปุ่มสร้างเปิด `OrderCreateForm` ด้วยคำ "บิลเข้าพัก" ทุกประเภทร้าน (CustomerPanel.tsx:939 · ChatThread.tsx:3712) ⇒ native ต้องใช้ฟอร์ม native แทนการเปิด `/bookings/new`
3. **ปฏิทินนัด/ค้นหาลูกค้าเก่า เว็บก็ใช้ร้านที่เปิดอยู่เท่านั้น** (≡ เท่ากันแล้ว)
4. ไม่มีจุด hidePayments เพิ่มในขอบเขตนี้ (เว็บใช้แค่ใน AiSuggestPanel ซึ่ง native ทำตามแล้ว) · ลิงก์เติมเงิน iShip เป็นของบุคคลที่สาม เว็บไม่ซ่อน

## E. ของที่ Native ทำแต่เว็บไม่มี

ตัดสิน (2026-10-31 · ตามคำสั่ง "ให้เหมือนหมด"):
- **ตัดออก/เปลี่ยนให้เท่าเว็บ** (เป็นพฤติกรรมที่ native คิดเอง): ถามเขียนทับตอนเลือกสินค้า (T59) · ปุ่ม "แก้ไขรายการ" ท้ายการ์ด (P20) · ยกเลิกเป็นปุ่มเปล่า (P21) · ใบมีนัดมีสองปุ่ม (P19) · ถามผลก่อนทำแล้ว (P29) · หัว "ข้อมูลลูกค้า" (P8) · ชื่อผู้ส่งเป็นข้อความ (T21) · สถานะส่งทุกฟอง (T20) · หัว "กลุ่ม" (L15) · ข้อความปิดฟอร์มที่พูดถึงการย่อ (P42)
- **คงไว้** (จำเป็นของแอป ไม่เปลี่ยนกติกาเว็บ): แถบออฟไลน์+คิวส่งรอเน็ต · ดึงลงรีเฟรช · haptics · แคชในเครื่อง · หน้า "ตั้งค่าแอป" (สวิตช์ native/เว็บ) · แผ่นแนบ 4 แบบ (คลังรูป/ถ่ายรูป/วิดีโอ/ไฟล์ — มือถือไม่มี file input) · ทางหนี "เปิดในหน้าเว็บ" สำหรับของที่ยังไม่ native
