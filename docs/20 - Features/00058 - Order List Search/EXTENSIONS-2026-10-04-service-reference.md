# ส่วนขยาย 2026-10-04: ช่อง "ข้อมูลอ้างอิง" (`Order.serviceReference`)

## 1. ที่มา

ร้าน BT Premium (ร้านบริการ/ติดตั้งอุปกรณ์รถ) พิมพ์ทะเบียนรถรวมไว้ในช่องชื่อลูกค้า เช่น `4กฐ9100 คุณบุญคอง` เพราะไม่มีที่ให้กรอก แล้วใช้ช่องค้นหาหน้ารายการงานหาด้วยทะเบียน

user ขอช่องข้อความธรรมดา 1 ช่อง หน้าตาเหมือนช่องชื่อลูกค้า โดยมีเงื่อนไขดังนี้:
- ไม่บังคับกรอก
- ค้นหาได้จากหน้ารายการงาน
- ต้องมีในหน้าสร้างงาน
- ร้านกรอกอะไรก็ได้ เป็นช่องกลาง ๆ ที่ใช้ได้กับบริการทุกประเภท
- ข้อความตอนยังไม่กรอกใช้แบบ A3-2

## 3. สิ่งที่เปลี่ยน

### 3.3 หน้าจอ (ร้านบริการเท่านั้น)

**ฟอร์มสร้าง/แก้ไข**
- มือถือ (`CustomerQuickBlock`): ช่องอยู่ใต้เบอร์โทร
- เดสก์ท็อป (`CustomerSelectBlock`): ช่องอยู่แถวเต็มต่อจากชื่อ/เบอร์
- ไม่มีดาวแดง
- หน้าแก้ไขโหลดค่าเดิมผ่าน `GET /api/orders/[token]`

**หน้ารายการ `/orders`**
- ค้นหาได้ทั้งมือถือและเดสก์ท็อป
- ข้อความช่องค้นหาต่อท้าย "/ ข้อมูลอ้างอิง"
- การ์ดและแถวตารางมีชิปค่าอ้างอิงอยู่หน้าชื่อลูกค้า และไฮไลต์คำค้นในชิป

**หน้ารายละเอียด**: การ์ดลูกค้ามีแถว "ข้อมูลอ้างอิง: …" (ไอคอน `tag`)

### 3.4 การค้นหา

**`searchOrders` (TS)**
- ค่าอ้างอิงอยู่ในชุดฟิลด์ที่ค้นทีละคำ เช่น `บุญคอง 9100` ก็เจอ
- มีกฎเพิ่มอีกหนึ่งข้อ: ถ้าค่าที่ตัดช่องว่าง/ขีดออกแล้ว **มีคำค้นทั้งก้อน** อยู่ข้างใน ถือว่าตรง ทำให้ `4กฐ9100` เจอใบที่บันทึกว่า `4กฐ 9100`
- `isExactIdentifierMatch`: ตรงเต็มค่า (ไม่สนช่องว่าง) จะลอยขึ้นบนสุด

**`order-search-sql.ts`**
- กติกาเดียวกันเป๊ะ (`regexp_replace` ตัด `[[:space:]._/-]`)
- เทส parity ยืนยันว่าผลตรงกับฝั่ง TS

### 3.5 กันไม่ให้ถึงผู้ซื้อ

มี endpoint ที่ผู้ซื้อเรียกได้และคืน Order **ทั้งแถว** (ไม่มี `select`) ทำให้คอลัมน์ใหม่หลุดไปถึงผู้ซื้อทันทีถ้าไม่ตัด จุดที่ต้องตัดด้วย `omitServiceReference()`:
- `GET /api/orders?role=buyer`
- `POST /api/orders/[token]/confirm`
- `POST /api/orders/[token]/cancel`

หน้า `/o/[token]` และ `guest-order-data.ts` ไม่อ่านช่องนี้เลย มีเทสสแกนกันไว้

## 4. เทส `[blocker]`

ไฟล์ `src/lib/__tests__/service-reference.test.ts` มี 17 เคส ครอบเรื่องต่อไปนี้:
- ตัวตัดสินและการเก็บค่า
- สคีมา ≤100
- ค้นหาทุกรูปแบบ รวมหลายคำ
- จัดอันดับ
- ข้อความช่องค้นหาต่อ vertical
- ทุกจุดเขียนผ่านตัวตัดสิน
- ฟอร์มแสดงเฉพาะร้านบริการ
- หน้าแก้ไขโหลดค่าเดิม
- endpoint ผู้ซื้อตัดค่าออก

ผลการตรวจ:
