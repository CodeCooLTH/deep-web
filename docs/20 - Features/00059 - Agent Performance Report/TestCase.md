## 2. อัตโนมัติ — SQL ต้องเท่ากับ TS (รันแล้ว เขียว)

ไฟล์: `src/services/__tests__/agent-performance-sql-parity.test.ts` — 1 เคส `[blocker]`

ป้อนชุดข้อมูลสังเคราะห์ 22 แถวผ่าน `VALUES` (ไม่อ่านไม่เขียนตารางจริงเลย) แล้วเทียบผลของ
`buildResponsePairsSql()` กับ `computeResponsePairs()` ต้องได้คู่ชุดเดียวกันทุกแถว
พร้อมปักหมุดคำตอบที่รู้ว่าถูกไว้ตรง ๆ (กันกรณีสองฝั่งเพี้ยนพร้อมกัน)

รันด้วย: `DATABASE_URL="postgresql://safepay:safepay@localhost:5434/safepay" npx vitest run src/services/__tests__/agent-performance-sql-parity.test.ts`
(fail-closed: ไม่ยอมรันถ้า connection ไม่ได้ชี้ localhost — HR13/14)

**mutation ที่ทำกับฉบับ SQL:**

| mutation | ผล |
|---|---|
| `MIN(createdAt)` → `MAX(createdAt)` ตอนหาใบแรกที่รอ | 🔴 แดง |
| ถอด `autoReplyKind IS NULL` ออกจากเงื่อนไข "คนตอบ" | 🔴 แดง |
| ถอด `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW` | 🟢 เขียว — **equivalent จริง** เพราะ `ChatMessage.seq` เป็น `@unique` ⇒ ไม่มี peer row ให้ `RANGE` ต่างจาก `ROWS` (บันทึกไว้ในคอมเมนต์ของฟังก์ชันแล้ว) |
