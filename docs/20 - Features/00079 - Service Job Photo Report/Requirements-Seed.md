# 00079 — รายงานงานบริการด้วยรูป (เมล็ดความต้องการ ยังไม่ใช่ PRD)

> แยกออกจาก 00078 ตามมติ user 2026-10-17 · ต่อยอดจุดเสียบ FR-CS-30 ของ 00078 (`composeServiceNotice`, kind/valueKey เสถียร)
> ต้องเขียน PRD + BRD ให้ user อนุมัติก่อนโค้ด (HR11)

## ความต้องการจาก user (คำต่อคำที่สรุป)

1. รายงานงานบริการ = **รูปก่อน/หลัง + บันทึกช่าง + ลิงก์ดูรายละเอียด** (2026-10-17)
2. **ตอนกด "เริ่มงาน" หรือ "ปิดงาน" มีตัวเลือก** ว่าจะส่งภาพรายงานด้วยไหม — รูปก่อนต้องถ่ายก่อนเริ่มงาน · รูปหลังถ่ายตอนปิดงาน (2026-10-17)
3. **ร้านเลือกได้ว่าจะส่งรูปแบบไหน:** เป็นลิงก์ (หน้ารายงาน) หรือส่งเป็นชุดรูป (batch image) เข้าแชทโดยตรง (2026-10-17) — ต้องตัดสินว่าเป็นค่าตั้งต้นระดับร้าน (หน้าตั้งค่าส่งอัตโนมัติของ 00078) หรือเลือกทุกครั้ง หรือทั้งสอง

## ข้อเท็จจริงจากโค้ด (สำรวจ 2026-10-17 — ดู `00078 …/Research-Notes.md` ส่วนงานบริการ)
